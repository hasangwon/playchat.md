# 외장(외부 호스팅) 이미지 방식 실측 — 2026-10-21

> 인기작 제작자 댓글(대댓글)에서 직접 확인. 크랙·베이비챗 상위작은 플랫폼 업로드가 아니라 **외부 호스팅 이미지 URL + 코드 규칙**으로 이미지를 출력한다. 플랫폼 장수 제한(베이비챗 100장 등)과 무관하게 수백 장을 쓴다.

## 크랙 베스트 1위 「게임 판타지 속 히든 클래스가 되다」(메테르, 317.5K)
URL: https://crack.wrtn.ai/detail/6aad594a3d1e941464f45bae
- 제작자 고정 댓글: "대댓에서 이미지 목록 확인 가능합니다." + "웹사이트에 복사 가능한 유저노트 용 문구가 있으니 활용" → **제작자 개인 도메인**(metel.uk)에 이미지·유저노트 문구 호스팅.
- 상세 설명에 단축어 `/디버그 -> 이미지 오류 해결용`, `/갤러리 -> 커뮤니티 열람용`, `/요약`, "1인당 인게임/현실 이미지 있음".
- 대댓글(제작자)의 이미지 규칙 원문:
```
주연 캐릭터: ![](https://1.metel.uk/{G/R}/{ID}/{상황코드}.webp)

G=로그인(게임 속 아바타) / R=로그아웃(현실 모습)
상황코드 0 기본 1 미소 2 웃음 3 슬픔 4 오열 5 삐짐 6 화남 7 경멸 8 설렘/부끄 9 놀람/당황
         10 포옹 11 착의+키스 12 머리쓰다듬받는 13 볼꼬집 14 전투 15 부상 16 사망
```

- 규모 계산: 주연 22명 × 2모습(G/R) × 상황 17종 = **최대 748장**(주연만) + NPC 37 + 몬스터 수십 + 지역. → 작품 하나에 수백~천 장 단위.

## 구조 요약 (실무 표준으로 채택)
1. 캐릭터마다 **같은 상황코드 표**(0 기본~N)로 이미지 세트를 일괄 생성(NAI 등).
2. `호스트/카테고리/{캐릭터ID}/{상황코드}.webp`처럼 **규칙적인 경로**로 외부에 업로드(webp).
3. 프롬프트(또는 키워드북)에 **마크다운 이미지 문법 + ID표 + 상황코드표**만 넣는다. AI가 장면에 맞는 URL을 조립해 출력.
4. 이미지가 깨질 때를 위해 `/디버그` 단축어, 코드표는 댓글·대댓글에도 공개(유저 유저노트용).
5. 호스팅: 개인 도메인(이 사례), 그 외 호스팅 서비스 종류는 추가 확인 필요.

## 베이비챗 랭킹(남성향) 페이지 — 작품 소개문에 노출된 외부 URL
- 이미지 직링크: `https://iioi9.com/AL1/{번호}.webp` (번호 1~232+ → 한 작품에 200장 이상)
- 제작자 개인 도메인·소개 페이지: ajin.uk(…/uni_academy.html), hero-aichat.cc(…/EGO.html), si-ran.com/preview, hjk100.com/link/*.html, 51yb.org/JD/preview.html
- **Cloudflare R2**(`pub-….r2.dev/….html`) — 무료 구간이 있는 오브젝트 스토리지를 호스팅으로 사용
- 아카라이브 채널 링크(작품 홍보·가이드)
- 명령어 관례: `!다음날`, `!요약`, `!디버그 — 이미지·상태창 오류 복구`, "자세한 사항은 고정댓글 및 플레이가이드" → 크랙의 `/디버그`와 동일한 패턴
- 소개문 관례: "인물 현재 17명/여캐플", 해시태그 `#19 #시뮬레이션 #NTL` 등

## 결론
- 상위 제작자 표준 = **개인 도메인 또는 Cloudflare R2에 webp 업로드 + `![](URL)` 코드 규칙 + 고정댓글/별도 HTML 페이지로 코드표·유저노트·이미지 목록 공개 + `디버그` 명령어**.
- 이미지 장수는 작품당 **200~700장 이상**(크랙 1위 주연만 최대 748장 구조, 베이비챗 상위작 230번대 파일).
- 미확인: 이미지 생성 도구(NAI 추정), 호스팅 비용, 플랫폼 정책상 외부 이미지 허용 범위(크랙 운영정책 "외부 이미지 활용 위반은 최고 제재" — 정책 위반 이미지만 해당하는지 확인 필요).

## 케이브덕 공식 크리에이터 작품 「대설원의 영혼들」
- 페이지 본문(크리에이터 코멘트/별도 설명)에 `https://i.cvdk.io/charim/{uuid}` 이미지 URL 다수 → **케이브덕 자체 이미지 서버(i.cvdk.io)에 올린 뒤 URL을 텍스트로 사용**. 외부 개인 도메인은 이 페이지에선 미사용.
- 케이브덕 제작 규정상 경쟁 플랫폼 유도 링크 금지, 소개란 HTML 이미지는 "케이브덕 업로드 주소 권장"(research/09 C-4, H).

## 이미지 파일 실측
- metel.uk / iioi9.com 샘플 3장: webp, 장당 약 0.8~1.06MB. **생성 도구 메타데이터 없음(제거됨)** → 파일로는 도구 판별 불가. 커뮤니티 근거상 NAI가 표준(docs/30-image-assets/02-tools.md 정정 블록).
- 용량 추정: 700장 × 1MB ≈ 0.7GB/작품.

## 정책
- 크랙 운영정책: 외부 이미지 사용 자체 금지 조항 없음. "외부 이미지를 활용한 위반"은 정책 위반 이미지를 외부 링크로 우회한 경우 최고 수준 제재(research/10 D) → 외장 이미지도 프로필·상황 이미지와 같은 기준 적용.
- 베이비챗 공식 가이드: 이미지는 "내부(img:[slug]) 또는 외부 URL 중 한 방식만" 사용(research/02 3.2) → 외부 URL 공식 허용.
- 케이브덕: 자체 서버 URL 사용이 관례·권장.
