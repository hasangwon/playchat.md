# 베이비챗(babechat.ai) 제작 스튜디오 스냅샷 — 2026-10-21 (로그인 상태, 브라우저 직접 확인)

> 사용자 계정으로 로그인된 상태에서 `캐릭터 제작` 화면까지 진입해 확인. **아무것도 제출/저장하지 않음.** 제작 화면 진입 시 '캐릭터 제작 시 반드시 유의해주세요!' 동의 모달이 뜨며, 이 모달은 사용자 확인 후 눌러야 함(약관 동의 성격).

## 홈 구조 (babechat.ai)
- 좌측 사이드바: 캐릭터 제작 / 채팅 목록 / B ONLY (19) / 프로챗 충전 / 최근 대화
- 홈 탭: 홈 / 신작 랭킹 / 랭킹 / 오늘 신작 / 파생작(19) / 카테고리 / 태그 / 공식 크리에이터 / 신인…(19)
- 섹션: "지금 뜨는 신작 캐릭터" 등. 카드에 `B ONLY` 뱃지(베이비챗 독점) 표시.
- 배너: 출석 플러스 출시, 선정작 50만 캐시 지원(공모/선정 이벤트), 앱 설치.

## 내 캐릭터 페이지 (`/character/my`)
- 필터 탭: 전체 / 공개 / 비공개 / 링크 공개 / 임시 저장
- 플랫폼 토글: **베이비챗 / 투킷** → 같은 스튜디오에서 투킷(여성향 자매 플랫폼)용 캐릭터도 제작·관리
- 정렬: 대화량순

## 캐릭터 제작 폼 (`/character/create?draft=none&tab=profile`)
상단 스텝 탭(순서): **프로필 → 캐릭터 설정 → 캐릭터 에셋 → 시작 상황 → 로어북 → 기타 설정 및 등록**
우측 상단: `임시 저장` 버튼.

### 1) 프로필 탭 필드
| 필드 | 제한/안내 |
|---|---|
| 대표 이미지 | `업로드` 또는 `AI 생성`(내장 이미지 생성 기능 존재). PNG/JPG/WebP. **1:1 비율 권장, 5MB 이하**. 부적절 이미지 제한(제작 정책 참고) |
| 이름 | **최대 20자**, 특수문자·이모지 가능 |
| 캐릭터 소개 | **최대 500자**, `자동 생성` 버튼 있음 |
| (하단) 다음 버튼 | 다음 스텝으로 이동 |

### 우측 패널: 채팅 테스트
- "내가 제작한 AI 캐릭터와 먼저 이야기해보세요. (최대 **10회** 가능)" — 0/10 카운터
- 일반 채팅 기준으로 진행, **필수정보를 모두 채워야** 대화 시작 가능
- 미리보기 항목: 첫 대화 날짜 / 첫 상황 / 캐릭터 이름 / 첫 대사 / 상황묘사 / 추천답변
  → 시작 상황에는 '첫 대화 날짜', '첫 상황', '첫 대사', '상황묘사', '추천답변' 개념이 있음을 시사

### 제작 시 운영정책 모달(원문 요지)
- 운영진 실시간 모니터링, 위반 시 캐릭터 삭제·계정 차단
- 금지: 과도한 선정성 / 지나치게 공격적·편향적 표현 / 저작권·초상권 침해 / 딥페이크·허위정보·미성년자 성적 대상화
- "세이프티 캐릭터 세부 가이드라인"을 포함한 운영정책 반복 위반 시 제재 강화
- 링크: `베이비챗 운영 정책`, `세이프티 캐릭터 세부 가이드라인` (URL은 아래 인터랙티브 트리에서 확인)

## 상위 캐릭터 메시지 포맷 관찰 (최근 대화 '이안' 캐릭터 첫 메시지에서)
```
<서술 문단 — 3인칭 소설체, 상황·행동 묘사>
이건우 | "대사"
<서술>
img[499y1] 이안 | "대사"      ← 메시지 중간에 이미지 삽입 문법 `img[ID]` + `이름 | "대사"` 포맷
<서술>
img[499y1] 이안 | "대사"
info 🗓2024년 1월 15일 | (월요일) ⏰️현재 시간 오후 2시 10분 🧒이안 / 10살 / 135cm, 29kg
🥼하상원의 복장 … 🥼이안의 복장 … 🗺하상원의 위치 … 🗺이안의 위치 … 💫현재 상황 …
```
- 메시지 끝에 **상태창(info 블록)**: 날짜/시간/캐릭터 스펙/양측 복장/양측 위치/현재 상황 — 이모지 라벨로 구조화. 몰입·연속성·기억 보조 장치로 널리 쓰이는 패턴.
- 멀티 캐릭터(이건우 + 이안) 등장, 유저 이름(하상원)은 유저 페르소나 치환.
- 세이프티 관점 주의: 해당 캐릭터는 10세 아동 설정 — 미성년 캐릭터 자체는 존재하나 성적 대상화는 금지. 우리는 미성년 설정 자체를 피하는 것을 기본 원칙으로 함.

## 남은 확인 항목 (동의 모달 통과 후)
- 캐릭터 설정 탭: 프롬프트/페르소나/유저노트 필드와 글자 제한
- 캐릭터 에셋 탭: 이미지 에셋 규격, `img[ID]` 문법, 표정/상황 이미지 수 제한
- 시작 상황 탭: 복수 시작 상황 가능 여부, 첫 대사/상황묘사/추천답변 길이 제한
- 로어북 탭: 키워드/내용/활성화 조건 필드, 엔트리 수 제한
- 기타 설정 및 등록: 공개 범위(공개/비공개/링크 공개), 태그/카테고리, 19 여부, 댓글, 베이비챗/투킷 선택, 심사 안내
