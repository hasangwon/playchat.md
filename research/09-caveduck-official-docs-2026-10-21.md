### A-2. 부가 수익
| 항목 | 유저 비용 | 크리에이터 수익 | 설정 위치 |
|---|---|---|---|
| 이미지 잠금 해제 | 500🪽(윙) 또는 500 | **250** 인센티브 | 캐릭터 만들기 > 미디어 > 이미지 추가 후 잠금 아이콘 |
| 스토리 유료 회차 열람 | 300 | **100** | 캐릭터 생성 후 [스토리 만들기] |
| 슈퍼보이스 재생 | 80 | **8** | 미디어 > 슈퍼 보이스 |
| 스냅샷 생성 | 150 | **10** | 공개 설정 > 스냅샷 허용 |
| 친구 추천 | — | 1,000 (가입 24시간 후) | 캐릭터 링크 공유 가입 or 추천 코드 |

### A-3. 현금화
- 인센티브 → 윙/깃털 전환(정수 단위) 또는 **현금 출금**.
- 출금 조건: **보유 인센티브 200,000 이상**, 단위 200,000 / 400,000 / 600,000 / 1,000,000 (공식 크리에이터는 최대 1,500,000).
- 환율: **200,000 인센티브 = 120,000원(세전)** → **1 인센티브 = 0.6원**. 400,000→240,000원, 600,000→360,000원.
- 출금 신청: [혜택] > 인센티브 [전환] > [출금 신청하기], 매월 1일~말일 접수.
- 환산 예: Opus 대화 1회 = 20인센티브 = 12원. 월 100만원을 벌려면 약 1,666,667 인센티브 ≈ Opus 대화 83,000회 또는 이미지 잠금해제 6,667건.

## B. 오리지널 캐릭터 제도 — 「오리지널 캐릭터란?」
- 케이브덕 **독점 공개** 캐릭터를 오리지널로 등록 → 'Original' 뱃지, 오리지널 태그 자동 부여, 고급 모델 이용 시 추가 인센티브(+1).
- 공식 수치: 일반 캐릭터 평균 채팅 161회 vs 오리지널 평균 1,061회 (**6.6배**).
- 설정: 캐릭터 생성/수정 > [공개 설정] > "케이브덕 오리지널 캐릭터" 토글.
- **3개월 동안 해제 불가**, 타 플랫폼 동시 공개 시 해제/조정될 수 있음. 타 플랫폼에서 비공개/삭제했다면 등록 가능. 세계관만 공유하고 캐릭터 설정이 다르면 가능. 리메이크/성인·비성인 변경판은 불가.

## C. 제작 규정 — 「캐릭터 제작 규정」(심사·제재 기준)
### C-1. 전체 금지
- **미성년자(19세 미만) 성적 표현 일체 금지.** 설정상 성인이어도 아래 중 하나라도 있으면 미성년자로 간주: 교복/학생복, 교실·학교가 주 배경, 외형·말투·행동이 미성년으로 보임. 중·고교 교사 직업은 가능하나 학교/학생이 주 설정이면 불가. 폐교·과거 고등학교 배경도 불가. 교실 배경 대학생은 성인 외형+성인 설정 명시 시에만 허용. **언세이프 캐릭터에는 미성년 등장인물 포함 불가.**
- 인간형 캐릭터의 어린 시절/육아/보호 설정 불가(인외 캐릭터만 조건부 예외 + 프롬프트와 설명에 "미성년/육아 대상과 성적 상호작용 불가" 지침 필수).
- 실존 인물 성적 묘사 금지. 실존 인물 기반이면 **전체 이용가 + 수익화 제한** 필수. 타인 저작권 포함 시 수익화 제한 필수.
- 범죄: 불법촬영물, 성매매 알선, 강간·윤간 노골 묘사, 범죄 미화·방법 상세, 적십자 마크.
- 도덕: 사회적 약자 비하·학대 묘사, 잔혹 신체 손상, 자살 미화, 차별·편견 조장, 도박 조장, 수간.
- **(NEW) 혈연 근친 설정 등록 불가.** 의남매/법적 가족/소꿉친구 등 비혈연은 비혈연임을 명확히 기재 시 허용.
- 무의미하거나 다수 중복되는 설정 불가.
### C-2. 세이프티(청소년 이용가) 캐릭터에 넣으면 안 되는 것 → 있으면 반드시 '청소년 이용 불가' 설정
- 성행위 묘사/암시, 성매매 관련 설정(매춘부, 유흥업소 등), 유혹·접대·밤 상대 표현, 페로몬·최면·강제 유혹 장치, 체액 표현, 특정 신체 부위(발 포함) 과도 강조, 성기 지칭 단어.
### C-3. 이미지 가이드라인
- 세이프티: 성적 암시 금지(표정·자세 포함). 수영복·운동복 일반 노출은 허용, 부위 강조·시선 유도 포즈는 제한. 실사/실존 인물로 보이는 이미지는 'AI 제작' 명시 필수.
- 언세이프: 등장인물 전원 19세 이상 외형. 치비(SD) 이미지는 비성적 용도만. 직접 성행위·성기 접촉·성기 노출 이미지는 대표 이미지 불가(의상 착용해도 불가). 여성 유두 노출 불가.
- 앨범 이미지: 성기·음모·항문 등은 **불투명 유색(흰/검)으로 가림** 필수. 모자이크·블러·시스루 불가. 피부색 가림 불가. 촉수 가림 기준 별도.
- 크리에이터 프로필, 캐릭터 소개란(HTML) 이미지는 세이프티 기준 적용.
### C-4. 외부 링크
- 개인 SNS·포트폴리오 링크 가능. **타 AI 캐릭터 플랫폼/경쟁 서비스 유도 링크 금지.**
### C-5. 위반 시 조치
- 캐릭터: 청불로 임의 변경 / 수익화 제한으로 변경 / 비공개 / 차단 / 삭제. 크리에이터: 공개(출시) 제한. 사전 안내 없음.

## D. 제작 폼 필드 — 「캐릭터 기본 제작 방법」
- 변수: `{{user}}`, `{{char}}` 치환 지원. 프롬프트는 **토큰 단위** 계산, 저렴한 모델 기준 **전체 2,000 토큰 권장**(짧고 간결).
### D-1. 기본 정보
| 필드 | 제한 | 메모 |
|---|---|---|
| 캐릭터 이름 | 최대 50자 | 번역 시 혼동 없는 명확한 이름 |
| 캐릭터 설명 | 최대 10,000자 | 나이·국가·외모·의상·성격·취미. 단어 위주 작성 권장 |
| 세계관(선택) | 제목 60자 / 설명 10,000자 | '세계관 관리' 메뉴에서 여러 캐릭터가 공유 가능 |
### D-2. 에피소드(도입부) 설정
- **시작 대사**: 에피소드 **최대 3개**, 각 10,000자. 형식 = 줄글(캐릭터 1인 대사) 또는 나눠쓰기(캐릭터/플레이어/지문 구분, **말풍선 최대 10개**).
- **비밀(선택)**: 유저에게 비공개, AI만 아는 정보. 10,000자. 플랫폼 지침이 "유도/발견 전엔 자연스럽게 숨김"을 함께 적용.
- **문체 프롬프트(선택)**: 비우면 기본 문체. 말투/출력 규칙/서술 방식/감정 표현. 한두 문장이면 충분. 예시 유형: ①말투 중심 ②서술+분위기 중심 ③출력 형식(최대 5줄, 유저 대사·행동 임의 생성 금지).
### D-3. 미디어
- **앨범 이미지**: 내장 AI 이미지 생성(10윙, 구독 시 무료). 금지 이미지 자동 분류 → 업로드 차단(재분류 신청 가능). 업로드 시 **키워드 자동 부여**, 대화 맥락에 맞는 이미지가 키워드 기반 자동 출력. 잠금 설정 시 유저 500윙 구매 → 250 인센티브. 키워드 팁: `smile1, smile2` 대신 `smile`로 통일(랜덤 1장), `random` 같은 키워드 비권장, **100장 초과 시 오작동 가능**.
- **슈퍼 보이스**: 목소리 설정, 유저 80윙 → 8 인센티브.
### D-4. 예시 대화(선택)
- 말투 중심. **항상 적용**(모든 세션 포함; 말투·어조·기본 반응) vs **상황에 따라 적용**(벡터 유사도로 관련 시만 포함; 특정 상황 반응).
### D-5. 공개 설정
- 비공개 / 링크 공개 / 공개(인센티브 획득 가능).
- 자동 번역(10개 언어 유저 존재). 전문가 모드 시 [저장 후 번역] 필수.
- 세이프티 여부(청불 설정 필수 조건은 C-2).
- **타깃: 남성향 / 여성향 / 전체** — 전체 타깃은 4조건(대표 이미지·인물 구성·스토리·소개/태그 모두 비편중) 충족 시만.
- 한 줄 소개(검색·메인 노출), 크리에이터 코멘트(마크다운/HTML), **태그 최대 10개**, 연관 캐릭터 최대 6개, 수익화 제한(저작권·실존 인물), 스냅샷 허용.
- 이미지 해상도·형식·용량은 문서에 **명시 없음(미확인)**.

## E. 전문가 모드 — 「전문가 모드 사용 방법」
1. 제작 유형: **롤플레잉**(1:1 상황극) / **시뮬레이터**(상황·사건 중심, 다수 인물) → 기본 프롬프트가 달라짐.
2. 수동 번역: [저장 후 번역] 대상 한국어·영어·일본어·스페인어·중국어(번체). 공개 탭 [번역본 관리]에서 수정.
3. 사용자 별도 설명: 프롬프트에 미반영되는 소개 페이지 영역(마크다운/HTML).
4. 키워드북(로어북) 적용: 만들기→키워드북→만들기 / 캐릭터 기본정보→전문가 모드→키워드북 설정.
5. 문체 프롬프트.
6. **추천 페르소나 가이드**: 최대 300자, 에피소드별. "플레이어가 누구인지"(관계·직업·성별·성격) 기준으로 작성.
7. **추천 모델 설정**: 모델+최대 출력량 조합 최대 3개, 대표 1개, 에피소드별. 출력량 초과분은 유저 추가 요금 → 유저 비용 고려.
8. **프롬프트 와치**: 내 캐릭터 채팅방 우측 상단 청진기(🩺) → 설정/예시대화/키워드북 반영 확인. RAG → Keywordbook에서 직전 답변에 적용된 키워드 확인.

## F. 키워드북(로어북) — 「키워드북 제작」
- 구성: **기본 키워드**(대화에 단어 등장 시 자동 삽입) + **단축어 키워드**(이름 붙인 AI 지시문, 유저가 호출).
- 키워드북 이름 20자, 폴더 분류, 개수 무제한. 공개 캐릭터에 연결된 키워드북 수정은 즉시 반영 → 테스트 후 적용.
- 기본 키워드 항목: 세부 키워드 여러 개(각 50자, `|`로 일괄 입력) + 내용 1개(**400자**). 항목 **최대 150개**, 한 대화에 **최대 10개** 삽입, **위에서부터 우선** → 순서 편집으로 중요 항목 상단 배치. **세부 키워드는 자동 번역 안 됨** → 다국어 키워드 직접 등록 (`불의 잔|Goblet of Fire|炎の杯`).
- 예: `루멘 제국|루멘|제국`, `엘레나 아르망|엘레나|아르망 공녀`, `붉은 방 사건|17번 사건|사건 번호 17`.
- 주의: 너무 일반적 단어 금지(오발동), 캐릭터 설정/세계관과 중복·충돌 확인.
- 단축어: 이름 20자(`/`,`{`,`}` 금지), 내용 400자, 설명 30자, 최대 150개. 예: "비 내리기", "상황 요약".

## G. 크리에이터 위젯(상태창) — 「크리에이터 위젯 제작」
- 채팅창에 날짜·호감도·관계 등 상태 정보를 표시. AI(더키)로 자동 제작 또는 직접(상태값/지시사항/HTML 콘텐츠).
- 프롬프트에 직접 쓴 상태창보다 누락이 적음. 기존 프롬프트의 상태창 명령어는 위젯 적용 시 제거.
- 상태값 이름 규칙: 의미 명확, 전부 대문자 불가(`NPC`→`Npc`). 지시사항에 출력 형식 예시 지정(예: 날짜 `MM-DD`, 호감도 0~100).
- 도입부(에피소드)별 적용, **비밀 설정 글자 수와 공유**. 상태 정보 많으면 답변 길이 감소.
- 위젯 예시 테마: 로맨스(날짜/시간/호감도/관계), 판타지 RPG(위치/HP/MP/소지금), 미스터리(사건번호/단서/의심수치) 등.

## H. 사용자 별도 설명(소개 페이지) — 「사용자 별도 설명 가이드」
- 최대 **15,000자**(마크다운/HTML/공백 포함). 크리에이터 코멘트는 별도 **30,000자**. 프롬프트에 미포함.
- HTML 허용 태그: div, p, span, b, strong, i, em, br, hr, img, a. 인라인 style만. h1~h6, table, ul/ol, details, button, svg, script, class, `<style>`, @media 불가. 유튜브 embed만 플레이어 변환.
- 이미지 src는 공개 URL(케이브덕 업로드 권장). 모바일: `width:100%;max-width:640px`, 이미지 `max-width:100%;height:auto`. 본문 12~14px 이상.

## J. 케이브덕 스토리(유료 회차) — 「케이브덕 스토리」
- 캐릭터 생성 후 '스토리' 버튼 → 스토리(커버/주인공 이름/제목/설명) → 에피소드(회차, 커버/제목/설명, 무료 또는 **유료 300윙 → 크리에이터 100 인센티브**) → 스크립트(터치 1회당 텍스트, **300자/개, 에피소드당 최대 60개**, 페이지 묶음으로 장면 전환).

## K. 메모리(유저 측 기능이나 제작 설계에 중요) — 「메모리」
- 자동 요약 = 시간·장소 추적 + 전체 서사 요약(10턴마다 갱신, 최신 1개 반영, 기존 대화는 [요약 생성] 1회 수동 필요) + 현재 대화 요약(매 턴, 최대 20개 반영).
- 요약 명령어(형식 커스텀)는 고급 모델 전용. 요약 수정은 출력 글자수+100자까지.
- 캐릭터 상태: 생체 정보(심박수, 부위별 체온 1~100), 스킨십 정보(청불+성인 유저일 때 단계/분위기/서사/성향).
- 시사점: 플랫폼이 시간·장소·상태를 자동 추적하므로 프롬프트에 중복 상태창을 넣으면 충돌 가능. 위젯(G) 사용이 권장 경로.

## L. FAQ에서 제작에 쓸 팁 — 「자주 묻는 질문」
- 답변에 영어/‘thinking’/‘I can't’가 섞이면 유저노트·페르소나의 'OOC', '속마음', '생각' 키워드를 제거 → **제작자도 프롬프트에 OOC/속마음 지시를 넣으면 사고 과정 노출 위험**.
- 출력 형식 예시: `[현재 캐릭터의 상태 | YY.MM.DD | hh:mm AM]`.
- 반복 대사 → 모델 변경, 반복 답변 삭제(남기면 학습됨), 리롤.
- 이탤릭 = 속마음/행동/상황 묘사, 일반 = 실제 대사(케이브덕 관례).
