### D1. 「맛있는 봇이란 무엇인가? 봇의 프롬프트 작성법」 (characterai 166786236, 2026-04-04, 추천 88 — 키워드 검색 상위 1위)

- 원칙 1: **형용사를 지우고 조건→행동 패턴으로.** BAD `{{char}} is cold, sarcastic` → GOOD "칭찬받으면 즉시 화제를 바꾼다. 도움을 제안받으면 문장이 끝나기 전에 '괜찮아'라고 한다."
- 원칙 2: **아키타입 레이블 금지**("츤데레" 대신 고유 감정 회로 + 예외 조건 + 서브텍스트 + 비대칭 반응 + 감정 60% 억제).
- 5계층 구조(총 약 2,000토큰, 매 턴 실소비 약 1,000~1,100)
  1. **CORE ~500** (설명 상단): 앵커 문장 1줄("무엇보다도, ~하는 사람이다") / Wound = 감각이 있는 결정적 장면(“7살. 엄마가 편의점 간다고 했다…지금도 우유 냄새가 나면 현관문을 확인한다”) / Want vs Need 충돌 / 감정별 Mask·Leak 쌍 / 핵심 모순을 조건→반응→이유로.
  2. **VOICE ~300** (설명 하단 + 매 턴 앵커 1줄): Ghost Dialogue(회피·진심·상처·거짓말·궁지의 실제 대사) / 감정별 말투 변화(방어 시 갑자기 존댓말 = 벽) / Silence Rules("외로워" 대신 "요즘 집이 넓어진 것 같아") / Barks(무의식 신체 습관, 설명 없이 묘사) / Narration Lens(세상을 무엇으로 지각하나: 거리·손·출구) / Truth Budget(신뢰 단계별 감정 인정 한도).
  3. **STATE ~600** (로어북): 관계 상태 3~5개, 각 상태는 관찰 가능한 행동 마커, 전이 조건은 **유저 행동 기반**, **역행 경로 필수**(배신 시 원래보다 더 높은 벽). Scene Game(같은 밀당이 반복될수록 강도↑, 깨지는 순간이 전환점).
  4. **REACTION ~400** (로어북): 트리거 1개 = 엔트리 1개, 구조 = 사실 + 행동 반응 + 밀었을 때 + 절대 경계("쉽게 극복 금지"), 키워드 동의어 포함, 엔트리 150~250토큰. 관계 단계 전이는 키워드 트리거로 하지 말 것.
  5. **DIRECTION ~200** (매 턴 주입부 = 프롬프트 맨 끝): 규칙 나열이 아니라 **턴 알고리즘** — ① 유저 행동 인정 + 대가 ② 긴장 정확히 1단계만 ③ 감정은 행동으로만 ④ 대사와 지문의 모순 허용 ⑤ 두 번 저항·한 번 보상·새 대가 ⑥ 유저가 반응할 훅 정확히 1개 ⑦ 폭발 후 쿨다운 ⑧ 유저 행동·생각·감정 서술 금지 + 보이스 앵커 1줄.
