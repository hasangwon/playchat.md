## I. 스토리 제작 튜토리얼 필드 스펙 (9단계)
단계: **프로필 설정 → 스토리 설정 → 시작 설정 → 스탯 설정 → 미디어 → 키워드북 → 단축어 → 엔딩 설정 → 등록**
### 1) 프로필 설정
- 프로필 사진(필수): JPEG/JPG/PNG, 5MB 이하, AI 사전 검열. **썸네일 2:3 비율 권장**, 1:1은 상하 여백 블러. 내장 '스토리 이미지 생성(프로필)'.
- 이름(필수): 2~30자, 특수문자·이모지 불가. (※ 실제 홈 노출 제목엔 ｜ ： 등 특수문자 다수 → 제목 필드와 이름 필드가 다르거나 정책 변경 가능. 미확인)
- 한 줄 소개(필수): 최대 30자.
### 2) 스토리 설정
- **프롬프트 템플릿(필수)**: 기본 / 1:1 롤플레잉 / 시뮬레이션 / 생산성 / 제작자 커스텀. 상단 HUB 작성 시 동일 답변 확률 ↑ 경고.
- **스토리 설정 및 정보(필수)**: 캐릭터 말·행동에 가장 큰 영향. 외모·성격·말투·행동 규칙 구체적으로. 일부 작성 후 '자동 생성' 가능. 글자 제한 미기재.
- 고급 설정 — **예시 대화 최대 3개**(유저에게 전개 가이드 역할도 함).
- "프롬프트의 이해" 가이드 별도 존재(URL 미확보).
### 3) 시작 설정 (최소 1개 필수, '설정 추가'로 복수)
- **프롤로그(필수)** = 첫 인사말. `{{img::이미지 이름}}`로 이미지 삽입. 우측 채팅 미리보기.
- 시작설정 이름(필수): 유저가 고르기 쉽게 내용이 드러나는 이름.
- 시작 상황: 세계관 추가(예: 학창시절/대학생/결혼 이후처럼 복수 시작점).
- 플레이 가이드(선택): 유저에게만 보임.
- 추천 답변: 최대 3개, 미지정 시 AI 자동 생성.
### 4) 스탯 설정 (시작 설정별)
- 호감도·체력 등 숫자 값. **시작 설정별 최대 7개**, 이름 10자, 단위 3자, **레벨 구간 최대 4개**, 레벨별 프롬프트 100자. 최소/최대/기본값/아이콘/색상, 'AI 적용 설명'(증감 조건 구체적으로), 다른 시작 설정으로 복제.
- 예: 호감도 0~30 경계 "유저를 경계하며 거리를 둔다" / 31~60 호감 / 61~100 연인 "애교를 떨기 시작한다".
- 상태창(코드블록)과 병행 가능. 스탯은 분기 엔진, 상태창은 표시.
### 5) 미디어
- 형식 jpeg/jpg/png/webp/**gif**, 파일당 5MB, 정방형 기준(세로 긴 이미지 비권장).
- **신버전**: 1회 업로드 최대 1,000장, 작품 전체 **최대 1,600장**. 파일명 `분류_상황` 규칙으로 업로드 시 자동 분류. **배치표**(분류×상황 2축)에 등록하면 플레이 중 AI가 상황에 맞는 이미지 자동 호출. 분류에 인물·배경·사물 가능. 유저 해금 힌트, 이미지 메모(AI 미반영).
- 구버전: 시작설정별 최대 50장, `{{img::이미지 이름}}` 문법을 첫 인사말·예시 대화에 삽입, 모든 이미지에 상황 묘사 필수.
- 내장 이미지 생성 연동.
### 6) 키워드북
- 키워드 노트 **최대 20개**, 동시 활성 **최대 3개**, 상위 노트 우선. 정보(기억시킬 내용) + 키워드(트리거). 선택 항목.
### 7) 단축어
- 작품당 최대 20개. 이름 10자, 설정 30자, 프롬프트 본문 400자. `/이름`으로 유저가 호출(예: `/일기`, `/플래시백`). 키워드북(자동) vs 단축어(수동 호출).
### 8) 엔딩 설정 (시작 설정별)
- 엔딩 이미지 5MB, **카드 사이즈 1,005×1,490px**. 엔딩 등급 N/R/SR/SSR(엔딩 수에 따라 상위 등급 개수 제한: ≤2개 N/R, 3~5개 SR1, 6~8개 SR2·SSR1, 9개↑ SR2·SSR2). 엔딩 이름 20자.
- 조건: **턴 수 필수(최소 10턴, AI가 5턴마다 검사)** + 스탯 규칙(AND/OR, 단계당 7개). 프롬프트(판단 기준), 에필로그(자동 생성 가능), 엔딩 힌트. 먼저 도달한 엔딩 1개만. 엔딩 카드 수집·순위(5등 이내 배지)·댓글 공유 — 2026-04-01 개편.
### 9) 등록
- 상세 설명(필수, 제한 미기재), 장르(필수; 2차창작은 '2차창작' + **언세이프티 불가**), 타겟(필수), **대화 형태(1:1 롤플레잉 / 시뮬레이션)**, 권장 모드(필수), 권장 최대 출력량(1x/1.5x/3x/5x 일괄 또는 모드별), 공개 여부(공개/링크/비공개), **세이프티/언세이프티(필수, 등록 후 변경 불가 — 유일)**, 해시태그, 댓글 기능 on/off.
