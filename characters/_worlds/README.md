# _worlds/ — 공유 세계관

여러 작품이 같은 세계관을 쓸 때 `characters/_worlds/<world-slug>/world.md`에 1번만 쓴다(시대·장소·규칙·조직·용어·금지 사항). 각 작품의 `character.md` §3 "세계관 요약"에는 상시 필요한 요약만 두고 여기로 링크한다.
- 케이브덕: '세계관 관리' 메뉴에 등록해 여러 캐릭터가 공유(제목 60자·설명 10,000자, research/09 D-1).
- 크랙: 시리즈 기능(내 프로필 > 시리즈)으로 묶고, 오리지널 편입은 캐릭터·배경·특수 설정 공유 기준(research/10 B).
- 로어북으로 내려보낼 항목(장소·사건·용어)은 작품별 `lorebook.md`에 복사한다.
