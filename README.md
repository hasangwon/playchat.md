# make-playchat

AI 캐릭터챗(플레이챗) 작품을 **기존 플랫폼**(크랙·케이브덕·베이비챗/투킷·제타)에 올려 수익과 승인을 얻기 위한 지식 베이스 + 제작 파이프라인. 플랫폼을 개발하는 프로젝트가 아니다.

- Claude 진입점: [`CLAUDE.md`](CLAUDE.md) · 진행 상태: [`TASKS.md`](TASKS.md)
- 전체 개요·용어: [`docs/00-overview.md`](docs/00-overview.md)
- 플랫폼 비교·추천: [`docs/10-platforms/README.md`](docs/10-platforms/README.md)
- 제작 기법: [`docs/20-character-design/`](docs/20-character-design/) · 이미지: [`docs/30-image-assets/`](docs/30-image-assets/) · 운영·성장: [`docs/40-growth/`](docs/40-growth/)
- 템플릿: [`templates/`](templates/) · 작품: [`characters/`](characters/) · 조사 원본: [`research/`](research/)
- 반복 작업: `.claude/skills/new-character`, `submit-crack`, `submit-caveduck`, `submit-babechat`

작업 순서: 플랫폼 결정 → 마스터 카드 작성 → 로어북·시작 장면·예시 대화 → 이미지 → QA → 플랫폼 폼 입력(사용자 확인 후 공개) → 운영.
