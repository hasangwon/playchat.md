| 시기 | 방식 |
|---|---|

### 3-3. 노출 제한 정책 (2025-11-27 시행, 공지 6337) [공식]
홈·랭킹 비노출·검색 불이익 대상: A 성적 접촉 전제 소재(원나잇·NTR·성인용품·임신 암시·페티시 용어·"고수위" 표기) — 관계 상태·성적 지향·세계관 언급은 허용, 신혼·소꿉친구·얀데레·BL·TS·하렘 등은 단순 언급만 / B 이미지 과도 노출·비침·부위 부각·비현실 신체·성적 표정 / C 과도 폭력·혐오 / D 기타 반사회. 직접·명시적 성적 접촉은 삭제. 해제는 수정 후 검토.

### 3-4. 세이프 모드·청소년

- 미성년 크리에이터·탈퇴 크리에이터의 플롯은 언리밋 불가.

### 3-5. 기타 제재

| **노출·팬덤 확보** | 국내 MAU 최대 + 일본 유저 → 세이프티·비독점 작품을 올려 팔로워·댓글 반응을 모은다 | 10~20대·여성 65% 유저층에 맞는 작품만. 미성년 유저 비중이 높아 세이프 모드 과잉 검열 전제 |
| **크랙 오리지널 트랙레코드** | 제타 통계(노출·클릭률·전환율)와 팔로워 수를 오리지널 심사 요청서의 '작품 소개' 근거로 활용 | 단, 크랙 오리지널 지원작은 **타 플랫폼 미등록**이 조건 → 제타에 올린 작품은 오리지널 지원 불가. 제타에는 **별도 작품**(또는 오리지널 후보가 아닌 작품)만 |
| **썸네일·제목 테스트** | 통계 탭의 노출 대비 클릭률로 제목·썸네일 가설 검증 후 크랙·케이브덕에 반영 | 플랫폼별 유저층 차이 감안 |
| **콘테스트** | 총상금 1억 원급 이벤트가 열릴 때만 참여 | 비정기 |
| **파트너 프로그램** | 무료피스 보상 → 제작 테스트 비용 충당 용도 | 현금 아님 |

**금지·배제**
- 크랙 온리·케이브덕 오리지널·B Only 작품(속편·스핀오프 포함)은 제타에 올리지 않는다.
- 2차 창작·타 작품 모티브 금지(삭제·법적 리스크).
- 가족 관계 설정(의붓·비혈연 포함) 캐릭터는 반려 위험 → 제타용 작품에서는 제외.
