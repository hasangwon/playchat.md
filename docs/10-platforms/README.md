## 3. 최종 추천 순위와 이유

### 1순위 — 크랙
- **이유**: (1) 국내 최대 유저풀 → 같은 작품으로 가장 많은 유료 대화. (2) 2026-09-01부터 **최소 1만 원 현금화** — 출금 문턱이 가장 낮다. (3) **크랙 오리지널**(구매금 + 5% 현금 + 해외 단가)과 **크랙 온리**(+1%p, OOC·캬라푸 노출)로 상방이 열려 있다. (4) 회사가 창작자 정산 확대를 성장 스토리로 밀고 있어(시리즈C 1,000억, 상위 월 5,000만 원 사례 홍보) 당분간 정책이 우호적일 가능성.
- **단점**: 기본 비율 1~2.5%로 낮고 언세이프티는 1%로 하향. **크리에이터 미션(아래 5-3) 전까지 정산 0원**으로 봐야 한다. 검열봇 오탐, 계정정지 시 캐시·후원 소실 사례, 오리지널은 저작권 양도.

### 2순위 — 케이브덕 (병행 필수)
- **이유**: (1) 대화 기준 실질 4.8~6%로 **환산율 국내 최고 수준** + 이미지 잠금 30%. (2) **자격 조건 없이** 공개 즉시 적립 → 크랙 미션 달성 전 유일한 현금 흐름. (3) 월 1회 현금 출금 명문화. (4) 해외 유저 67% + 자동 번역 10개 언어 → 추가 비용 없이 해외 노출. (5) 성인 콘텐츠 자유도 → 크랙에서 비율이 깎인 언세이프티 작품의 주 수익처.
- **단점**: 최소 출금 12만 원(Opus 1만 회)까지 시간, 월 1만 크리에이터 경쟁("하루 1개 업로드"가 정석), 공식 크리에이터 신규 접수 중단(2026-09), MAU·매출 미공개, 2026-09 과금 개편 롤백 등 운영 변동.

### 3순위 — 베이비챗 / 투킷 (조건부: 비독점 남성향·여성향 성인물 추가 노출)
- 명목 적립률은 높지만 **현금 출금 불가**(상품권), 2025-12 정산 Cap·프로챗 몰수·데이터 반출 거부, 2026-05 검열 기준 비공개 → 운영 신뢰도 최하. **B Only/T Only 독점은 사용하지 않는다.** 응원하기 90%는 팬덤이 생긴 뒤에만 의미.

### 4순위 — 엘린 (관망)
- 고품질 모델·성인향 틈새, 인증 8%지만 상품권 환전만. 운영사 이관(2026-10-04) 직후.

### 노출·포트폴리오 전용 — 제타
- 정산 0원. 국내 최대 MAU·일본 유저·상세 통계(클릭률·전환율)를 **팬덤 확보·썸네일 테스트·크랙 오리지널 심사용 트랙레코드**로 활용. 세이프티·비독점 작품만. 2차 창작·가족 관계 설정 금지.

### 진입 불가·보류 — 러비더비(수익 제도 없음), 네이버웹툰·원스토어·레진(IP 전용), 글로벌(Character.AI 파산, 창작자 배분 없음)

| 크랙 온리는 대표작 1~2개만 | +1%p는 작고 실익은 세이프티 작품의 OOC·캬라푸 노출. 속편·스핀오프까지 18개월 묶이므로 **시리즈 확장 계획이 없는 완결형**만 |
| 케이브덕 오리지널은 적극 사용 | 3개월 락인·6.6배 노출·+1 인센. 케이브덕을 주 수익처로 삼는 언세이프티 작품에 기본 적용. 단, 같은 작품을 크랙에 올릴 계획이 있으면 3개월 후 해제 시점까지 대기 |
| B Only / T Only는 사용하지 않음 | 보상이 상품권이고 운영 신뢰 이슈. 베이비챗·투킷에는 비독점 작품만 |
| 독점작의 속편·프리퀄·스핀오프 | 원작과 같은 플랫폼에만. 세계관만 공유하고 캐릭터·설정이 다르면 별개 작품으로 취급 가능(케이브덕 기준; 크랙은 '시리즈 편입 심사' 대상) |
| 홍보 | 독점 기간 중 스크린샷·링크 홍보는 가능(크랙). 케이브덕 소개란에는 경쟁 플랫폼 링크 금지 |

### 4-3. 진입 장벽: 크랙 크리에이터 미션 [공식] research/10

| 단계 | 조건 | 계획 |
|---|---|---|
| 참여 조건 ① | 전체 공개 캐릭터 **10개 이상**(링크공개·비공개 제외) | 세이프티 1:1 캐릭터 10개를 초기 1~2개월 내 공개. 동일 작품을 케이브덕·제타에도 올려 반응 교차 확인 |
| 참여 조건 ② | 전체 공개 캐릭터와 대화한 사람 **누적 1,000명** | '떠오르는 신예 창작자들' 구좌(수백~수천 대화)가 신작 노출 진입점. 제목은 「상황 한 줄」형 |
| 참여 조건 ③ | 팔로워 **500명** | 댓글 응답·업데이트 공지·제타 팬덤 유입 |
| 미션 달성 | 내 캐릭터 발화 **100,000회**(미션 시작 이후 집계) | 반응 좋은 캐릭터를 스토리로 확장(고가 모드 소모 → 정산 증가는 뱃지 이후부터) |
| 뱃지 이후 | 정산 시작(1.5%/1%) + 선물 90% + 오리지널·온리 신청 자격 | 보존해 둔 오리지널 후보 제출 → 결과 30일 대기 → 탈락 시 온리 전환 |

- 뱃지 전까지 크랙 수익은 0원으로 계획. 이 기간 현금 흐름은 **케이브덕**에서 만든다.
- 미션 집계가 "캐릭터" 기준 문구이므로 스토리 작품이 포함되는지 미확인 → 안전하게 캐릭터 10개로 충족.

### 4-4. 공통 가드레일 (CLAUDE.md 6장 재확인)
- 전원 성인 + 나이 명시 + 성인 외형·직업·배경. 교복·학교·학원·아이돌 연습생 배경 금지(크랙·케이브덕·베이비챗 모두 "설정상 성인이어도 미성년 간주").

- 2차 창작 금지(크랙 정산 제외·언세이프티 불가·오리지널/온리 불가, 제타 삭제 리스크, 케이브덕 수익화 제한).

- 상태창은 답변 **최하단**(크랙 HUB 가이드·베이비챗 info 관례). 케이브덕은 위젯 사용.
