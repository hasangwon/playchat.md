## 4. 심사·운영정책 요약 [공식] 운영정책 2026-06-30 시행, research/10 D·research/02 §1.6

### 4-1. 심사 방식
- **사전 심사 제도 없음** → 등록 즉시 공개. 등록 시 이미지 AI 사전 검열 + 자체 검열봇, 등록 후 사후 검토. 등록 거부 시 "필수값 누락 또는 성적 표현·욕설 점검" 안내.
- 오리지널 투고 시에만 1차(정책)·2차(정성) 심사.
- 적용 범위: 이름·소개·설정·프롬프트(텍스트) + 프로필 이미지 + 상황별 이미지 전부.
- 위반 시 **사전 안내 없이** 세이프티/언세이프티 전환, 비공개, 대화 제한.

### 4-2. 공통 금지 (세이프티·언세이프티 공통)

| 원칙 | 핵심 내용 |
|---|---|
| 미성년자 보호 | 실제 나이 설정 무관. 신체 발달·복장(교복·체육복)·소품·배경(학교·학원·학생회·아이돌 연습생)을 **종합해 미성년자로 보이면 미성년자 간주** → 성적 묘사·학대 일체 금지. 경고 없이 최고 수준 제재 |
| 불쾌·혐오 | 극사실 고어, 집단 혐오 금지 |
| 악용 가능 | 불법 약물·범죄·자살 미화 금지 |
| 플랫폼 목적 저해 | 맞팔·좋아요 어뷰징, 무의미 캐릭터(프롬프트 없음), 스팸·피싱·홍보, 운영진 사칭 금지 |
| 권리 침해 | IP·초상권·개인정보 침해, 딥페이크, 실존 인물 연상 실사 금지. **2차 창작은 원작 가이드라인 준수 + 세이프티로만** |
| 불법 콘텐츠 | 금지 |

### 4-3. 세이프티 vs 언세이프티 (텍스트)

| 등급 | 금지 | 허용 |
|---|---|---|
| 세이프티 | 성적 행위·암시, 성적 부위 단어, 성인용품 단어, 고어·범죄·자해 미화, 비속어 남용 | — |
| 언세이프티 | 성범죄·비동의·수간·시간 등 위법/극도 음란 묘사, 체액·배설물의 성적 활용, 목적 없는 고어, 차별·혐오 | 캐릭터 성격용 일반 비속어 |

- 세이프티/언세이프티는 **등록 후 변경 불가**(스토리 등록 단계). 성인 컨셉은 언세이프티 설정 필수 → 성인 인증 유저만 열람.

### 4-5. 2차 창작 [공식] 공지 2025-10-13, research/02 §1.6
