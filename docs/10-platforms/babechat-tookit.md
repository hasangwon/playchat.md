## 2. 수익 구조

### 2-1. 크리에이터 클럽 등급표 (2025-10-03 시행, 소급) [공식] research/01 §3-2, research/02 §3.3

| 등급 | 조건: 전체 공개 캐릭터 / 누적 유료 채팅 / 팔로워 | 응원하기 정산률 (베이비챗) | 응원하기 (투킷) | 베리 적립 일반 | 베리 적립 B Only / T Only | 2026 한정 달성 보너스 |
|---|---|---|---|---|---|---|
| 베이비 | 1개 / 1,000회 / 10명 | 70% | 70% | 10% | 28% | — |
| 루키 | 2개 / 10만 / 100명 | 75% | 75% | 10% | 30% | 1만 프로챗 |
| 슈퍼 | 2개 / 50만 / 200명 | 80% | 80% | 11% (문서 간 10/11% 불일치) | 32% | 5만 |
| 메가 | 3개 / 300만 / 500명 | 85% | 85% | 12% | 34% | 30만 |
| 하이퍼 | 5개 / 500만 / 1,000명 | 90%(표) / 85%(본문) 불일치 | 85% | 13% | 37% | 50만 |

- 무료 모델 대화는 채팅 수에서 제외. 마이 > 크리에이터 클럽에서 순서대로 '획득하기'.
- 베리 제도 구버전 문서엔 B Only 11/11/14/17/20%로 기재 → 2026 현행 공식 표는 28~37% [공식] research/01.

### 2-2. 베리(Berry) [공식] 「인센티브: 베리 제도」 research/02 §3.3
- 유저가 **구매한 프로챗**으로 내 캐릭터와 대화한 사용량 × 적립률 (무료 프로챗·메모리+ 소모 제외). **본인 대화도 적립**.
- 작품별 **대화 500회 도달 시 활성화** (누적분 일괄 지급).
- 신작(전체 공개 후 30일) B Only **+10%p**. 투킷은 문서에 "+3%p" 표기와 "+10%p" 예시가 불일치 → 미확인.
- 소멸: 적립 1년 후 익월 1일. 휴면·탈퇴 시 즉시 소멸.
- 지급 정지: 장기 미활동, 비공개·링크공개만 유지, 도용·저작권 침해, 정책 반복 위반, 다중 계정 등 부정 사용(취소+법적 조치). "타 플랫폼 중복 게시 비권장".

### 2-3. 환전 — **현금 직접 출금 없음** [공식]

| 경로 | 조건 | 비고 |
|---|---|---|
| 베리 → 프로챗 | **10베리 = 1프로챗**, 최소 5,000베리, 1년 유효 | 플랫폼 내 재투자용 |
| 베리 → 베리샵(2025-12-23 오픈) | **11베리 = 1BP(베리포인트)**, 베이비 등급 이상 + **한국 휴대폰 본인인증** 필수 | 상품권·네이버포인트 등 교환. **1BP의 원화 가치 공식 미확인**(1원 가정) |

**현금 환산 [추정] research/01**: 프로챗 ≈ 0.98원 → 일반 10% 적립 × 11:1 환전 ≈ 유료 사용액의 **약 0.9%** 상당 상품권, B Only 37%면 **약 3.4%**. 즉 명목 "28~37%"는 베리 기준이며 상품권 환산 시 크랙(1~2.5% 현금)·케이브덕(5~6% 현금)과 비슷하거나 낮다.

### 2-4. 응원하기(후원) [공식]
- 유저가 **구매 프로챗**으로 캐릭터/크리에이터 페이지에서 후원, **최소 1,000프로챗**. 등급별 70~90% 적립(수수료 10~30%; 나무위키는 "후원 수수료 30%" 비판 [커뮤니티]).
- 팬덤이 생기면 베리보다 응원이 큰 수익원이 될 수 있으나 역시 베리로 적립 → 상품권.

### 2-5. 공식 크리에이터 [공식] + [커뮤니티]
- **운영진 초청제**(메가·하이퍼 우선 검토, 수치 기준 없음). 공식 뱃지, "업계 최고 수준 특별 정산 비율"(수치 비공개), 글로벌 런칭 우선 지원·IP 사업 협상 우선권.
- [커뮤니티] **월 정산 한도(Cap) 100만 원** 계약 존재 주장 (2025-12 폭로, 7장 참고). 공식 수익 사례 없음.
- 투킷 공식 크리에이터: **T Only 독점 파트너십 초대제**, 일본 우선 글로벌 진출·IP 사업화 지원. X 공지: 작품 이식 시 3주 메인 배너 + **작품당 현금 30만 원**, 캐릭터 공모전 총 5,500만 원 — 진행 여부 미확인 [공식 X, research/02 §4].
- 홈 배너 "선정작 50만 캐시 지원" 공모/선정 이벤트 존재(2026-10-21 실측, research/07) — 조건 미확인.

### 5-1. 변수·포맷팅 [공식] 「프롬프트 포맷팅과 변수 [심화]」, 「프롬프트 가이드라인 [기초]」(2025-08), research/02 §3.2
- 변수: `{{char}}`(이름 필드 값), `{{user}}`(유저 페르소나 닉네임). **한 겹 `{char}`는 인식 안 됨.** 시뮬레이션형(캐릭터=상황)에서는 `{{char}}` 대신 주체 명시 권장.
- 포맷: **마크다운 권장**(헤더·목록·대괄호), XML 고려 가능, JSON 비권장. 캐릭터 상세 설정은 헤더 단계 자유, **페르소나·로어북은 `###`부터**(메인 설정 하위로 인식).
- 작성 원칙: 시점·서술·표현을 구체적으로 지정, [캐릭터 정보]/[출력 지시] 분리, 과도한 동시 지시(스탯 계산+다인 연기+이미지) 지양, **글자수 지정("500자 이상")은 시스템 프롬프트와 충돌 → 묘사 깊이로 지정**.
- 이미지: 내부(`img:[slug]`) / 외부 URL 중 **한 방식만**. 미사용 이미지 제거. 키워드 유도 문구(`img: 비비 슬픈 표정`) 금지.

### 5-2. `img[ID]` 문법과 info 상태창 관례 (상위 캐릭터 실측) [공식 화면] research/07
'이안' 캐릭터 첫 메시지 구조:
```
<서술 문단 — 3인칭 소설체, 상황·행동 묘사>
이건우 | "대사"
<서술>
img[499y1] 이안 | "대사"        ← 메시지 중간 이미지 삽입 img[ID] + `이름 | "대사"` 포맷
<서술>
info 🗓2024년 1월 15일 | (월요일) ⏰️현재 시간 오후 2시 10분 🧒이안 / …
🥼A의 복장 … 🥼B의 복장 … 🗺A의 위치 … 🗺B의 위치 … 💫현재 상황 …
```
- 메시지 끝 **`info` 블록 상태창**: 날짜/시간/캐릭터 스펙/양측 복장/양측 위치/현재 상황을 이모지 라벨로 구조화 — 몰입·연속성·기억 보조 관례. (크랙의 "상태창은 최하단" 권장과 일치.)
- 멀티 캐릭터(이건우+이안) 등장, 유저 이름은 페르소나 치환.
- 공식 가이드 표기는 `img:[slug]`, 실측 출력은 `img[499y1]` → 입력 문법과 출력 표기가 다를 수 있음. 에셋 탭에서 실제 slug 형식 확인 필요(미확인).
- 주의: 실측 캐릭터는 10세 아동 설정(미성년 캐릭터 존재는 가능하나 성적 대상화 금지). 본 프로젝트는 미성년 설정 자체를 배제.

### 5-3. 유저 측 설정 (제작 설계 시 고려) [공식 유저 가이드]·[커뮤니티]
페르소나 **1,000자**, 유저노트 **2,000자**(2026-06 확장 시 4,000자, 대화당 10프로챗 추가), 채팅방당 유저노트 1개, 대화 자동 요약 → 유저노트 생성.

### 5-4. 투킷 차이점 [공식] docs.channel.io/tookit, research/02 §4
- 제작 폼 구조 동일. **캐릭터 소개 최대 250자**(베이비챗 500자)만 다름. 나머지(이름 20자, 상세 7,000자, 에셋 100개·512×768, 시작 시나리오 3개, 로어북 100/5/500자/키워드 5개, 테스트 10회) 동일.
- 보상: 베리 일반 10~13% / T Only 28~37%, 응원 70/75/80/85/85%, 500회 활성화, 10:1 프로챗, 11베리=1BP. 신작 +3%p 표기 vs +10%p 예시 불일치.

## 9. 미확인 / 다음 확인 항목
1. 제작 폼 2~6단계 실측 — 동의 모달("캐릭터 제작 시 유의사항 → 동의하고 캐릭터 제작하기") 통과는 **사용자 확인 후** 진행 (TASKS.md 사용자 확인 필요 항목).
2. 로어북 저장 상한(50 vs 100), 상시 적용 옵션 유무.
3. 시작 상황 탭의 '첫 대화 날짜'·'상황묘사' 필드 존재 여부와 글자 제한.
4. 에셋 slug 실제 형식(`img:[slug]` vs `img[499y1]`), 표정/상황 이미지의 공개/비공개 효과.
5. 커스텀 템플릿 사용 시 프롬프트 글자수(6,000 vs 7,000).
6. 1BP의 원화 가치, 베리샵 상품 목록·최소 교환 단위.
7. 공식 크리에이터 "특별 정산 비율" 수치와 Cap 존재 여부.
8. 투킷 신작 보너스(+3%p vs +10%p), 투킷 공모전·이식 지원금 진행 여부.
9. "선정작 50만 캐시 지원" 공모 조건.
10. 2차 창작·AI 생성 이미지 공식 정책.
