### 2-3. 환율·출금 조건 [공식] research/09 A-3

| 항목 | 내용 |

**현금 환산 [추정] research/01·09**

## 4. 제작 규정·심사 요약 [공식] 「캐릭터 제작 규정」 research/09 C

### 4-1. 심사 방식
- **사전 심사 없음**. 사후 모니터링·신고(누구나 가능) 기반. 이의는 고객센터. 댓글 신고 누적 시 자동 숨김.
- 조치(사전 안내 없음): 캐릭터 → 청소년 이용 불가 강제 변경 / 수익화 제한 변경 / 비공개 / 차단 / 삭제. 크리에이터 → 공개 제한.
- 검열로 미생성된 채팅의 재화 반환 기능 2026-09-22 추가. Claude 5·Gemini 3.7 계열은 검열이 심하다는 평 [커뮤니티] research/01.

### 4-2. 미성년 판단 기준 (가장 중요)
- **19세 미만으로 인식될 수 있는 캐릭터는 설정상 성인이어도 불가.** 아래 중 하나라도 있으면 미성년자로 간주:
  - 교복/학생복
  - 교실·학교가 주 배경 (폐교·과거 고등학교 배경도 불가)
  - 외형·말투·행동이 미성년으로 보임
- 중·고교 교사 직업은 가능하나 학교/학생이 주 설정이면 불가. 교실 배경 대학생은 **성인 외형 + 성인 설정 명시** 시에만 허용.
- **언세이프 캐릭터에는 미성년 등장인물 포함 불가.**
- 인간형 캐릭터의 어린 시절/육아/보호 설정 불가(인외 캐릭터만 조건부 예외 + "미성년/육아 대상과 성적 상호작용 불가" 지침을 프롬프트와 설명에 필수 기재).

### 4-3. 전체 금지 항목
| 분류 | 내용 |
|---|---|
| 실존 인물 | 성적 묘사 금지. 실존 인물 기반은 **전체 이용가 + 수익화 제한** 필수. 타인 저작권 포함 시 수익화 제한 필수, 권리자 요청 시 비공개 |
| 범죄 | 불법촬영물, 성매매 알선, 강간·윤간 노골 묘사, 범죄 미화·방법 상세, 적십자 마크 |
| 도덕 | 사회적 약자 비하·학대, 잔혹 신체 손상, 자살 미화, 차별·편견, 도박 조장, 수간 |
| **근친** | **혈연 근친 설정 등록 불가.** 의남매·법적 가족·소꿉친구 등 비혈연은 **비혈연임을 명확히 기재** 시 허용 |
| 기타 | 무의미하거나 다수 중복되는 설정 |

### 4-4. 세이프티(청소년 이용가)에 넣으면 안 되는 것 → 하나라도 있으면 '청소년 이용 불가' 체크 필수
성행위 묘사/암시, 성매매 관련 설정(매춘부·유흥업소), 유혹·접대·밤 상대 표현, 페로몬·최면·강제 유혹 장치, 체액 표현, 특정 신체 부위(발 포함) 과도 강조, 성기 지칭 단어.

### 4-5. 이미지 가림·노출 기준
| 구분 | 기준 |
|---|---|
| 세이프티 | 성적 암시 금지(표정·자세 포함). 수영복·운동복 일반 노출은 허용, 부위 강조·시선 유도 포즈는 제한. **실사/실존 인물로 보이는 이미지는 'AI 제작' 명시 필수**(운영자 강제 적용 가능) |
| 언세이프 | 등장인물 전원 19세 이상 외형. 치비(SD)는 비성적 용도만. 직접 성행위·성기 접촉·성기 노출 이미지는 **대표 이미지 불가**(의상 착용해도 불가). 여성 유두 노출 불가 |
| 앨범 이미지 | 성기·음모·항문은 **불투명 유색(흰/검)으로 가림** 필수. **모자이크·블러·시스루·피부색 가림 불가**. 인체 모방 성인용품·촉수 가림 기준 별도 |

## 11. 미확인 / 다음 확인 항목 (로그인 후 확인)
1. 대표 이미지 규격·용량·비율, 한 줄 소개 글자수.
2. 시작 대사 텍스트 내 이미지 삽입 문법(UI 첨부만인지, 텍스트 문법이 있는지).
3. 크리에이터 통계 화면(캐릭터별 대화 수·수입 대시보드) 존재 여부.
4. 공식 크리에이터 선정 조건·재개 시점.
5. 출금 지급 수단(계좌/USDC)·세율·본인확인 절차.
6. 제작 화면의 토큰 카운터 권장치(2,000 vs 5,000/8,000).
7. 카드의 두 번째 숫자(좋아요 vs 이미지 수)의 의미.
8. 아트 스튜디오 생성 이미지의 상업 이용·타 플랫폼 사용 라이선스.
9. 공모전 필터의 현재 진행 공모전과 조건.
