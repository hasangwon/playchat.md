# 00. 프로젝트 개요 — 목적·범위·용어·워크플로우

> 근거: research/01, 02, 09, 10 (2026-10-21). 플랫폼별 상세는 `docs/10-platforms/`, 제작 기법은 `docs/20-character-design/`.

## 1. 목적
기존 AI 캐릭터챗 플랫폼에 **수익이 나고 승인(노출·선정)되는 작품**을 꾸준히 올린다. Claude는 기획·집필·이미지 브리프·폼 입력을 맡고, 사용자는 로그인·최종 제출·결제·정책 동의를 맡는다.

## 2. 범위
- **한다**: 플랫폼 조사·비교, 캐릭터/스토리 기획과 본문 집필, 로어북·시작 장면·예시 대화, 이미지 에셋 브리프와 프롬프트, 플랫폼 폼 입력(브라우저), 출시 후 반응 분석·수정.
- **하지 않는다**: 플랫폼/앱 개발, 사용자 계정 생성·로그인, 약관 동의·최종 공개 버튼·결제 클릭(사용자 확인 전), 미성년·실존 인물·타 IP 2차창작 작품.

## 3. 2026-10 기준 핵심 결론 (상세: docs/10-platforms/README.md)
| 순위 | 플랫폼 | 이유 | 전제 |
|---|---|---|---|
| 1 | **크랙**(뤼튼) | 유저풀 최대급, 2026-09-01부터 캐시 현금화(최소 1만원), 오리지널(판권 구매금 + 유료 크래커 5% 현금), 온리(+1%p, 해외 OOC·캬라푸 노출) | 정산은 **공식 크리에이터**부터 실질적: 공개 캐릭터 10개 + 대화자 1,000명 + 팔로워 500 → 발화 10만 회. 기본 비율 1~2.5%로 낮음 |
| 2 | **케이브덕** | 대화 1회당 모델별 고정 인센티브(Opus 20 = 12원), 월 1회 현금 출금(최소 12만원), 이미지 잠금해제 50% 배분, 해외 유저 67%, 검열 가장 느슨 | 최소 출금 20만 인센티브. 하루 1개 꾸준한 업로드가 수익의 핵심(커뮤니티) |
| 3 | 베이비챗/투킷 | 명목 적립률 높음(B Only 28~37%) | **현금 출금 불가**(상품권 환전), 2025-12 정산 Cap·2026-05 검열 논란. 남성향/여성향 성인 니치에만 제한적 사용 |
| 4 | 제타 | MAU 최대, 노출 가치 | 창작자 현금 정산 없음, AI 자동 심사, 저작권 소송 중 → 포트폴리오·노출용 |
| — | 네이버웹툰·원스토어·레진 | 공식 IP 전용 | 일반 창작자 진입 불가 |

## 4. 표준 워크플로우 (작품 1개 기준)
```
① 플랫폼·장르 결정 ─ docs/10, docs/40/01-trends
② 기획            ─ templates/character.master.md → characters/<slug>/character.md
③ 본문            ─ 배경 → 프롬프트 → 로어북 → 시작 장면(1~3개) → 예시 대화   (docs/20)
④ 이미지          ─ templates/image-brief.md → assets/ (프로필·배경·표정·상황·인트로 컷) (docs/30)
⑤ 자체 QA         ─ docs/20/08-testing-qa.md 체크리스트, 플랫폼 테스트 채팅
⑥ 제출            ─ templates/platform-mapping.md로 변환 → .claude/skills/submit-<플랫폼> → 사용자 확인 후 공개
⑦ 운영            ─ 출시 72시간 홍보, 댓글 대응, 수정, status.md 기록 (docs/40)
```
- 마스터 카드 1개 → 플랫폼별 변환. **플랫폼마다 따로 집필하지 않는다.**
- 세이프티 버전을 본진으로 쓰고, 언세이프티는 성인 유저용 파생본으로 분리한다(크랙 등록 후 등급 변경 불가, 2차창작은 언세이프티 불가).

## 5. 용어 사전 (플랫폼 간 대응)
| 우리 용어 | 크랙 | 케이브덕 | 베이비챗/투킷 | 제타 |
|---|---|---|---|---|
| 작품 | 스토리 / 캐릭터 | 캐릭터 (+세계관, 스토리) | 캐릭터 | 플롯(캐릭터) |
| 프롬프트(설정) | 캐릭터 프롬프트 / 스토리 설정 및 정보 | 캐릭터 설명 + 세계관 + 문체 프롬프트 + 비밀 | 캐릭터 상세 설정 | 설명(프롬프트) |
| 시작 장면 | 시작 설정(프롤로그·시작 상황·이름) / 인트로 | 에피소드(시작 대사·비밀) | 시작 시나리오(첫 상황·첫 대사) | 인트로 |
| 로어북 | 키워드북(키워드 노트) | 키워드북(기본 키워드) | 로어북 | 설정집 |
| 단축어 | 단축어 `/이름` | 키워드북 단축어 | — | — |
| 상태창 | 코드블록 상태창 / 스탯 | 위젯 | info 블록(관례) | 상태창(스타일 탭) |
| 유저 설정 | 대화 프로필·유저노트 | 페르소나·유저노트 | 페르소나·유저노트 | 대화 프로필 |

| 유료 재화 | 크래커 | 윙(유료)·깃털(무료) | 프로챗 | 피스 |

| 변수 | `{{user}}`, `{{img::이름}}` | `{{user}}`, `{{char}}` | `{{user}}`, `{{char}}`, `img:[slug]` | 미확인 |
