# 07. 사례 연구 — 플랫폼별 상위 작품 분석 (장르·훅·구조·왜 잘 됐나)

## 0. 공통 패턴 (먼저 읽기)
1. **제목이 곧 플레이 약속**: "내가 누구이고 무슨 상황인지"가 제목에서 끝난다(크랙 1인칭형, 케이브덕 `이름 | 상황 "대사"`).
2. **구조가 발화를 만든다**: 시뮬레이터(스탯·분기), 군상극(조연이 사건을 계속 공급), 미션형(호감도 목표)이 1:1 잡담보다 오래 간다.
3. **작가 단위 연작**: 상위 작가는 세계관을 공유하는 작품을 여러 개 보유해 팔로우·시리즈 효과를 누적한다.
4. **세이프티로 상단을 잡는다**: 크랙 메인·오리지널·매입 대회 모두 세이프티 서사형이 올라간다.
5. **카드 수치의 자릿수**: 신예 수백~7K → 트렌드 7K~70K → 공식 신작 4K~13K → 베스트 수십만 → 오리지널 수백만~18M(research/06 **[확인]**). 케이브덕 #Original 상위 3.7k~116.5k, 일반 평균 161(research/08·09 **[확인]**).

## 1. 크랙

### 1-1. 국가의 시대 (caaat) — 18M, 오리지널 전용관 1위
- **장르**: 국가 운영 시뮬레이션(세이프티). 같은 작가의 초능력 학교 5.7M, 초능력 학교：NOVA 1.7M.
- **훅**: "내가 통치자"라는 역할 부여 하나로 유저마다 다른 플레이가 나온다.
- **구조(실측에서 읽히는 것)**: 유저가 통치자로서 무한 분기 플레이, 시리즈로 재방문 유도, 오리지널 전용관 상시 노출(research/05 §7 **[확인: 06 실측]**).
- **왜 잘 됐나**: ① 시뮬레이터는 '정답 플레이'가 없어 재플레이·발화가 길다 ② 크랙 '시뮬레이션' 장르 탭이 따로 있어 탭 유입이 상시 ③ 오리지널 선정으로 전용관 노출·공식 홍보 ④ 작가 연작(학교 시뮬 2종)으로 팔로우 재방문.
- **우리 적용**: 니치 #2(국가·조직 운영 시뮬레이터 + 엔딩, → `01` §6). 스탯은 7개 이하, 턴 이벤트, 엔딩 카드로 재플레이.

### 1-2. 루멘시아 아카데미 (Pora) — 10.3M / 아스트라 전기 4.3M
- **장르**: 로판 아카데미 군상극 / 판타지 서사. 동일 작가 복수 오리지널.
- **훅**: 아카데미(입학·학년·시험·대회)가 이벤트를 자동 공급하는 무대.
- **구조**: 아카데미 군상극 + 세계관 연작(research/05 §7 **[확인: 06 실측]**).
- **왜 잘 됐나**: ① 아카데미는 조연 다수·행사 일정이 있어 군상극 소재가 고갈되지 않음 ② 로판 수요(크랙 장르 탭 '로판', 여성 인기 탭) ③ 같은 세계관 2작 이상으로 작가 팔로우.
- **우리 적용**: 니치 #3(성인 아카데미 군상극). 미성년 기준 때문에 **성인 아카데미(나이 명시)** 로 설계, 조연 3명 이상 로어북.

### 1-3. 게임 판타지 속 히든 클래스가 되다 (메테르) — 317.5K, 베스트 랭킹 1위
- **장르**: 게임판타지(웹소설 문법 그대로).
- **훅**: "히든 클래스" — 웹소설 독자가 즉시 기대치를 세우는 키워드.
- **구조**: 웹소설 독자 문법 그대로(research/05 §7 **[확인: 06 실측]**).
- **왜 잘 됐나**: ① 18M 오리지널보다 위에 있다는 것은 랭킹이 기간 가중이라는 뜻 → 신작도 베스트 1위 가능(**[추정]**) ② 웹소설 독자층이 크랙 10~30대와 겹침 ③ 성장(레벨·클래스) 구조가 발화를 늘림. 같은 계열: 탑 등반물의 히든 NPC가 되었다 480.8K, 이번 생은 소환수입니다만 262.6K, 청명 헌터 기숙학원 278.4K.
- **우리 적용**: 세계관에 성장 축(등급·클래스·스탯) 1개를 넣는다. 단 타 웹소설 고유명사 차용 금지.

### 1-4. 내가 키운 제자들에게 집착받는다 — 34.6K (트렌드 4위·베스트 9위) / 남미새 부수기 (빈찬합) — 69.5K (트렌드 2위·베스트 3위)
- **장르**: 집착·육성(여성향 추정) / 현대 관계 갈등.
- **훅**: 관계 명사(제자·남미새) + 반전 동사(집착받는다·부수기) 한 줄. 유저의 역할(스승·응징자)이 제목에서 정해진다.
- **구조(추정)**: 육성 → 역전(집착) 구조는 호감도 축적형, '부수기'는 "공공의 적" 응징 구조(제타 제작자 체감과 일치, research/05 §1-2 **[커뮤니티]**).
- **왜 잘 됐나**: ① 감정 갈등형(집착·혐관·질투)이 크랙에서 소구(research/05 §1-1 **[커뮤니티]**) ② 단기 트렌드와 누적 베스트에 동시에 있음 = 신작이면서 재방문이 높음 ③ 제목만으로 플레이 목표가 보임.
- **우리 적용**: 니치 #3·#6. 제목 규칙(관계 명사 + 반전 동사, `01` §2-1).

### 1-5. 계시록 REVELATION (힉힉) — 오리지널 집중 매입 최우수(3,000만 원)
- **장르**: 심리 스릴러(세이프티).

- **우리 적용**: 니치 #1(세이프티 심리 스릴러 군상극)을 오리지널 투고용 미공개작으로 제작. 고어 대신 암시, 단서·의심 수치 상태창.
