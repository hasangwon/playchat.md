## 2. 응답 관례

### 2-1. 고정 댓글 용도(공개 직후 작성)
- **크랙(1개)**: ① 플레이 팁 2줄(권장 모드·출력량 1.5x, 시작 설정 선택) ② 기억·길이 문제 시 유저노트 지침 한 줄 ③ 최근 업데이트 1줄 ④ "팔로우하면 신작이 목록 상단에 뜹니다"(팔로우 시 상단 노출, research/05 §2-1 **[커뮤니티]**) ⑤ 같은 세계관 작품 링크.
- **케이브덕(5개)**: 1 세계관·인물 관계 보충 / 2 FAQ(기억·답변 길이·권장 모델) / 3 이미지 잠금·유료 회차 안내(있을 때) / 4 업데이트 로그 / 5 리뷰 이벤트·연작 안내(`#케이브덕` 후기 쓰면 깃털 보상, research/09 §M **[확인]**).
- 2026 관례: 케이브덕 제목·한줄소개에 `[01/08 updated]`처럼 갱신일 표기(research/08 **[확인]**).

### 2-2. 답글 원칙(이 프로젝트 규칙, **[추정]** 포함)
- 공개 72시간은 2시간 간격, 이후 1일 1회 확인. 답글은 짧게, 유저 호칭 통일, 캐릭터 말투로 답하지 않는다(혼동 방지).
- 불만 댓글은 삭제하지 않고 고정 댓글 FAQ로 흡수한다. 같은 불만 2건 이상이면 작품 수정 트리거(§3).
- 악성 댓글: 크랙은 신고 1회(부당 신고 남발은 제재 대상 **[확인]**), 케이브덕은 신고 누적 자동 숨김 + 크리에이터 차단(50명 한도 **[커뮤니티]**).
- 홍보 캡처는 리롤 없이 평균 품질로 올린다. 유저는 "허위매물"(잘 나온 결과만 올린 캐릭터)·"찐빠"(기억상실·반복·순간이동 등 AI 실수) 같은 용어로 리뷰를 남긴다(research/05 §3-2 **[커뮤니티]**).
- 피카부 관행: 플레이 캡처를 함께 올려 반응을 미리 보여주고, 성과 압박에는 "내가 소비자로서 즐기고 싶은 것"으로 회귀(research/05 §3-3 **[커뮤니티]**).

### 4-2. 수정 절차(체크리스트)
1. [ ] 수정 전 원본을 `characters/<slug>/versions/vN/`에 복사(베이비챗 정지 시 데이터 반환 거부 사례 → 로컬이 원본, research/05 §3-4 **[커뮤니티]**).
2. [ ] **한 번에 하나만** 바꾼다(프롬프트·로어북·첫 메시지 중 1곳). 변경 사항과 이유를 `status.md`에 1줄.
3. [ ] 테스트 챗: 크랙 채팅 미리보기, 베이비챗 제작 화면 테스트 10회(research/07 **[확인]**), 케이브덕 본인 대화(인센 미지급이므로 테스트 용도로만). 새 방 + 기존 방 이어서 둘 다 확인.
4. [ ] 공개 전 자가 검수: 뤼여갤 '캐릭터 테스트 젬'·'프롬프트 검수 프롬프트'(research/05 §3-3 **[커뮤니티]**) 또는 `docs/20-character-design/08-testing-qa.md`.
5. [ ] 크랙 업데이트 노트 작성 → 고정 댓글 갱신. 케이브덕 고정 댓글 4번(로그) 갱신 + 한줄소개 `[MM/DD updated]`.
6. [ ] 불만을 남긴 유저 댓글에 "vN에서 반영했습니다" 답글.
