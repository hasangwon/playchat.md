2. 관계 명사 1개 + 반전 동사 1개. 세계관 이름만 있는 제목(예: "아스트라 전기")은 오리지널·시리즈가 있을 때만 통한다.
3. 크랙 세이프 버전에만 `S` 접미, 언세이프 파생본은 무표기(→ `02` §5).
4. 케이브덕은 `이름 | 상황 "대사"` + 한줄소개에 수치.
5. 제타 이식본은 캐릭터명 제목 + 소개문에 상황.

### 2-2. 한줄소개
- 크랙: 30자 필수(research/05 §2-1 **[확인]**). 한 줄에 "관계 + 상황 + 긴장"을 넣는다.
- 케이브덕: `"대사 한 줄." + 상황 요약 + 구체 수치`(research/08 **[확인]**). 대괄호 메타 태그 관례: `[👤24+]`(연령/대상), `[👤N명]`(등장 수), `[BL]`, `[입헌군주제]`, `[MM/DD updated]`, `SFW`. `{{user}}` 변수도 한줄소개에 쓰인다.
- 베이비챗: 캐릭터 소개 최대 500자, 자동 생성 버튼 있음(research/07 **[확인]**) — 자동 생성은 초안용으로만.

### 2-3. 태그·필수 필드
- 크랙 등록 필수: 장르(2차창작은 '2차창작' + 언세이프티 불가), 타겟(남/여), 대화 형태(1:1 롤플레잉 / 시뮬레이션), 권장 모드, 권장 출력량, 세이프티/언세이프티(등록 후 변경 불가), 해시태그(research/10 §I-9 **[확인]**).
- 케이브덕: 순애/집착/얀데레 등 세분 태그(**[커뮤니티]**), 오리지널 태그 자동 부여(**[확인]**).
- 제타: 해시태그 검색이 추천에 반영(**[커뮤니티]**).
- 조합 권장(**[추정]**): 장르 1 + 관계 1 + 감정 1 + 형식 1(예: 로판 / 소꿉친구 / 집착 / 군상극). 플랫폼 장르 탭 이름과 같은 단어를 쓴다.
