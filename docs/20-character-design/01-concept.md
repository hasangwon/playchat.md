## 1. 잘 되는 컨셉의 4원칙 [종합, research/03 1-1]

1. **설정보다 상황(훅)이 팔린다.** 노출면에서 "내가 뭘 하게 되는지"가 보여야 한다. 포스타입 공식: "캐릭터의 매력이 잘 드러나는 문구일수록 대화 시작이 늘어난다" [공식].
2. **유저 중심으로 짠다.** "AI는 캐릭터보다 유저를 우선시하므로 유저를 중심으로 짜야 캐붕·오류가 줄어든다" [커뮤니티, 제타 여성향갤 15348].
3. **단순·직관적일수록 인식률이 좋다.** "소재가 직관적이고 단순할수록 AI의 인식률과 대화 흐름이 좋아진다. 억지로 스토리를 유도하면 반응이 어색해진다" [커뮤니티, 케이브덕 채널 94746023]. 며칠 고민한 캐릭터보다 냅다 만든 캐릭터가 히트하는 자조적 관찰도 같은 맥락 [커뮤니티, 제타 여성향갤 5986].
4. **첫 흐름이 재미없으면 끝까지 안 한다.** 시작 상황이 원하는 스토리로 유도되도록 설계 [커뮤니티, 뤼튼갤 42661].

실무 해석: **한 문장으로 말해지는 상황 + 유저가 맡는 역할 + 캐릭터의 한 마디**가 나오지 않으면 컨셉이 아직 없는 것이다.

### 2-3. 관계 곡선을 먼저 정한다 [종합]

여성향은 "관계 변화 곡선"이 상품이다(철벽→호감, 혐관→순애, 후회·집착·연하·다정). 곡선의 **시작점·전환 조건·끝점**을 컨셉 단계에서 적어야 `03-persona-prompt.md`의 관계 단계 블록과 `02-world-background.md`의 조건·분기가 나온다.

```
관계 곡선: 혐관(존댓말·거리) → 어색한 농담(조건: 단둘이 밤, 다그치지 않을 때) → 옛 반말(조건: 떠난 이유를 유저가 먼저 짐작)
```

### 4-2. 실측 제목 패턴 3종

**① 크랙 '상황 한 줄'형** [실측, research/06] — 트렌드·랭킹 제목이 압도적으로 이 형식. 유저가 "내가 되는 상황"을 1인칭/관계 중심으로 즉시 상상하게 한다.
```
내가 키운 제자들에게 집착받는다 / 소꿉친구의 랜선여친 / 내 동생이 사이코패스 인 거 같다 / 신입 버튜버로 데뷔 해버렸다
→ 공식: [내 입장] + [상대·관계] + [지금 벌어진 일(동사 종결)]
→ 우리 예시: 2년 전 날 버린 동업자가 내 가게 단골이 됐다 / 365일 위장 신혼, 계약서엔 키스 조항이 없었다
```
접미 `S`, `ˢᵃᶠᵉ`, `𝓢`, `SA` 표기는 세이프 모드 대응 표기로 추정되며 의미는 research/05에서 확인(**미확인**). 제목 장식용 유니코드(`｜ ：`)는 관례.

**② 케이브덕 `이름 | 상황 "대사"`형** [실측, research/08] — 다작 크리에이터(@saebyeok_studio)가 하루 여러 개 올리는 포맷.
```
정다율 | 위장 신혼부부 365일 "도장만 찍어."
윤채아 | 7년 전 날 버린 전 여친이 내 수행비서가 됐다
→ 공식: [캐릭터 이름] | [상황 한 줄] "[말투가 보이는 한 마디]"
→ 우리 예시: 윤세아 | 날 버리고 떠난 동업자가 단골이 됐다 "…주문은요?"
```
한줄소개 공식: `"대사 한 줄." + 상황 요약 + 구체 수치` (예: 금고 80만 원, 월세 D-30).

**③ 대괄호 메타태그** [실측, research/08] — 카드만 보고 유형을 알게 하는 관례.
```
[👤24+]  연령/대상       [👤4명] [👤6명]  등장 캐릭터 수(군상극 어필)
[BL] [입헌군주제]  장르/설정     [01/08 updated]  갱신일     SFW / sfw 버전  수위
→ 우리 예시: [👤3명] 청운장 셰어하우스 | 입주 첫날, 관리인의 규칙 "쓰레기는 화요일이에요." SFW
```
크랙 이름 필드는 특수문자 불가이므로 메타태그는 **케이브덕·베이비챗 전용**으로 쓰고, 크랙은 해시태그·장르 필드로 대체한다.

### 4-3. 한줄소개 템플릿 [종합, research/03 1-5]

```
[관계/상황 훅] + [캐릭터 한 마디(말투가 보이게)] + [무엇을 하게 되는지]
예) 2년 전 말도 없이 떠난 동업자가 내 바 '밤섬'의 단골이 됐다. "…주문은요, 선배." 왜 떠났는지, 물어볼 수 있을까.
```
- 앞부분이 메인·검색에 노출되므로 **핵심 정체성/어필을 맨 앞**에 [커뮤니티, 뤼튼갤 76734].

| 원하는 것 | 고를 유형 | 크랙 | 케이브덕 |
|---|---|---|---|
| 관계 몰입(여성향 로맨스·집착·순애), 한 사람과 깊게 | **캐릭터형 1:1** | 캐릭터 빌더 또는 스토리+1:1 롤플레잉 템플릿(출력량 많음, 제3자 등장 어려움 [커뮤니티 뤼튼갤 76734]) | 롤플레잉 |
| 세계 탐험·다인캐·상태창·분기·엔딩 | **상황극/시뮬레이션** | 스토리 빌더 + 시뮬레이션 템플릿(게임형·멀티 스토리라인) + 스탯·엔딩 | 시뮬레이터 + 위젯 |
| 유저가 "나"로서 생존·경영·육성 | **시뮬레이터** | 스토리 + 시뮬레이션 + 스탯 7개/엔딩 | 시뮬레이터 + 키워드북 단축어 |
| 룰을 전부 직접 쓰고 싶음 | 제작자 커스텀 | 난이도 높음, 시스템 지시문 전부 자작 [공식 research/10 G] | — |

규칙: **둘을 섞지 않는다.** 1:1 관계극에 상태창·다인캐·스탯을 얹으면 템플릿/시스템 프롬프트와 충돌한다 [종합]. 캐릭터 플롯은 갈등 해소 후 지루해지므로 **엔딩 이후 떡밥**을 미리 설계하고, RPG 플롯은 목표·지침·조건·분기·출력 방식을 전부 갖춰야 작동한다 [커뮤니티, 제타 여성향갤 15348].

### 5-3. 수익 관점 보정 (docs/10-platforms 참고)

- 크랙 오리지널·온리 신청 대상은 "스토리" 중심 문구, 크리에이터 미션 집계는 "캐릭터" 기준 문구 [공식 research/02 1.1] → 크랙에서는 **캐릭터(다작으로 미션 달성) + 스토리(오리지널 투고)** 두 트랙을 병행한다.
- 크랙 오리지널 심사는 성행위 주 소재·유틸리티 제외, **세이프티 선호**, 재미·완성도·신선도·독창성·확장성 평가 [공식 research/10 B] → 오리지널 노릴 작품은 세이프티 버전을 기본으로 만든다.
- 케이브덕 오리지널(독점) 평균 채팅 161회 vs 1,061회(6.6배) [공식 research/09 B] → 케이브덕 전용 작품은 처음부터 오리지널 토글 전제로 기획(3개월 해제 불가).

## 6. 컨셉 체크리스트

- [ ] 한 문장으로 말해진다: "[유저 역할]인 내가 [캐릭터]와 [상황]을 겪는다"
- [ ] 노출면 3종(썸네일·제목·한줄소개)이 **같은 훅**을 약속한다
- [ ] 유저의 역할·관계·첫 거리감(경계/호의/친함)이 정해졌다
- [ ] 관계 곡선(시작→전환 조건→끝)이 있다, 또는 시뮬레이터면 목표·조건·엔딩이 있다
- [ ] 유형을 하나만 골랐다(1:1 / 상황극 / 시뮬레이터)
- [ ] 타깃(남성향/여성향/전체)과 등급(세이프티/언세이프티)을 확정했다 — 크랙은 등록 후 변경 불가, 베이비챗은 성인→전체 불가 [공식]
- [ ] 등장인물 전원 **성인·나이 명시**, 교복·학교·학생회·어린 외형 없음, 실존 인물·타 작품 캐릭터 없음(CLAUDE.md 6절)
- [ ] 케이브덕이면 혈연 근친 설정 없음(비혈연은 명시) [공식 research/09 C-1]
- [ ] 엔딩 이후 떡밥 또는 두 번째 시작점 아이디어가 있다
- [ ] 독점 여부(크랙 온리 18개월 / 케이브덕 오리지널 3개월 / B Only 100일)를 결정하고 `status.md`에 적을 준비가 됐다

## 7. 컨셉 시트 템플릿

```markdown
## 컨셉
- 작품 유형: 1:1 롤플레잉 (크랙 캐릭터 빌더 + 1:1 템플릿 / 케이브덕 롤플레잉)
- 타깃·등급: 전체 / 세이프티
- 한 문장: 2년 전 말없이 떠난 전 동업자(유저)가, 내가 혼자 꾸리는 바 '밤섬'에 단골로 나타났다.

- 캐릭터: 윤세아, 26세, 여, 을지로 바 '밤섬' 사장
- 관계 곡선: 혐관(존댓말·"선배") → 방어적 농담 → 옛 반말·"너" (전환 조건: 단둘이 마감 후, 유저가 다그치지 않을 때)

- 엔딩 이후 떡밥: 바를 함께 옮길지 결정 / 두 번째 시작점 "개업 전날"

## 노출면
- 제목(크랙): 날 버리고 떠난 동업자가 내 가게 단골이 됐다
- 제목(케이브덕): 윤세아 | 날 버리고 떠난 동업자가 단골이 됐다 "…주문은요?"

- 메타태그(케이브덕/베이비챗): [👤1명] SFW
- 해시태그: #재회 #혐관 #순애 #을지로 #바
```
