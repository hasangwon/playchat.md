# 05. 첫 메시지(인트로·프롤로그·시작 대사) — 가장 영향력 큰 칸

> 목적: 모델이 응답 길이·형식·말투를 가장 강하게 학습하는 첫 메시지를, 유저 행동을 쓰지 않고 열린 비트로 끝나게 쓴다. 이미지 삽입 문법·복수 시작 장면·추천 답변 포함.

## 1. 왜 가장 중요한가 [종합, research/03 5-1]

- SillyTavern 공식: "모델은 **첫 메시지에서 소통 스타일과 응답 길이**를 다른 어떤 것보다 강하게 학습한다." Chub 공식: "initial message는 이후 행동을 강하게 형성."
- 2026 블로그 공통: "the single highest-leverage field" — 밋밋한 두 줄 오프너는 밋밋한 두 줄 응답을 허용한다는 신호.
- 크랙(뤼튼갤): 첫인사는 "캐릭터가 한 말"로 취급돼 초반 진행에 영향, **키워드북 트리거**로도 쓰임 [커뮤니티].
- 제타 여성향갤: "AI는 입력한 인칭·맞춤법·띄어쓰기·강조·대사 기호를 그대로 학습" → 오탈자 금지 [커뮤니티].

## 2. 길이

| 출처 | 권장 |
|---|---|
| 케이브덕 [공식] | 에피소드당 10,000자 상한, 나눠쓰기 시 말풍선 10개 |
| 베이비챗 [공식] | 첫 상황 1,000자 + 첫 대사 500자 |
| 포스타입 [공식] | 최대 1,000자 |
| 크랙 [공식] | 글자수 미기재(커뮤니티: 시작 설정 3개×1,000자, **미확인**) |
| 유니챗 | **3~6문장** |
| JanitorAI | "긴 첫 메시지는 긴 답변을 유도" |
| 제타 여성향갤 [커뮤니티] | 장문 선호 시 2~4페이지도 가능하나 턴이 지나면 밀도 저하 |

**실무: 원하는 턴당 응답 길이의 1~1.5배.** 유저가 3~5문단 응답을 원하면 인트로도 3~5문단. 크랙 기본 출력 1,000토큰·베이비챗 시스템 길이 관리를 고려하면 보통 **400~900자**.

## 3. 구조 공식: 상황 → 캐릭터 등장 → 공 넘기기 [종합, research/03 5-3]

유니챗 3요소: ① 상황 설정(장소·시간·분위기) ② 캐릭터 등장(무엇을 하는지, 말투·성격이 드러나는 행동과 대사) ③ **공 넘기기**(질문·시선·다가오는 행동으로 유저가 반응할 여지). "첫 메시지가 스스로 완결되면 유저가 받아칠 거리가 없다."

```
*[장소·시간·감각 1~2개]. [{{char}}가 하고 있던 행동].*
*[{{user}}를 인지하는 순간의 반응 — 시선·망설임·표정].*
"[말투가 또렷한 첫 대사 — 호칭·어미 포함]"
*[반응 여지를 남기는 행동 — 손을 내밀거나, 자리를 비우거나, 묻는다].*
```

- JanitorAI: 핵심 특성(사투리·능력)을 첫 메시지에서 부각. **유저 행동을 직접 서술하지 말 것**: "You pick up…" 대신 "{{char}}는 {{user}}가 집어 드는 것을 본다".
- Ali:Chat/kingbri: 루프 방지를 위해 **유도 질문(leading question) 제거**. 예시 대화의 마지막은 첫 메시지와 겹치게(연결감).
- 제페토·캐럿 [공식]: 나레이터(상황) → 캐릭터(대사) → 추천 답변. 케이브덕 **나눠쓰기**(지문/캐릭터/플레이어 말풍선)도 같은 구조 [공식 research/09 D-2].

## 4. 시점 [종합, research/03 5-4]

- **3인칭 제한 시점**이 글로벌 기본값. 유니챗: 3인칭 또는 1인칭 중 택일 후 세션 내내 일관.
- **1인칭 나레이션**: 별도 프롬프트 없이 **인트로를 1인칭으로 쓰면** 이후 대화도 1인칭 ("{{char}}가 문을 열었다" → "나는 문을 열었어") [커뮤니티 제타갤 195063].
- **2인칭("당신/너")은 혼동 위험**: 케이브덕 스냅샷 테스트에서 1·2인칭 서술은 캐릭터와 유저 묘사를 혼동(특히 동성) [커뮤니티 포스타입].
- 인트로에서 **내레이터/유저/캐릭터 역할을 섞지 말 것** [커뮤니티 제타 여성향갤]. 첫인사 머리말에 `#`을 쓰면 시스템 메시지 과다 출력 [커뮤니티 뤼튼갤].
- 바베챗 공식 예: "3인칭 전지적 시점, 캐릭터의 내면 심리 중심, 은유법 사용, 형이상학적 표현 회피"처럼 시점+서술 중심+표현 기법을 프롬프트에 명시하고 인트로가 그대로 따른다.

## 5. 분위기·감각

- 장면 감각 목록(빛·소리·냄새·촉감)을 프롬프트에 미리 적고 인트로에서 2~3개 사용 [유니챗].
- 첫 문장에서 **장르와 시대**가 보여야 한다(감각 디테일 하나로). 인트로에 현대 문물이 섞이면 이후 전부 오염 [커뮤니티 와따].
- 한줄소개에서 약속한 훅이 인트로에 **바로** 나와야 한다(케이브덕 ②형 제목의 대사가 인트로에 그대로 등장하는 패턴, 10절 분석 3).

## 6. 유저 행동 유도

| 하지 말 것 | 대신 |
|---|---|
| 유저의 행동·대사·감정·취향 서술("따뜻한 라떼 좋아하시죠?") | 캐릭터가 **제안하고 멈춘다**(잔을 내민다, 자리를 가리킨다) |
| 매 턴 질문으로 끝내기 | 열린 비트(캐릭터가 등을 돌린 채 말을 잇지 않는다) |
| 완결된 장면 | 결정이 유저에게 남은 상태 |
| 장황한 세계관 설명 | 감각 디테일 1~2개 + 현재 긴장 한 줄 |

유저가 처음 칠 말을 예상해 **추천 답변 3개**로 유도한다(9절).

## 10. 잘 된 첫 메시지 분석 3개

판정 기준 7개 [종합, research/03 5-7]: ① 첫 문장에 장르·시대 ② 첫 대사에서 말투 고정 ③ 유저 행동·대사·감정·취향 0줄 ④ 열린 비트로 끝남 ⑤ 길이·형식의 본보기 ⑥ 로어북 키워드 1~2개 ⑦ 한줄소개와 톤 일치.

### 분석 1 — 유니챗 Before/After (research/03 5-3 요지)
- **Before(나쁨)**: 캐릭터 자기소개 + 환영 인사 + "따뜻한 라떼 좋아하시죠?" — 유저 취향까지 정해버림(③ 위반), 개성 없음(② 위반), 받아칠 거리 없음(④ 위반).
- **After(좋음)**: 시간·분위기를 살리고(①), 캐릭터의 어수룩한 행동과 말투를 보여준 뒤(②·⑤) 질문으로 마무리(④). 유저 행동은 쓰지 않음(③).
- 교훈: 좋은 인트로는 **정보가 아니라 행동**으로 캐릭터를 보여주고, 유저 몫을 비워 둔다.

### 분석 2 — 베이비챗 상위 캐릭터 메시지 구조 (research/07 실측)
관찰된 포맷(구조만 인용; 해당 캐릭터는 10세 아동 설정이라 **우리는 미성년 설정 자체를 배제**하고 포맷만 참고):
```
<서술 문단 — 3인칭 소설체, 상황·행동 묘사>
이름 | "대사"
<서술>
img[ID] 이름 | "대사"
<서술>
info 🗓날짜 | ⏰️시간 🧒캐릭터 스펙 🥼양측 복장 🗺양측 위치 💫현재 상황
```
- 서술/대사 포맷(`이름 | "대사"`)을 첫 메시지가 **본보기로 제시**(⑤) → 이후 턴이 같은 포맷을 유지.
- 이미지는 대사 줄 앞에 **별도 토큰**으로 분리(크랙 공식 "별도 줄" 권고와 일치).
- 상태창(`info`)은 **메시지 끝**(크랙 공식 "최하단" 권고와 일치, `03-persona-prompt.md` 9절).
- 멀티 캐릭터(2인)가 첫 메시지에서 각자 한 번씩 발화해 역할을 고정.

### 분석 3 — 케이브덕 신작 ②형 "제목 대사 → 인트로 재등장" 패턴 (research/08 실측 + 재구성)
실측 제목 `정다율 | 위장 신혼부부 365일 "도장만 찍어."`는 제목의 대사가 한줄소개·인트로에 그대로 이어지는 **약속 일치(⑦)** 패턴이다. 같은 구조로 쓴 오리지널 재구성(백도윤, 31세):
```
*성수동 복층 오피스텔, 밤 11시. 거실 테이블 위에 서류 한 묶음과 인주. 백도윤은 수트 재킷을 벗지도 않은 채 서서 계약서 마지막 장을 넘기고 있다.*
*문이 열리는 소리에 고개를 들지 않는다. 왼손 약지의 반지를 한 번 돌리고, 펜을 서류 위에 올린다.*
"늦었네. 7조까지 읽었어?" *그제야 시선이 올라온다. 안경 너머의 눈은 피곤하지만 흔들림이 없다.* "안 읽었으면 지금 읽어. …아니면 도장만 찍어."
*그는 의자를 빼 주고는 주방 쪽으로 가 물을 따른다. 등을 돌린 채, 서명 소리를 기다린다.*
```
- ① 장소·시간·소품(인주)으로 계약 결혼물임이 첫 문장에 보임. ② "늦었네 / 도장만 찍어"로 반말·명령형 말투 고정. ③ 유저 행동은 "문이 열리는 소리"뿐, 선택(읽을지/찍을지)은 유저 몫. ④ 등을 돌린 채 기다리는 열린 비트. ⑥ '7조'가 로어북/비밀 해금 키워드. ⑦ 제목 대사가 인트로 마지막 대사로 재등장.

## 11. 템플릿 3종

## 12. 체크리스트 (유니챗 발행 전 체크 + research/03 5-7)

- [ ] 유저의 행동·대사·감정·취향을 한 줄도 쓰지 않았다
- [ ] 상황 → 캐릭터 등장 → 공 넘기기 3요소가 있다
- [ ] 첫 대사에 호칭·어미(말투)가 있다
- [ ] 길이가 원하는 응답의 1~1.5배이고, 별표/따옴표/단락 형식이 프롬프트 출력 형식과 같다
- [ ] 시점이 하나로 일관되고(3인칭 기본), 내레이터/유저/캐릭터 역할이 섞이지 않았다
- [ ] 첫 문장에 장르·시대가 보이고 세계관 금지 요소(현대 문물 등)가 없다
- [ ] 열린 비트로 끝난다(완결 X, 유도 질문 남발 X)
- [ ] 로어북 키워드 1~2개가 자연스럽게 들어갔다
- [ ] 한줄소개·제목의 훅이 인트로에 바로 나온다
- [ ] 머리말에 `#` 헤더가 없다, 오탈자가 없다, 이모지·특수문자 도배가 없다
- [ ] 이미지는 대사와 별도 줄, 플랫폼 공식 문법만 사용, 등록된 이미지 이름/slug와 일치
- [ ] 복수 시작 장면이면 각각 독립적으로 읽히고 공통 설정은 프롬프트에 있다
- [ ] 추천 답변 3개가 서로 다른 태도를 대표한다
- [ ] 등장인물 전원 성인·나이 명시, 교복·학교 배경 없음
