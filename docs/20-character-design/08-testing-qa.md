## 1. 테스트 워크플로 [종합, research/03 10-1]

1. **단계 사이에 테스트를 끼운다**: 상세 규칙 → 시작 상황 → 테스트 → 수정 → 키워드북 → 테스트 → 수정 → 이미지 → 테스트 [커뮤니티 뤼튼갤 42661].
2. **한 번에 하나만 바꾼다**. 새 채팅과 이어지는 채팅 둘 다에서 확인. 기록: 프롬프트 버전·모델·맥락·첫 응답·근거 문장 [crushon.ai].
3. **비공개/링크 공개로 테스트 후, 공개는 새로 만들어 옮긴다**(크랙): 비공개로 만들어 테스트 후 공개로 전환하면 등록일이 고정돼 최신순 노출·팔로워 알림이 없다 [커뮤니티 뤼튼갤 69098/76734]. 케이브덕은 공개 캐릭터에 연결된 키워드북 수정이 **즉시 반영**되므로 비공개 사본으로 테스트 [공식 research/09 F].
4. 도입부 초안 뽑기: 도입부에 `.`만 찍고 비공개 생성 → 채팅방에서 AI에게 상황을 설명해 초안 받기 → 상태창·말투·분위기 확인 → 도입부 칸에 옮김 [커뮤니티 Xiruan].
5. 유저 페르소나(5줄)를 먼저 채우고 테스트한다 — 비우면 "편한 사이"로 오염돼 테스트가 무의미 [유니챗].
6. 수정 후 반영 확인: 제페토는 새로고침 필요 [공식]. 크랙·케이브덕도 미리보기 재시작 후 확인.

## 3. 테스트 체크리스트

### A. 새 채팅 — 첫 응답 5회 리롤
- [ ] 말투·호칭·어미가 인트로·프롬프트와 일치하는가(5회 모두)
- [ ] 길이·단락·별표/따옴표 형식이 지시대로인가
- [ ] 유저 대사·행동·감정을 쓰지 않았는가
- [ ] 시대·세계관 금지 요소(현대 문물 등)가 새지 않았는가
- [ ] 첫인사의 키워드로 로어북이 발동했는가(크랙은 첫 응답부터)
- [ ] 상태창이 있다면 **최하단**에, 가변 문장과 함께 나오는가
- [ ] 시스템 메시지·메타 발언·영어·'thinking'이 섞이지 않았는가
- [ ] 이미지가 지정한 상황에서만 나오고 엉뚱한 이미지가 없는가

### B. 유저 대역 진단 5종 [crushon.ai, research/03 10-2]
각 입력에서 캐릭터가 유저의 발화·행동·내면·결정을 가로채지 않는지, **그리고 장면이 유용하게 진행되는지**를 따로 채점한다("I will not control you"만 반복하면 규칙은 지켰지만 RP 실패).
- [ ] 결정하지 않은 선택: "…잠깐만." → 캐릭터가 유저 대신 결정하지 않는가
- [ ] 침묵: "(아무 말도 하지 않는다)" → 침묵을 동의로 취급하지 않는가
- [ ] 명시한 감정: "짜증이 난다." → 그 감정을 바꿔 쓰거나 확대하지 않는가
- [ ] 완료한 행동: "잔을 비운다." → 추가 행동을 덧붙이지 않는가
- [ ] 모호한 이어짐: "그래서…" → 유저 문장을 완성하지 않는가

### C. 이어지는 채팅 — 20~30턴, 캐릭터 일관성
- [ ] 비밀이 유도 없이 새지 않는가(케이브덕 비밀 칸 / "증거 전까지" 규칙)
- [ ] 조건부 규칙(관계 단계·트리거)이 조건 전/후로 다르게 작동하는가
- [ ] 혐관/철벽 캐릭터가 한 번 거부에 순응하지 않는가
- [ ] 긍정 편향(무조건 다정)·과도한 공격성이 없는가
- [ ] 제3자가 멋대로 등장하지 않는가
- [ ] 호칭·어미가 관계 단계에 맞게만 변하는가(크랙 공식: 말투는 대화에 따라 실시간 변동 가능 [research/10 J] → 변동이 **설계한 조건에서만** 일어나는지)
- [ ] 군상극이면 한 턴 발화 인물 ≤2, 허용 목록 밖 인물 없음

### D. 로어북 [Elyn 체크리스트, research/03 10-2]
- [ ] 키워드 발동/해제가 확인됐는가(케이브덕 청진기 RAG)
- [ ] 흔한 키워드 오발동이 없는가
- [ ] 동시 활성 상한(크랙 3/바베챗 5/케이브덕 10)에서 중요 항목이 누락되지 않는가
- [ ] 상호 배타 항목(적대/연인)이 동시에 들어가지 않는가
- [ ] 챗봇이 말한 키워드가 다음 턴에 발동하는가(크랙)

### E. 장기 — 50~100턴
- [ ] 시작 상황 휘발 후에도 핵심 설정이 유지되는가
- [ ] 반복 대사·같은 행동으로 끝나는 패턴이 없는가
- [ ] 요약/메모리에 잘못된 사실이 들어가지 않았는가(케이브덕 메모리 편집)
- [ ] 요약 OOC/단축어를 돌렸을 때 관계·사건이 정확히 정리되는가
- [ ] 엔딩 또는 갈등 해소 후에도 떡밥이 작동하는가

### F. 노출면
- [ ] 썸네일 우하단 가림·원형 크롭 확인(앱/웹)
- [ ] 한줄소개 앞부분에 훅, 제목·한줄소개·인트로가 같은 약속
- [ ] 태그는 유저 입장에서(검색은 설명+태그 기반)
- [ ] 세이프티/타깃 설정이 내용과 일치(공개 후 변경 불가 항목 주의)

## 5. 디버깅 팁 [research/03 10-4]

- **OOC로 원인 묻기**(디버그 전용): "OOC: 방금 왜 그렇게 답했는지 참고한 설정을 알려줘" [커뮤니티 뤼튼갤]. 본 플레이에선 쓰지 않는다(메타 발언 학습). 케이브덕은 OOC 단어 자체가 노출 유발 → 청진기로 대체.
- **순서대로 의심**: 로어북이 **발동 자체가 안 되는지**(키·범위) → 발동됐지만 **무시되는지**(너무 길거나 모호, 더 강한 지시와 경쟁) [SillyTavern 커뮤니티].
- **서버 vs 프롬프트 구분**: 위 표 마지막 행.
- **AI로 검수**: 인트로 검수 프롬프트, 문체 분석 보고서, 상세정보 생성기 등 LLM 보조 도구 활용 [커뮤니티 제타갤 562449].
- **데이터로 분리 진단**(제타 통계): 클릭률 낮음 → 썸네일·한줄소개 / 전환율 낮음 → 인트로 / 10분 전환·대화량 낮음 → 프롬프트.
