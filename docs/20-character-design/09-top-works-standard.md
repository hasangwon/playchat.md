# 09. 상위작 기준선 — "이 정도는 돼야 랭킹에 든다"

> 근거: research/16(2026-10-22, 크랙 랭킹 115작품·케이브덕 트렌딩 60작품·베이비챗 주간 80작품의 공개 데이터와 댓글, 아카라이브·디시 제작자 개념글). 작품을 쓸 때 이 문서를 **합격선**으로 쓰고, 01~08 문서는 세부 작법으로 쓴다.
> 표기: 수치는 2026-10-22 실측. [커뮤니티] = 제작자 경험담.

## 2. 노출 텍스트 (사용자가 클릭하기 전에 보는 것)
- **제목**: 장르 관용구형(「~속 히든 클래스가 되다」, 「~에서 살아남기」, 「~에게 집착받는다」) 또는 대사·반말형(「우정박 할래」, 「쿼터백이 너랑 자겠냐고ㅋㅋ」). 여성향 1:1은 캐릭터 이름 자체가 제목(케이브덕).
- **한 줄 소개**(크랙 30자 이내 실측 25자 중앙값): ① 규모형 `[👤N｜🖼N] 훅` ② 대사형 `"…"` ③ 상황 훅형 `{{user}}억까주의⚠️…`. 세 가지 중 하나로 쓴다.
- **상세 설명 순서**(크랙): 대표 이미지(외부 소개 페이지 링크) → 규모 요약 → 시작 모드 목록(모드별 한 줄) → 인물 카드(이미지 + 이름·나이·직업·관계 1줄) → 이미지 미리보기 → 단축어 표 → 권장 모델·출력량.
- **케이브덕 소개란**: HTML 카드 페이지(헤더 → 프로필 카드 → 배경 → 시놉시스/게시판 캡처풍 연출). 크리에이터 코멘트도 HTML 세계관 페이지로. → 우리 템플릿에 HTML 소개 페이지를 추가해야 경쟁 가능.

## 3. 시작 설정·첫 화면
- **2~3개 시작 설정**: 기본 / 같은 세계를 **반대편에서** 하는 모드(학생 ↔ 성좌, 신입 ↔ 선배) / 자유 설정. 상위작 다수가 이 구성.
- **프롤로그 600~1,300자** 구조: 첫 줄 상태 헤더(`#0｜날짜｜요일｜시간｜📍장소｜⚪`) → 이미지 줄 → 이탤릭 서술(세계를 보여주는 장면) → 인물 등장 `**『 이름 』**` + 대사(+`![이름::감정](URL)`) → 유저가 할 일 지시(`[프로필을 채팅창에 입력 후 시작해주세요]`) → 빈 상태창/프로필 양식.
- 프롤로그 맨 위에 **보이지 않는 지시**를 숨기는 기법: `[//]: # (Never describe {user}'s actions, dialogues, or feelings)` — 마크다운 주석이라 화면엔 안 보이고 모델은 읽음.
- **추천 답변 = 완성된 예시 페르소나 2~3개**(진지한 것 1 + 웃긴 것 1) 또는 성향이 다른 유저 대사 3개.
- **플레이 가이드**: 세계관 핵심 규칙 1줄씩, 수치 규칙표(레벨 구간), 권장 모델·출력량, 단축어 안내, "막막하면 이름과 레벨만 말하세요" 같은 진입 장벽 낮추기.
- 베이비챗형: 첫 메시지 자체를 `!명령` 표로 만들고 "권장 2개, 최대 3개 조합"처럼 조합을 유도.

## 4. 캐릭터 프롬프트 작법 (제작자 커뮤니티 최상위 가이드)
1. **형용사 금지 → 조건→행동**: "차갑다" 대신 "칭찬받으면 즉시 화제를 바꾼다".
2. **아키타입 레이블 금지**(츤데레·얀데레 등): 고유 감정 회로 + 예외 조건 + 서브텍스트로.
3. 위→아래 배치(모델은 처음과 끝을 강하게 봄):
   - 맨 위 CORE: 앵커 문장 1줄 / 상처 장면 1개(감각 디테일) / Want vs Need 충돌 / 감정별 가면·누출 / 핵심 모순(조건→반응→이유)
   - VOICE: 상황별 실제 대사(회피·진심·상처·거짓말·궁지) / 감정별 말투 전환(방어 시 존댓말로 벽) / 직접 말하지 않는 것 / 무의식 습관 3~4개 / 세상을 지각하는 렌즈 3개 / 신뢰 단계별 감정 인정 한도
   - 로어북 STATE: 관계 상태 3~5개, 행동 마커, 유저 행동 기반 전이, **역행 경로 필수**
   - 로어북 REACTION: 트리거 1개 = 엔트리 1개(사실 + 반응 + 밀었을 때 + 절대 경계)
   - 맨 아래 DIRECTION: **턴 알고리즘** 8단계(인정+대가 → 긴장 1단계 → 감정은 행동으로 → 대사·지문 모순 허용 → 두 번 저항 한 번 보상 → 훅 1개 → 쿨다운 → 유저 서술 금지) + 말투 앵커 1줄
4. 군상극: 인물마다 **개인 동기 + 세계가 그 동기를 강제하는 이유**, 같은 세계를 다르게 보는 기준점 인물, 입문 튜토리얼 역할 인물.
5. 크랙 캐릭터 프롬프트 2,000자 안에 다 못 넣으므로 CORE·VOICE·DIRECTION만 본문, STATE·REACTION은 키워드북으로(크랙 스토리 5,000자 + 키워드북 20개).

## 6. 출시·운영
- **세이프 먼저, 언세이프는 바로 뒤에**: 세이프 작품 댓글 1위 요구가 "언셒 언제". 언세이프 심사 기간에도 세이프로 유저를 모은다.
- **고정 댓글 템플릿**: 공개 인사(장르 한두 줄) / 업데이트 로그(날짜) / 권장 모델과 모델별 맛 차이 / 출력량 올리는 유저노트 문구 / 사칭 방지 문구 / 오류 대응(디버그) / 추천 플레이 3~5개 / Q&A / "대댓에 이미지 코드표".
- 업데이트를 자주(시즌 이벤트·의상·모드 추가) 하고 한 줄 소개·설명 맨 위에 `[🆙 …]`로 표시.
- **출시 전 플랫폼 상태 확인**: 2026-10-19~ 크랙 대화수 집계 오류 기간에 낸 신작이 랭킹 진입 실패 사례 → 갤러리·공지에서 장애 여부 확인 후 출시.
- 작품을 내리거나 설명을 지우지 않는다(유저 요청).
