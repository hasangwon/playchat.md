## 1. 로어북이 하는 일 / 하지 않는 일 [종합]

| 넣는다 | 넣지 않는다 |
|---|---|
| 지명·조직·역사·용어 상세 | 캐릭터 기본 정보(이름·나이·성격·말투) — 프롬프트에 [루나톡 공식] |
| 조연 프로필, 가게·동네 정보 | 매 턴 필요한 세계 규칙("현대 문물 없음") — 프롬프트에 |
| 사건의 진상, 비밀(해금 조건과 함께) | 외부 이미지 링크(오류 유발) [루나톡 공식] |
| 아이템·능력·상태창 모드 전환 | 캐릭터 간 관계(각 캐릭터 프롬프트에) [유니챗] |
| 유저가 호출하는 커맨드(단축어) | 대화에 나오지 않을 단어("세계관")를 키로 하는 항목 |

## 3. 키워드 설계 9원칙 [종합, research/03 4-2]

1. **흔한 단어 금지**: '회사', '대표', '커피', '그', '이', '저'는 엉뚱한 턴에 호출돼 다른 엔트리를 밀어낸다 [투킷·유니챗]. 일상적으로 적용될 정보는 프롬프트에.
2. **너무 길고 구체적인 복합어도 금지**: 실제 대화에 안 나온다. "투킷 대표", "탈출 계획"처럼 **정확한 고유명칭 또는 캐릭터 고유의 비밀 명칭**이 이상적 [투킷].
3. **유저가 실제로 칠 말**을 포함: "바, 술집, 가게, 이 집, 사장님 가게" [유니챗].
4. **동의어·별칭·연관어 묶기**: 케이브덕 `|`, 베이비챗 5개 칸, 루나톡 예 `과거, 기억, 트라우마, 괴롭힘, 왕따`.
5. **대소문자**: 영문은 둘 다 등록(`Leonar|leonar|LEONAR`) [커뮤니티 Xiruan, 케이브덕].
6. **지문 기호(`.` `*`)를 키워드로 쓰지 말 것** [공식 제타].
7. **부분 일치 주의**: 크랙 키워드북은 텍스트 일부만 일치해도 작동 → 짧은 키워드는 오발동 [커뮤니티 뤼튼갤 69098]. 두 글자 키워드는 피한다.
8. **2차 키/AND 로직**(SillyTavern): 1차+2차 키 동시 존재 시만 활성 → 국내 플랫폼엔 없으므로 키워드를 **복합 고유명사**로 만들어 대체("등대 사건").
9. **다국어**: 케이브덕은 자동 번역(10개 언어) 유저가 있지만 세부 키워드는 번역되지 않는다 → `불의 잔|Goblet of Fire|炎の杯`처럼 병기 [공식 research/09 F]. 영어 키워드만 병기해도 커버율이 크게 오름 [커뮤니티].

## 4. 엔트리 분량·포맷 [종합, research/03 4-3]

- **"엔트리 하나는 질문 하나에 답한다"** [Tavern Studio]. 큰 설정은 독립적으로 발동 가능한 조각으로 쪼갠다.
- 본문은 **독립적으로 읽히는 서술**로. 제목·키는 프롬프트에 들어가지 않는다 [공식 SillyTavern, 바베챗 "로어북 제목은 저장되지 않으니 `###` 헤더를 본문에"].
- 베이비챗/투킷 권장 구조: `### 제목(캐릭터 요소명)` 아래 실력 / 특징 / 실수 대응 / 관련 대사. **`###`부터 시작**해야 "메인 설정이 아닌 키워드 종속 하위 정보"로 인식 [공식].
- 분량 가이드: 케이브덕 400자·베이비챗 500자 상한의 **60~80%**(150~400자). 유니챗 3,000자 상한은 플랫폼 로어북이 아닌 세계관 문서 기준.
- 환경 엔트리는 짧은 PList, 인물 엔트리는 PList + 캐릭터의 반응을 보여주는 Ali:Chat 한 줄 [rentry World Info Encyclopedia].

## 5. 상시 vs 조건, 우선순위, 상한 공략

### 5-1. 상시 활성이 필요한 정보 [종합, research/03 4-4]
- 원칙: 상시 필요하면 **프롬프트**에. 로어북 상시 기능은 SillyTavern(🔵), CCv2 `constant`, Elyn '찾았을 때 비활성화'에만 있다.
- 크랙 응용: 트리거가 없을 때 **상단 3개가 상시 활성** → 상위 3개를 "추가 프롬프트 칸"으로 쓰는 기법 [커뮤니티 뤼튼갤 76734]. 단, 그 3개가 조건부 엔트리를 밀어내므로 정말 상시여야 하는 것만.
- 베이비챗: 상시 로어북 1개 운용 팁 [커뮤니티] — 공식 옵션 **미확인**.

### 5-2. 우선순위 = 목록 순서 [공식]
케이브덕·크랙·베이비챗·루나톡 모두 **목록 상단 우선**. 정체성·행동 원리에 치명적인 정보일수록 위로. 순서 기준:
```
1~N(상한 수)  : 없으면 캐붕이 나는 핵심 비밀·관계·규칙 보강
그 아래       : 자주 언급되는 장소·조연
맨 아래       : 드문 아이템·TMI·후반 이벤트
```

### 5-3. 크랙 3개 제한 공략 [커뮤니티, 뤼튼갤 30440]
① 우선순위 낮은 항목(마을)을 맨 아래 ② 비슷한 역할 묶기(포션+무기, 마을+던전) ③ 스토리 키워드는 **초반 스토리일수록 아래**(다음 스토리용을 먼저 읽게). 둘을 조합하면 키워드 20개도 안정. 첫인사에 키워드를 넣으면 첫 응답부터 발동 [커뮤니티].

### 5-4. 해금·타이밍 [종합]
- 국내 플랫폼엔 delay/sticky가 없다 → **해금 키워드**로 대체: 진상 엔트리의 키워드를 유저가 후반에야 쓸 단어("증거", "7조")로 둔다.
- 케이브덕 **비밀 칸**이 있으면 비밀은 그쪽에, 로어북에는 비밀을 둘러싼 객관 정보만.
- 상호 배타 항목(적대 로어 vs 연인 로어)은 국내 플랫폼에서 그룹 기능이 없으므로 **한 엔트리 안에 단계별 서술**로 합친다.

## 6. 엔트리 예시 (오리지널, 전원 성인)

세계: 에르나 공국 북부 국경(`02-world-background.md` 3-4 판타지 예시와 연결). 캐릭터: 세드릭 하벨(34세, 기사단장), 유저: 공국 조사관(28세).

### 6-1. 인물 — 조연
```
키워드(케이브덕): 레오나르 공작|레오나르|공작 각하|Leonar
키워드(베이비챗 5칸): 레오나르 / 공작 각하 / 레오나르 공작 / Leonar / 공작가
내용(약 260자):
### 레오나르 공작
- 61세, 북부 영주. 세드릭의 임명권자. 등대 사건 보고서에 서명했다.
- 특징: 느리고 정중한 말투, 모든 문장을 "그렇지 않은가"로 끝냄. 사람을 이름이 아닌 직함으로 부른다.
- 세드릭과의 관계: 세드릭을 아끼지만 공국 이익이 우선. 사건이 공개되면 세드릭을 버릴 것.
- 세드릭의 반응: 공작 이야기가 나오면 "각하께서 결정하실 일입니다."로 끊는다.
```

### 6-2. 장소
```
키워드: 칼드|요새 칼드|북부 요새|성채
내용(약 200자):
### 요새 칼드
- 북부 국경의 돌 요새. 기사단 120명 주둔. 남쪽 성문 위 망루에서 붉은 등대가 보인다.
- 구조: 1층 병영·식당, 2층 단장실(세드릭), 지하 기록고(열쇠 필요).
- 분위기: 바람 소리, 젖은 돌 냄새, 밤에는 등대 불빛이 창을 비춘다.
- 규칙: 해 진 뒤 성문 폐쇄, 조사관도 예외 없음.
```

### 6-3. 사건
```
키워드: 붉은 등대 사건|등대 사건|그날 밤|사건 번호 3
내용(약 280자):
### 붉은 등대 사건 (공식 기록)
- 3개월 전, 국경 등대가 하룻밤 붉게 타올랐고 등대지기 2명이 실종됐다.
- 공식 보고서: 기사단 야간 순찰 중 화재 발견, 진화 실패. 세드릭 서명.
- 공국 조사관({{user}})이 파견된 이유: 실종자 가족의 탄원.
- 알려진 모순: 그날 밤 순찰 기록에 세드릭의 이름이 없다.
(진상은 비밀 칸/해금 엔트리에 따로 둔다 — 이 엔트리는 "누구나 아는 것"만)
```

### 6-4. 아이템
```
키워드: 은빛 열쇠|열쇠|기록고 열쇠
내용(약 150자):
### 은빛 열쇠
- 요새 칼드 지하 기록고를 여는 유일한 열쇠. 세드릭이 목에 걸고 다닌다.
- 유저가 열쇠를 요구하면 세드릭은 "기록고엔 보고서와 같은 내용뿐입니다."라고 답하며 거절한다. 단, 유저가 순찰 기록의 모순을 지적한 뒤에는 열쇠를 책상 위에 올려두고 자리를 비운다(직접 건네지 않는다).
```

### 6-5. 비밀/해금형 (케이브덕은 비밀 칸에, 그 외는 후반 키워드로)
```
키워드: 증거|순찰 기록|진실
내용(약 230자):
### 진상 (유저가 '증거' 또는 '순찰 기록'을 언급한 뒤에만 참조)
- 그날 밤 세드릭은 등대에 있었다. 등대지기들이 국경 너머로 도망치려는 걸 알고, 붙잡는 대신 보내 주었고 불은 추격을 막으려 직접 질렀다.
- 세드릭은 이 사실을 말하면 부하들이 연루된다고 믿는다.
- 유저가 증거를 제시하면: 부정하지 않는다. 긴 침묵 뒤 "…부하들은 몰랐습니다."로 시작한다.
```

### 6-6. 현대물 장소 — 유니챗 '서진의 바' 구조 재구성
```
키워드: 밤섬|바|술집|가게|이 집|여기
내용(약 180자):
### 바 '밤섬'
- 을지로 3가역 뒷골목 지하 1층. 영업 저녁 7시~새벽 2시, 월요일 휴무.
- 바 테이블 6석, 2인 테이블 2개. 재즈 LP, 낮은 조도, 단골 위주.
```
