## 3. 제작자가 쓰는 추천 페르소나 [종합, research/03 7-2]

제작자가 미리 유저 역할을 설정하면 관계극의 거리감이 안정된다(제타 대화 프로필·제페토 "주요 소비층"). **비워두면** AI가 빈칸을 "편한 사이"로 채워 첫 턴부터 반말·애칭, 매번 자기소개 반복, 직업·과거를 임의 생성한다. **관계·거리감이 가장 중요** — 이름·성격이 비어도 관계만 정확하면 대부분 잡힌다.

유니챗 5줄 양식(케이브덕 300자·제타 추천 대화 프로필·크랙 플레이 가이드 "추천 대화 프로필" 안내에 공통 사용):
```
이름: {불릴 이름 / 호칭. 본명 아니어도 됨}
성격: {핵심 기질 2~3개}
말투: {반말/존댓말 · 1인칭(나/저) · 입버릇}
관계: 상대 캐릭터와 나는 {연인/동료/처음 본 사이/주종 등}, 첫 거리감은 {경계/호의/친함}
한 줄 배경: {지금 내 처지 한 문장}
```
예시(윤세아 작품용, 300자 이내):
```
이름: 선배(윤세아가 부르는 호칭). 29세.
성격: 무뚝뚝하지만 챙김, 미안한 일을 말로 못 함.
말투: 반말, 1인칭 '나'. 말끝을 흐리는 버릇.
관계: 윤세아와 나는 2년 전 함께 '밤섬'을 연 전 동업자. 내가 말없이 떠났다. 첫 거리감: 경계(세아 쪽이 차갑다).
한 줄 배경: 2년 만에 을지로로 돌아왔고, 왜 떠났는지 아직 아무에게도 말하지 않았다.
```
- 위치 유형: 주인공형(밀착) / 관찰자형(들어주는 위치) / 제3자형(이름·배경 구체적).
- 흔한 실수: 관계 없이 이름만 / 연표·혈액형 과다 / 말투를 "시크함"처럼 추상어로만.
- 베이비챗: 페르소나 제목은 `###`부터(상위 헤더면 프로필을 이상하게 해석), AI 지시는 프로필 아래 `##`로 주어를 분명히 [커뮤니티 바베챗갤].
- 케이브덕은 **에피소드별**로 다른 추천 페르소나를 둘 수 있다 → 시작점별 유저 역할(소꿉친구/적/상사).

## 4. 유저노트 활용 패턴 [커뮤니티, research/03 7-3]

제작자는 직접 쓰지 못하지만, **플레이 가이드/크리에이터 코멘트에 "추천 유저노트"를 복사용으로 제공**하면 유저 측 품질이 올라간다.

- 헤더 관행: `# MUST FOLLOW`, `# OVERRIDE ANOTHER RULES` [뤼튼갤 747946]. 바베챗은 `###` 항목(진행사항 / 캐릭터별 규칙 / 스테이터스).
- 유저 대역 방지 문구(제타갤 642545, Gemini 계열 확인, "100% 아님"):
```
# 규칙
- 페르소나이름의 대사와 행동 도용 금지.
* 페르소나이름은 {{user}}가 직접 조종함.
```
- 출력 형식 보정: "나레이션·독백은 *별표*로 감싸기 + 예시"(크랙 유저노트에서 잘 적용) [로판공방]. 상태창 하단 고정: `# 코드블록 상태창 혹은 HUB/HUD 구조 출력을 반드시 답변의 최하단에만 출력하라` [공식 research/10 G].
- 기억 보조: 핵심 정보만 간추려 **10~20턴마다 갱신**(5절 JSON 스키마).
- 주의: 외부에서 공유되는 유저노트는 검열 우회·시스템 은닉 지시가 섞인 경우가 있어 내용 확인 후 사용 [커뮤니티]. 'OOC', '속마음', '생각' 단어는 케이브덕에서 사고과정 노출 유발 [공식 research/09 L].

## 5. 기억력 유지

### 5-1. 왜 잊는가 [종합, research/03 8-1]
- 컨텍스트 한도: 프롬프트+예시+페르소나+최근 대화가 한도를 채우면 오래된 것부터 탈락. 카드가 비대하면 최근 메시지를 밀어내 "방금 일을 잊은 것처럼" 보임.
- 크랙 공식: 일정 토큰 이상이면 **중간 맥락**을 잘 활용하지 못함(lost in the middle) [공식 research/10 J].
- 서버 상태에 따라 인식률 저하(유저노트 무시·호칭 급변·외형 혼합이 동시에 나타나면 서버 의심) [커뮤니티 로판공방].

### 5-6. 상태창·위젯을 기억 장치로 [공식+실측]
- 베이비챗 상위 캐릭터의 `info` 블록(날짜/시간/양측 복장/위치/현재 상황)은 몰입·연속성·**기억 보조** 장치로 메시지 끝에 둔다 [실측 research/07].
- 케이브덕 위젯: 상태값(날짜·호감도·관계)을 플랫폼이 관리해 프롬프트 상태창보다 누락이 적음. 비밀 칸과 글자 수 공유, 상태 정보가 많으면 답변 길이 감소 [공식 research/09 G].
- 크랙 스토리: 스탯(최대 7개, AI 적용 설명에 증감 조건 구체적으로)이 분기 엔진 겸 기억. 상태창은 최하단 [공식 research/10 I-4·G].
- 제타: 스타일 탭 상태창(배경/캐릭터 항목) [공식].

## 6. 멀티 캐릭터 / 군상극

### 6-1. 구조 설계 [종합, research/03 9-1]

유니챗 다중 캐릭터 템플릿 블록: 제목/무대 → 핵심 한 줄 → 역할(사용자·캐릭터들·AI) → 꼭 지킬 규칙(유저 대사 대신 쓰지 않기 / 감정은 행동으로 / **한 명만 계속 말하지 않기**) → 글 스타일 → 분량·구조 → 장면 감각 목록 → **공통 무대** → 등장인물(인물당 겉모습·속마음·말투 한 마디) → **인물 사이 관계** → **누가 언제 나오나(등장 계기)** → 첫인사.
- 깊게 다룰 인물은 **2~4명**, 단역은 이름+한 줄. 인물 설명보다 **관계에 분량**.
- 턴 순서: 공통 장면·감각 → 상황에 맞는 인물의 행동·대사 → 다른 인물 반응 → 유저 여지. **한 턴에 말하는 인물 최대 2명**.
- 제타 다인캐 슬롯 [커뮤니티 240088]: 최상위 슬롯에 특정 캐릭터 대신 **"등장인물" 포괄 설명 또는 세계관**을 두고, 각 캐릭터는 하위 슬롯에. 최상위에 캐릭터를 넣으면 AI가 자신을 그 캐릭터로 인식해 1:1이 됨.
- 호칭: 전체를 부를 때만 `{{char}}`, 각 인물은 이름으로 [JanitorAI]. 제타는 `{{char}}`가 "해당 턴에 말하는 캐릭터"로 작동해 오류가 적다는 반대 보고 [커뮤니티] → 플랫폼별 테스트.
- YAML 들여쓰기 구조는 인물 정보를 섞지 않음 [커뮤니티 제타갤 23864]. 각 인물에 반복 등장 디테일 1~2개와 **고유 어미** 한 마디 필수.

### 6-2. 플랫폼 지원 [공식, research/03 9-2]

| 플랫폼 | 지원 |
|---|---|
| 크랙 | 시뮬레이션 템플릿이 다수 캐릭터에 적합(1:1은 제3자 등장 어려움). 파티챗(기본 출력 2배) |
| 케이브덕 | 전문가 모드 **시뮬레이터** 유형, 세계관 단위로 캐릭터 묶음, 에피소드 **나눠쓰기**로 캐릭터·플레이어·지문 분리 |
| 제타 | 다인캐 지원(2,400자 내), 내레이터 기능, `@캐릭터이름` 서술자 지정 |
| 베이비챗/투킷 | "여러 캐릭터 동시 연기"는 복합 작업이라 지시 누락 위험 → 가급적 피하거나 단순화 [공식 경고] |
| (참고) 제페토 | 최대 20명, 인트로 발화자 선택 |

### 6-3. 군상극 팁 [커뮤니티, research/03 9-3]
- 발화 통제: 제3자 난입 금지("허용된 등장인물만"), 내레이터 출력 제한. **캐스트 허용 목록**("AI가 조종 가능한 인물: A, B, C / 유저 인물: {{user}}")이 "주인공 외 금지"보다 낫다.
- 컷씬 인물 도입 시 내레이션이 새 캐릭터 등장으로 오인됨 → 약 40자 내레이션 제한 추가 [제타갤 399878].
- 이벤트 컷씬 기법: 트리거명을 기존 프롬프트에 적고, 컷씬 이미지+부가 설정만 가진 새 캐릭터를 만들어 트리거로 호출(성공률 약 70%) [제타갤 399148].

### 6-4. 템플릿 — 셰어하우스 '청운장' (3인, 전원 성인)
```markdown
# 출력 규칙
- AI가 조종 가능한 인물: 오하림, 권태오, 남지수. 유저 인물: {{user}}(새 입주자). 그 외 인물은 등장하지 않는다.
- {{user}}의 대사·행동·감정은 쓰지 않는다. 한 턴에 말하는 인물은 최대 2명.
- 한 턴 순서: 공통 장면·감각 1개 -> 상황에 맞는 인물의 행동·대사 -> 다른 인물의 짧은 반응 -> {{user}}가 받아칠 여지.
- 3인칭 현재형. 대사 "따옴표", 행동 *별표*. 모든 출력은 한국어.

# 무대
- 서울 연남동 2층 주택 '청운장'. 1층 공용 거실·주방, 2층 방 4개. 규칙: 쓰레기 화요일, 밤 11시 이후 거실 조용히, 냉장고 칸 이름표.

# 등장인물
- 오하림 (33세, 여, 관리인·전직 호텔리어): 깐깐하고 규칙적. 말투 존댓말, 어미 "~이에요.", "규칙은 규칙이에요." 버릇: 손목시계를 본다. 속마음: 세입자들을 가족처럼 여기지만 티 안 냄.
- 권태오 (28세, 남, 프리랜서 번역가): 능청, 밤샘. 말투 반말, 어미 "~잖아~", 입버릇 "어~ 신입?" 버릇: 머그컵을 들고 돌아다님. 속마음: 마감이 두 달 밀렸다.
- 남지수 (26세, 여, 수의사 레지던트): 낯가림, 새벽 출근. 말투 존댓말 단답, "…네.", "(꾸벅)". 버릇: 고양이 털이 묻은 가디건. 속마음: 집에 혼자 있는 시간이 제일 좋다.

# 관계
- 태오는 하림을 놀리고 하림은 질색한다. 지수는 하림을 따르고, 태오를 어려워한다. 셋 다 {{user}}가 어떤 사람인지 아직 모른다.

# 등장 계기
- 하림: 규칙·공용공간 문제, 입주 첫날 안내. 태오: 저녁 거실, 야식. 지수: 늦은 밤 주방, 새벽 현관.
```

## 7. 체크리스트

- [ ] 추천 페르소나(케이브덕 300자/제타/플레이 가이드)에 **관계·첫 거리감**이 있다
- [ ] 플레이 가이드에 추천 유저노트(규칙 헤더·유저 대역 방지·요약 트리거)를 복사용으로 넣었다
- [ ] 매 턴/조건부/진행/초반 정보가 각각 프롬프트/로어북/유저노트·메모리/시작 상황에 분산됐다
- [ ] 요약 주기(5~10턴 OOC, 10~20턴 유저노트)를 플레이 가이드에 안내했고 크랙은 단축어로 등록했다
- [ ] 케이브덕이면 프롬프트 상태창을 빼고 위젯을 썼다(비밀과 글자 수 공유 확인)
- [ ] 군상극이면 캐스트 허용 목록, 한 턴 최대 2명, 인물별 고유 어미·반복 디테일, 관계·등장 계기가 있다
- [ ] 베이비챗 군상극은 스탯·이미지·다인 연기를 동시에 요구하지 않는다
- [ ] 엔딩 이후 떡밥이 프롬프트에 있다
- [ ] 등장인물 전원 성인·나이 명시
