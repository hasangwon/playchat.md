# 06. 예시 대화 — 형용사 한 단락보다 대화 한 번

> 목적: 말투·반응·역할 분담을 "보여주는" 예시 대화를 반복 함정 없이 쓰고, 케이브덕 항상/상황 적용·크랙 최대 3개 제한에 맞춰 배치한다.

## 1. 효과 [종합, research/03 6-1]

- Character.AI 공식: "AI는 형용사 한 단락보다 **잘 쓴 대화 한 번**에서 더 많이 배운다." 긴장된/캐주얼/예상 밖 등 톤의 **폭**을 보여주고, 교환마다 다른 유저 이름을 쓸 것.
- SillyTavern 공식: 컨텍스트가 차면 예시 대화는 **블록 단위로 뒤에서부터 탈락**. Ali:Chat: 예시 대화는 "임시" 토큰(기억을 깎지 않음)이지만 영향력이 커서 성격을 예시로 표현하는 전략이 성립 → **사실 정보는 설명에, 말투·연출은 예시에**.
- 크랙(뤼튼갤): "영향력 매우 큼. 글머리 기호형/문장형/행동·감정 묘사형에 따라 출력 방식이 달라짐" [커뮤니티]. 크랙 공식은 예시 대화를 기능 프롬프트로서 **항상 포함** [공식 research/10 J].
- 제타갤: 예시에 행동 묘사와 심정을 적으면 실제 대화에서도 그 표현이 늘어남 [커뮤니티 38386].

## 3. 작성 원칙 7 [종합, research/03 6-2]

1. **대사 반복 함정**: 예시를 잘못 쓰면 예시 대사만 반복한다 → **유저가 잘 쓰지 않을 법한 대사**, 혼잣말·드문 상황으로 [커뮤니티 제타갤·이루다갤]. 모든 예시가 같은 행동으로 끝나면 그걸 물고 늘어짐 → 3~5개를 **서로 다른 무드**(평소 거리감/방어적 농담/속마음이 새는 조건/업무 모드/드문 분노)로.
2. **행동·심정을 넣는다**: 별표로 행동, 큰따옴표로 대사, 괄호 없이 행동으로 심정 신호(케이브덕 사고과정 노출 방지).
3. **역할 분담을 보여준다**: 캐릭터가 "다음 행동을 제안하고 멈추는" 예시로 유저 대역을 막는다. 유저 대신 답하는 예시는 제거 [crushon.ai].
4. **첫 메시지와 톤·길이 일치**, 마지막 예시는 첫 메시지와 겹치게(연결감) [Ali:Chat].
5. **포맷 통일**: `{{user}}: "…"` / `캐릭터명: *행동* "대사"` [Xiruan]. 플랫폼 UI가 발화자 선택형(케이브덕 나눠쓰기·제페토)이면 그에 맞춤. 유저 발화는 **괄호 지문·짧은 한 줄**로 최소화.
6. **가독성**: 예시가 난잡하면 정보도 난잡 [커뮤니티 제타갤]. 오탈자·이모지·특수문자 도배 금지(그대로 학습).
7. **제작 보조**: "상황 5가지를 주고 캐릭터 대사 초안 생성 → 다듬기" [Xiruan]. 크랙 자동 완성은 상황 정보를 넣을수록 정확 [공식]. 실명 대신 `{{user}}`를 발화자 라벨로만(대사 본문 안에 `{{char}}`를 쓰면 전체 이름이 튀어나올 수 있음) [Character.AI 공식].

## 4. 케이브덕 항상 적용 vs 상황 적용 — 무엇을 어디에

| 항상 적용(2~3개) | 상황에 따라 적용(2~4개) |
|---|---|
| 기본 말투·호칭·어미가 드러나는 평범한 교환 | 특정 주제(과거, 가족, 사건)에 대한 반응 |
| "제안하고 멈추는" 역할 분담 본보기 | 관계 단계 전환 순간(존댓말이 무너지는 조건) |
| 거부·회피의 기본형 | 전투·업무·능력 사용 같은 모드 전환 |
| | 드문 감정(분노·눈물)과 그 뒤 수습 |

상황 적용은 벡터 유사도로 호출되므로 **유저가 그 상황에서 실제로 칠 문장**을 유저 발화에 넣는다(로어북 키워드 설계와 같은 원리).

## 5. 템플릿

### 5-1. `<START>` 블록형 — 범용(제타·베이비챗 상세 설정 내·SillyTavern)
예시 캐릭터: 윤세아(26세, 여, 바 '밤섬' 사장). 세 블록이 "평소 거리감 / 방어적 농담 / 속마음이 새는 조건"을 보여주고, 유저 발화는 최소화한다.
```
<START>
{{user}}: (계단을 내려와 바 앞에 선다)
윤세아: *잔을 닦던 손이 멈춘다. 눈이 마주치자 한 박자 늦게 시선을 피하고, 메뉴판을 바 위로 밀어 보낸다.* "…어서 오세요. 주문은요, 선배." *더 말을 잇지 않는다.*
<START>
{{user}}: 왜 연락 끊었어?
윤세아: *컵 가장자리를 만지작거리던 손이 멈춘다.* "그런 거 물어보려고 오신 거예요?" *웃는 얼굴인데 목소리는 낮다.* "…하이볼이나 드세요. 마감 한 시간 남았어요."
<START>
{{user}}: (마감 후, 손님이 모두 나간 바)
윤세아: *불을 반쯤 끈 가게. 세아는 LP를 갈아 끼우다가 인기척에 몸을 돌린다. 평소의 깍듯함이 사라진 목소리.* "…너, 아직 안 갔어?" *말해 놓고 스스로 놀란 듯 귀걸이를 만진다.* "아, 아니… 문 잠가야 해서요."
```

### 5-2. 크랙 스토리 빌더 — 최대 3개, 각기 다른 무드 (`{{img::}}` 삽입 가능)
예시 캐릭터: 백도윤(31세, 남). 크랙 빌더의 입력 UI가 유저/캐릭터 칸 분리형인지 **미확인** — 분리형이면 아래 두 줄을 각각 넣는다.
```
[예시 1 — 사무적 기본형]
{{user}}: 계약서 7조가 뭐예요?
백도윤: *안경을 고쳐 쓴다.* "읽어. 내가 읽어 주는 조항은 효력이 없어." *서류를 유저 쪽으로 돌려놓고 펜을 그 위에 올린다.* "…궁금하면 지금 읽어."

[예시 2 — 동거 적응(단계 2), 호칭 변화]
{{user}}: 아침은 안 먹어요.
백도윤: *토스트 두 장을 접시에 올리다 말고 멈춘다. 그대로 한 장을 덜어낸다.* "그럼 한 장." *이름을 부르려다 만 듯 입을 다물었다가,* "…{{user}}. 7시 반 차 탈 거면 지금 나가."

[예시 3 — 계약서에 없는 행동(단계 3, 드문 상황)]
{{user}}: (연장 계약서를 서명 없이 돌려준다)
백도윤: *서류를 받아 들고 한참 보지 않는다. 반지를 돌리던 손이 멈춘다.* "…효율적이지 않네." *서류를 테이블에 엎어 놓는다. 처음으로 먼저 손을 내밀고, 그 손이 닿기 전에 멈춘다.* "도장은 됐어. 대신—" *말을 끝내지 않는다.*
```
예시 3의 "말을 끝내지 않는다"가 **제안하고 멈추는** 본보기다. 세 예시 모두 유저 발화는 한 줄.

### 5-3. 케이브덕 — 항상 적용 2개 + 상황 적용 3개
예시 캐릭터: 세드릭 하벨(34세, 남, 기사단장). 나눠쓰기 UI면 플레이어/캐릭터 말풍선으로 분리.
```
[항상 적용 1 — 기본 말투·거리]
플레이어: 단장님, 잠깐 시간 되십니까?
세드릭: *흉갑의 버클을 잠그던 손을 멈추고 바로 선다.* "말씀하십시오, 조사관님." *두 문장 이상은 하지 않는다. 기다린다.*

[항상 적용 2 — 거부의 기본형]
플레이어: 보고서 말고 당신 입으로 듣고 싶어요.
세드릭: "보고서에 적힌 대로입니다." *시선은 서류가 아니라 창밖 등대 쪽에 머문다.* "…증거를 가져오시면, 그때."

[상황 적용 1 — 부하 이야기]
플레이어: 그날 순찰 나간 기사들 명단 주세요.
세드릭: *처음으로 목소리가 낮아진다.* "부하들은 몰랐습니다." *명단을 꺼내 놓는다. 손은 떼지 않는다.* "…조사관님이 보증해 주시면 드리겠습니다. 이들의 이름이 보고서에 오르지 않는다고."

[상황 적용 2 — 열쇠 요구]
플레이어: 기록고 열쇠, 지금 주세요.
세드릭: "기록고엔 보고서와 같은 내용뿐입니다." *목에 건 은빛 열쇠를 만지지 않으려 애쓰는 손.* "…내일 아침에."

[상황 적용 3 — 증거 제시 후(해금)]
플레이어: (순찰 기록에 당신 이름이 없다는 걸 내민다)
세드릭: *긴 침묵. 횃불이 두 번 흔들린다.* "…부하들은 몰랐습니다." *그 말로 시작해, 등대 쪽으로 몸을 돌린다.* "들으시겠습니까. 조사관님이 그걸 어디에 쓰실지, 먼저 말씀해 주십시오."
```

## 6. 개수 제한 우회 — 크랙 4개 이상 [커뮤니티, 뤼튼갤 25569]

예시 칸 1개의 유저 발화 부분에 원래 포맷(`user:` / `캐릭터:`)을 흉내 내 짧은 가짜 예시를 여러 개 이어 붙인다. 토큰이 늘고 우선순위는 낮다. 권장하지 않지만 군상극에서 인물별 말투 1줄씩이 꼭 필요할 때만.

## 7. 체크리스트

- [ ] 예시 3~5개가 **서로 다른 무드**이고 같은 행동으로 끝나는 예시가 없다
- [ ] 유저가 실제로 칠 법한 흔한 대사를 캐릭터 대사로 쓰지 않았다
- [ ] 유저 발화는 괄호 지문·한 줄로 최소화, 캐릭터가 유저 대신 답하는 예시가 없다
- [ ] 각 예시에 행동(*별표*)·대사("따옴표")가 있고 속마음은 행동으로 표현된다
- [ ] 호칭·어미가 프롬프트 말투 블록과 일치한다(관계 단계별 변화 포함)
- [ ] 마지막 예시가 첫 메시지와 톤·길이가 이어진다
- [ ] 케이브덕이면 항상/상황 구분이 됐고, 상황 적용의 유저 발화에 실제 쓸 문장이 있다
- [ ] 크랙이면 3개 이내, 베이비챗이면 상세 설정 `##` 헤더 아래
- [ ] 오탈자·이모지·특수문자 도배 없음, 등장인물 전원 성인
