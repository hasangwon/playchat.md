## 2. 프롬프트 vs 로어북 배분표 [종합, research/03 2-2]

| 프롬프트(상시, 매 턴 읽힘) | 로어북(조건부, 키워드 발동 시) |
|---|---|
| 시대·장소·기본 규칙 **한 줄씩** (3줄 이내) | 지명·조직·역사·용어의 상세 |
| 캐릭터 시점에서 본 관계(누가 누구를 어떻게 생각하는지) | 객관적 정보(동네, 가게, 규칙, 조연 프로필) |
| 매 턴 영향을 주는 금지/세계 규칙("현대 문물 없음") | 특정 키워드가 나올 때만 필요한 TMI |
| 시작 시점의 긴장(지금 무엇이 걸려 있는가) | 챕터/이벤트별 설정, 비밀의 진상 |

판정 질문: **"이 정보가 없으면 평범한 턴에서 캐릭터가 이상해지는가?"** 예 → 프롬프트. 아니오 → 로어북.

플랫폼별 근거:
- 유니챗: 세계관 문서와 프롬프트가 충돌하면 **프롬프트 우선**. 캐릭터 간 관계는 세계관이 아니라 각 캐릭터 프롬프트에 [research/03 2-2].
- 투킷/베이비챗 공식: "핵심 설정은 상세 설정에, 필요할 때 꺼내 쓸 부가 정보·세계관은 로어북에" [공식].
- 케이브덕: 세계관 칸은 여러 캐릭터가 **공유**하는 단위 [공식 research/09 D-1] → 공유 가능한 객관 정보만 세계관에, 캐릭터별 시점은 설명 칸에.
- Xiruan: 항상 출력할 필요 없는 조연 상세는 로어북으로 분리해 프롬프트 용량을 줄인다 [커뮤니티].

## 3. 세계관 작성법

### 3-1. 시대·장소·규칙은 "존재할 수 없는 것"까지 [커뮤니티, 와따]

조선풍 캐릭터가 파스타를 권하는 식의 붕괴를 막으려면 금지 요소를 명시한다.
```
이 캐릭터가 사는 시대는 ○○년이며, 중식·양식·일식 등은 존재하지 않습니다.
```
사극풍 말투·과거형 표현 지시를 함께 넣는다. 인트로에 현대 문물이 섞이면 이후 전부 오염되므로 세계관 금지 규칙과 인트로를 **일치**시킨다 [research/03 5-5].

### 3-2. 압축법 [커뮤니티, 제타갤 159084]

- "AI는 1,000자를 한 번에 인지하지 않고 대략 150자 단위로 대화한다"(저자 추정) → 기호·구조(`#`, `##`, `-`)와 함축 표현으로 줄인다.
- 반복 용어는 상위 항목 + 하위 불릿으로 묶는다(「미초아칸 카르텔」 → 장악 지역 / 악명 / 라이벌과 10년 분쟁).
- **초반에만 중요한 설정은 인트로에, 반복 상기할 설정은 예시 대화에** 넣고 세계관 칸에서 뺀다.
- 세계관을 **여러 항목에 분산**: 세계관 칸에만 두지 말고 상황·말투·캐릭터 특징에 녹이면 어느 항목을 읽든 참조돼 고정률이 오른다.

### 3-3. 구조: 기본 설정 + 스토리 배경 [공식, 제페토 예시 구조]

제페토 공식 예시(조선 궁궐 로맨스)는 "기본 설정(신분제, 남장 의녀)"과 "스토리 배경(세자를 만나 궁을 빠져나가야 하는 목표, 정체 발각 시 역적, 궁 안 세력 다툼)"을 분리한다 [research/03 2-3]. 즉 **규칙 → 목표 → 위험 → 세력** 순.

### 3-4. 세계관 블록 템플릿 [종합]

```markdown
# 세계관
- 시대/장소: 2026년 서울 을지로 뒷골목 (현대)
- 핵심 규칙(3줄 이내): 바 '밤섬'은 {{char}} 혼자 운영한다 / 단골 외 손님은 드물다 / 영업은 저녁 7시~새벽 2시
- 지금 이 이야기의 긴장: {{user}}는 2년 전 말없이 떠난 전 동업자이고, {{char}}는 떠난 이유를 아직 묻지 않았다
- 금지: {{char}}가 먼저 과거를 설명하지 않는다 / 제3자(다른 손님)는 {{user}}가 언급하기 전엔 등장하지 않는다
(가게 내부 구조·메뉴·단골 명단·2년 전 사건의 진상은 로어북으로)
```

판타지 예시:
```markdown
# 세계관
- 시대/장소: 에르나 공국 북부 국경, 중세 후기 수준. 화약 없음, 마법은 '등대지기'만 쓴다
- 핵심 규칙: 마법은 대가(기억)를 요구한다 / 신분제 존재(공작-기사-평민) / 국경 너머는 금지 구역
- 지금 이 이야기의 긴장: {{user}}는 공국 조사관(28세)이고, {{char}} 세드릭 하벨(34세, 기사단장)은 '붉은 등대 사건'의 책임을 추궁당하고 있다
- 금지: 현대 음식·기기·인터넷 언급 금지 / 죽은 인물 부활 금지 / {{char}}는 사건의 진상을 유저가 증거를 제시하기 전까지 말하지 않는다
(공작 가문·등대 사건·은빛 열쇠·요새 '칼드'는 로어북으로 → 04-lorebook.md 예시)
```

## 4. 시작 상황 설계

### 4-1. 시작 상황은 휘발된다 [커뮤니티, 뤼튼갤 76734·69098]

크랙 테스트 기준 **30~50턴이 지나면 시작 상황 프롬프트가 사라진다**. 단, 크랙 공식 "프롬프트의 이해"는 기능 프롬프트(예시 대화·미디어·시작 설정·키워드북) 중 **키워드북만 조건부이고 나머지는 항상 포함**된다고 적는다 [공식 research/10 J] → 공식과 커뮤니티가 상충하며 실측 **미확인**. 어느 쪽이든 안전한 설계는 같다:
- 시작 상황에는 **초반에만 필요한 내용**(첫 장면의 시간·장소·분위기, 상태창·줄바꿈 같은 초반 기강)만 넣는다.
- **중심 설정은 반드시 상세 프롬프트**에 둔다.
- JanitorAI Scenario 원칙: 항상 유효한 정보(배경·규칙)만 넣고 **현재진행형 임시 사건은 넣지 말 것** — 봇이 그 사건이 영원히 지속된다고 가정한다 [종합, research/03 2-4].

### 4-2. 조건·분기·변화 후 출력을 명시한다 [커뮤니티, 제타 여성향갤 15348]

혐관인데 "거부하면 무조건 순응"하는 문제는 금지문으로 못 고친다. 다음 셋을 적는다.
```
# 관계 변화
- 변화 조건(트리거): 마감 후 단둘이 남고, {{user}}가 떠난 이유를 다그치지 않고 기다릴 때
- 분기점: 조건 충족 → 존댓말이 반말로 무너지는 한 문장이 섞인다 / 미충족 → 존댓말·"선배" 유지, 화제를 주문으로 돌린다
- 변화 후 출력: 호칭 "선배"→"너", 어미 "~요"→"~거든", 말 길이는 그대로 짧게
- 조건 충족 예: "…너, 아직 안 갔어?" / 미충족 예: "주문 안 하실 거면 마감이에요, 선배."
```

### 4-3. 복수 시작점 패턴 [공식+종합, research/03 5-6]

| 축 | 예 |
|---|---|
| 관계별 | 소꿉친구로 시작 / 적으로 시작 / 상사로 시작 |
| 시간대별 | 개업 전날 / 재회 당일 / 1년 후 |
| 팩션별(시뮬) | 기사단 소속 / 공작가 소속 / 조사관 |
| 난이도별 | 혐관 시작(어려움) / 호감 시작(쉬움) |
| 유저 페르소나별 | 남성 유저용 / 여성 유저용 (케이브덕 추천 페르소나를 에피소드별로) |

**시작점끼리 합쳐지지 않는다** — 크랙 시작 설정은 하나만 선택됨 [커뮤니티 뤼튼갤 76734], 케이브덕 에피소드도 각각 독립 [공식]. 공통 설정은 프롬프트에, 시작점 고유 정보만 각 시작 설정에.

## 5. 플랫폼 기능 활용

### 5-1. 케이브덕 세계관 관리 [공식 research/09 D-1·E, research/02 2.1]

- 기본 정보 탭의 **세계관(선택)**: 제목 60자 / 설명 10,000자. '세계관 관리' 메뉴에서 여러 캐릭터가 **공유**하고 일괄 수정.
- 세계관을 공개하면 청소년 이용 불가 여부를 필수 설정. 홈 상단 탭에 '캐릭터 / 세계관'이 별도로 있어 세계관 자체가 노출 단위 [실측 research/08].
- 활용: 군상극·시리즈는 세계관 1개 + 캐릭터 N개로 만들고, 캐릭터별 시점·관계는 각 캐릭터 설명에 쓴다. 세계관 공유 시 **오리지널 등록 조건**("세계관만 공유하고 캐릭터 설정이 다르면 가능") [공식 research/09 B]도 충족된다.
- 에피소드(최대 3개, 각 10,000자)마다 **비밀·문체 프롬프트·추천 페르소나·추천 모델**을 따로 둘 수 있다 [공식 research/09 D-2·E] → 같은 캐릭터를 소꿉친구/적/상사로 다르게 시작.
- 시작 대사 형식: 줄글(캐릭터 1인 대사) 또는 **나눠쓰기**(캐릭터/플레이어/지문 말풍선 최대 10개) → 군상극·지문 분리에 유리.

### 5-2. 크랙 시작 설정 [공식 research/10 I-3·I-4·I-8]

스토리 빌더 3단계. 최소 1개 필수, '설정 추가'로 복수.
| 필드 | 내용 |
|---|---|
| 시작설정 이름(필수) | 유저가 고르기 쉽게 내용이 드러나는 이름(예: "재회 당일", "개업 전날") |
| 시작 상황 | 세계관 추가. 공식 예시: "학창 시절/대학 시절/결혼 이후"처럼 상황별 시작점 — 우리는 성인 시점만 사용 |
| 프롤로그(필수) | 첫 인사말. `{{img::이미지 이름}}`로 이미지 삽입. 우측 채팅 미리보기 |
| 플레이 가이드(선택) | **유저에게만 보임**(AI 미기억) — 조작법·추천 페르소나·주의사항 |
| 추천 답변 | 최대 3개, 미지정 시 AI 자동 생성 |

시작 설정별로 **스탯(최대 7개, 레벨 구간 4개, 레벨 프롬프트 100자)**과 **엔딩(턴 수 최소 10, 스탯 조건)**을 따로 건다 [공식 research/10 I-4·I-8]. 스탯은 분기 엔진, 상태창은 표시용으로 역할을 나눈다.

### 5-3. 베이비챗/투킷·제타

- 베이비챗: 시작 시나리오 **최대 3개**(이름 10자 권장, 첫 상황 1,000자, 첫 대사 500자, 추천 답변 3×200자) [공식 research/02 3.1]. 실측 미리보기에 '첫 대화 날짜·상황묘사' 항목도 있음 [research/07] — 필드 상세 **미확인**.
- 제타: 인트로 1개 필수. 상태창(스타일 탭)에서 배경(날짜·시간·장소·날씨·상황) 항목의 첫 장면 값을 인트로 탭에 입력 [공식 research/02 5.1].

## 6. 체크리스트

- [ ] 세계관 블록이 시대/장소·규칙 3줄·긴장·금지 네 항목으로 끝난다(상세는 로어북)
- [ ] "존재할 수 없는 요소"가 금지에 적혔고 인트로가 그것을 어기지 않는다
- [ ] 캐릭터 간 관계는 세계관이 아니라 캐릭터 프롬프트에 있다
- [ ] 시작 상황에는 초반에만 필요한 내용만 있고, 중심 설정은 프롬프트에 중복돼 있다
- [ ] 현재진행형 임시 사건을 시작 상황에 넣지 않았다
- [ ] 관계 변화의 조건·분기·변화 후 출력(예시 포함)이 적혔다
- [ ] 복수 시작점이 있으면 각각 독립적으로 읽히고, 공통 설정은 프롬프트에 있다
- [ ] 케이브덕이면 세계관 공유 여부·청불 여부를 정했다 / 크랙이면 시작 설정 이름이 내용을 드러낸다
- [ ] 등장인물 전원 성인·나이 명시, 학교·교복 배경 없음
