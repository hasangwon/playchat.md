## 2. 도구별 실무 메모

### 2-1. Nano Banana Pro / 2.1 — 마스터·표정 세트·한글 텍스트의 기본값
- 레퍼런스 한도: 캐릭터 4장(2.1/3.1 Flash) / **5장(Pro)**, 오브젝트 최대 14(Lite)/10/6(Pro), 스타일 레퍼런스 3장(Pro). `previous_interaction_id`로 다중 턴 편집. [공식] https://ai.google.dev/gemini-api/docs/image-generation
- 커뮤니티 베스트 프랙티스 [커뮤니티, 디시 특이점 갤러리] research/04 §3-1·§6-1: **3:4·2K·정면 하프샷** 마스터, 한국어 프롬프트 그대로 OK, 1K 초안 다량 → 선별 → 업스케일, `noise/JPEG artifact/VHS` 키워드 금지, 부분 수정은 ComfyUI(SDXL+8스텝 라이트닝 LoRA).
- 한계: NSFW 전면 불가, 격한 표정도 필터에 걸릴 수 있음, SynthID 워터마크(육안 비가시), 투명 배경 불가(단색 배경 → 누끼).
- 세이프티 프로필·상황 이미지 다량 제작과 **말풍선 한글**이 필요한 웹툰 컷에 최적.

### 2-2. GPT Image 2 / 2.5 — 스토리보드·보조
- 레퍼런스 최대 8장(image-2) [3rd], 출력물 소유권 사용자. 애니 질감이 회화적이라 메인 스타일로는 2순위. 콘티·스토리보드 초안, 한글 텍스트 보조에 적합.

### 2-3. Midjourney V8.2 — 배경·키비주얼
- Edit Model(레퍼런스 4장)로 캐릭터 유지 가능하나 다컷 일관성은 SD/NAI보다 약함. **배경·오브젝트·브랜드 키비주얼**에 쓰고, 인물 차분은 다른 툴로.

### 2-4. SD/ComfyUI(Illustrious · NoobAI · Animagine) — 대량 차분·정밀 제어
- danbooru 태그로 표정·구도를 가장 정밀하게 제어. IP-Adapter(얼굴 weight 0.7~0.85, end 0.8~0.9) + ControlNet(OpenPose/Depth) + 시드 고정 + 캐릭터 LoRA. [3rd] research/04 §3-2
- **라이선스 주의**: NoobAI는 출력물 상업 이용 금지. 수익화 작품에는 **Animagine XL 4.0(OpenRAIL++-M)** 또는 라이선스를 확인한 Illustrious 파생만. Civitai 모델 페이지의 "Commercial use" 항목을 캡처해 `characters/<slug>/assets/LICENSE.md`에 남긴다 [프로젝트 규칙].
- 온라인 대안: Tensor.Art(일 100크레딧, 2025년 말 SFW 전환), Civitai(Buzz), SeaArt, PixAI. 로컬은 SDXL이면 RTX 20번대도 가능 [커뮤니티], FLUX는 40~50번대 권장.

### 2-5. NovelAI V4.5 Opus — 성인 캐릭터·애니 특화·상업 OK
- Precise Reference: Character / Style / Character&Style, strength(너무 높으면 표정·포즈까지 복제)·fidelity(프롬프트 덮어쓰기 저항) 조절, +5 Anlas, 인페인팅 병용, Vibe Transfer와 동시 불가. [공식] https://docs.novelai.net/en/image/precisereference/

### 2-6. 플랫폼 내장 생성기 — 정책 필터 선통과, 최종 보정용
- 크랙: 세이프티 한정. 프로필·미디어 탭 '생성' 버튼 → 프롬프트 1,000자·8스타일·5비율·최대 4장, **95크래커/장**. **변형은 업로드 파일에도 적용**(95크래커) → 외부에서 만든 마스터의 "한 끗" 표정·의상 변경 시험용. 95크래커 ≈ 95원/장 [추정]이라 대량 생성은 외부 도구가 유리. [공식] research/10 K
- 케이브덕: Quill10-Anime/Semi로 19+ 앨범까지 제작 → '민감부위 수정'으로 바로 가림 → 앨범 업로드. 갤러리에 게시된 타 크리에이터 프롬프트 참고 가능.
- 베이비챗: 레퍼런스+스타일 프리셋(로판/순정/동양화)으로 "같은 얼굴 표정만 변경". 130프로챗/장이라 **대량은 비쌈** → 외부에서 만든 세트의 **보정·추가 컷** 용도.
- 제타: 스냅샷 15피스. 캐릭터별 5장 한도라 대량 필요 없음.
