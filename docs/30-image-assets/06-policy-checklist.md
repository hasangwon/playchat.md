## 1. 사용법

1. 에셋 1세트(프로필·표정·상황·인트로·엔딩)를 `export/<platform>/`에 모은다.
2. §2 공통 → §3 해당 플랫폼 → §4 가림(언세이프만) → §5 AI 표기 순으로 체크.
3. 하나라도 미통과면 업로드하지 않는다. 통과 결과(날짜·버전)를 `characters/<slug>/status.md`에 기록.
4. 프로필/썸네일은 **등급과 무관하게 세이프티 기준**으로 본다.

## 2. 공통 체크리스트 (모든 플랫폼, 모든 이미지)

### 2-1. 미성년 신호 — 하나라도 있으면 불가 (설정상 성인이어도)
- [ ] 얼굴: 앳된 얼굴·큰 눈 비율·둥근 볼이 "성인으로 읽히지 않음" 수준이 아니다
- [ ] 체형: 미성숙 체형·과도한 슬랜더(베이비챗 오인 검열 사례 [커뮤니티])가 아니다. 키·체형을 설정 카드에 성인으로 명시했다
- [ ] 의상: **교복·학생복·세라복·블레이저+주름치마** 없음 (전 플랫폼 공통 신호)
- [ ] 배경: **교실·학교·학원·폐교·과거 고교** 없음. 대학 강의실은 성인 외형·설정 명확할 때만(케이브덕)
- [ ] 소품: 책가방·학생증·명찰·교과서 등 학생 신호 없음
- [ ] 설정: 인간 캐릭터의 어린 시절·육아·보호 설정 없음(케이브덕 금지, 프로젝트 원칙)
- [ ] 나이가 프롬프트·소개에 숫자로 명시돼 있다(예: 28세)

### 2-2. 실사·실존 인물
- [ ] 실사풍·포토리얼·3D 실사 질감이 아니다(크랙·베이비챗·제타는 실사 오인 이미지 자체 금지, 케이브덕은 AI 표기 의무)
- [ ] 실존 인물(아이돌·배우·스트리머·지인) 얼굴·특징을 레퍼런스로 쓰지 않았다
- [ ] 딥페이크·합성 아님

### 2-3. 저작권·오리지널
- [ ] 타 작품 캐릭터·공식 일러스트·팬아트·타인 그림을 **레퍼런스로도** 쓰지 않았다
- [ ] 타인 저작 배경·로고·브랜드·단체 표장이 화면에 없다
- [ ] 생성 도구의 라이선스가 상업 이용 가능(NoobAI 출력물 제외)하며 `assets/LICENSE.md`에 기록했다
- [ ] 플랫폼 공식 콜라보(예: 크랙 QWER/ZB1)가 아닌 한 2차 창작이 아니다

### 2-4. 노출·폭력 (세이프티 기준 = 프로필·썸네일·인트로·소개 페이지)
- [ ] 속옷·란제리·비치는 옷·젖은 옷·찢긴 옷 없음
- [ ] 가슴·둔부·허벅지 강조 포즈/앵글 없음, 시선 유도 포즈 없음
- [ ] 나체·성행위 연상 자세·성적 접촉·성인용품 없음
- [ ] 수영복·운동복·전투복은 "일반 노출" 범위(민감 부위 강조 없음, 베이비챗 "신체 면적 절반 이상 노출" 아님)
- [ ] 혈흔·상해·절단·고어 없음(크랙 프로필은 혈흔 자체 금지, 상황 이미지도 과도한 혈흔 금지)
- [ ] 성적 암시 표정(과장된 입벌림·혀·유혹 눈빛) 없음(케이브덕·제타는 표정·자세도 제한)

### 2-5. 텍스트·기타
- [ ] 이미지 안에 비속어·성적 은어·정치 구호·시위 문구 없음
- [ ] 워터마크·타 플랫폼 로고·경쟁 서비스 URL 없음(케이브덕 경쟁 서비스 유도 금지)
- [ ] 움직이는 이미지(GIF/WebP)로 성행위 묘사 없음(크랙)
- [ ] 용량 5MB 이하(크랙·베이비챗), 형식이 플랫폼 허용 목록에 있음

### 3-2. 케이브덕 [공식] research/09 C-1·C-3·D-3·D-5
- [ ] 세이프티 캐릭터: 성적 암시(표정·자세 포함) 없음, 부위 강조·시선 유도 포즈 없음
- [ ] 실사/실존 인물로 보일 수 있는 이미지 → **"AI로 제작된 이미지" 설명 또는 이미지 내 명시**(§5)

- [ ] 언세이프 앨범: 성기·음모·항문·인접부 **불투명 유색(흰/검)** 가림, 모자이크·블러·시스루·피부색 가림 아님
- [ ] 치비(SD) 이미지는 비성적 용도(소개 페이지 장식·굿즈)로만

- [ ] 타깃 '전체' 선택 시 대표 이미지가 특정 성향에 치우치지 않음
- [ ] 크리에이터 프로필·소개란(HTML) 이미지는 세이프티 기준
- [ ] 앨범 100장 이하, 키워드 `smile` 통일, `random` 없음
- [ ] 금지 판정으로 업로드 차단된 이미지는 수정 후 재업로드 또는 **'이미지 재분류 신청'**(건전 이미지 오판이 잦음 [커뮤니티])

### 3-3. 베이비챗·투킷 [공식] research/04 §1-3, research/02 3.4
- [ ] 대표 이미지 1:1 5MB PNG/JPG/WebP, 민감 캐릭터여도 대표는 과도한 음란 없음
- [ ] 실제 인물 사진·딥페이크·**하이퍼리얼리즘** 아님
- [ ] 세이프티(14세+): 부분 노출까지만, 성행위·옷 위 성기 형태·여성 유두 없음, 신체 면적 절반 이상 노출 없음, 성적 도구·부위 강조 없음

- [ ] 스포일러·고수위 에셋은 **비공개** 설정
- [ ] 성인 등급 → 전체 등급 되돌리기 불가를 인지하고 등급을 정했다

### 3-4. 제타 [공식] research/04 §1-4, research/02 5.2

절차 [프로젝트 규칙]:
1. 생성 단계에서 네거티브에 `mosaic, censored_bar`를 넣어 자동 검열을 끈다(`05-prompt-recipes.md` §3-4).
2. 편집 툴에서 **단색 불투명 도형(흰 #FFFFFF 또는 검 #000000)**을 대상 부위와 윤곽까지 덮는다. 투명도 100%, 그라데이션·블러 없음.
3. 케이브덕은 아트 스튜디오 '민감부위 수정'(흰색 가림) 또는 앨범 [가리기] 버튼(베타)으로 대체 가능. 펜 가리기는 일반 제작자는 게시 불가 판정 이미지에서만.
4. 가림본은 `export/<platform>/`에, 무가림 원본은 `scene/raw/`에 분리 보관(실수 업로드 방지).
5. **세이프티 버전은 가림이 아니라 별도 생성**(의상 착용·포즈 변경). 가림 처리본을 세이프티로 올리면 등급 오지정 제재.
