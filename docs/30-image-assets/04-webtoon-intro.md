# 04. 인트로 웹툰 컷 제작 (패널·말풍선·세로 스크롤 → 플랫폼 삽입)

> 목적: 첫 인사말/프롤로그를 3~6컷 웹툰으로 연출해 첫 화면 몰입(대화 전환율)을 올리는 제작 절차와, 플랫폼별로 컷을 넣는 방법을 정리한다.

## 0. 먼저 알아둘 것

- **"웹툰 컷 삽입" 전용 기능은 4개 플랫폼 어디에도 없다.** 크랙 앱스토어 부제 '즉흥 서사 플레이'는 브랜딩이며, 실제로는 상황 이미지·첫 인사말 이미지 삽입이 컷 역할을 한다. [공식] research/04 §1-1, research/02 1.5
- 플랫폼은 **세로로 긴 이미지를 비권장**(크랙 정방형 기준)하므로, 세로 스크롤 한 장이 아니라 **컷 단위(1:1 또는 4:5)로 분할**해 올린다. 세로 스크롤 원본은 케이브덕 소개 페이지(HTML)나 외부 홍보용으로만.
- 인트로 컷도 **프로필과 같은 세이프티 기준**으로 만든다(크랙 프로필 이미지 내 비속어·성적 은어 금지, 제타 시위 문구 이미지 삭제 사례). 말풍선 문구는 짧고 중립적으로.

## 1. 플랫폼별 '컷'이 들어가는 자리

| 플랫폼 | 자리 | 규격 | 수량 | 근거 |
|---|---|---|---|---|
| **크랙** | ① 프롤로그(첫 인사말)에 `{{img::이름}}`으로 직접 삽입 ② 배치표 '인트로' 분류(자동 호출) ③ 이미지 보관함 해금과 결합해 "진행할수록 컷이 열리는" 연출 | 정방형 기준, 5MB, jpeg/png/webp/gif | 구 50장/시작설정, 신 총 1,600장 | [공식] research/10 G·I-3·I-5 |
| **케이브덕** | ① 에피소드 시작 장면 이미지(UI 첨부) ② 앨범 키워드 `intro`, `prologue` ③ 사용자 별도 설명(소개 페이지) HTML `<img>`로 세로 웹툰 전체 삽입 | 소개 페이지 15,000자(URL 포함), `max-width:100%;height:auto` | 에피소드 3개, 소개 페이지 글자수 내 | [공식] research/09 D-2·H |
| **베이비챗** | 첫 대사/상황묘사에 `img:[slug]`(제작 창 표기 확인) | 상황·배경 16:9, 감정 2:3(512×768) | 에셋 100개 내 | [공식] research/04 §1-3 |
| **제타** | 커버 이미지 최대 10장을 **인트로 컷 시퀀스**로 구성 [추정] + 나만의 소개글 이미지 5장 | 3:4 | 커버 10, 소개글 5 | [공식 수치] research/04 §1-4, research/02 5.1 |

## 2. 제작 흐름 7단계 (research/04 §4-3 기반)

### 2-1. 콘티 (3~6컷)
구조: **상황(원경) → 캐릭터 등장(중경) → 유저에게 말을 거는 컷(클로즈업)**. 컷마다 카메라 거리·대사 1줄·표정 키워드를 적는다.

```
[인트로 콘티 — 서하린 / 현대 로맨스 / 세이프티]
컷1 | 원경  | 비 그친 밤, 광고회사 옥상. 도시 야경, 젖은 바닥 반사. 인물 없음        | 대사: (없음)            | 비율 1:1
컷2 | 중경  | 난간에 기대 선 하린, 뒷모습 3/4, 바람에 머리 흔들림                    | 대사: "……또 야근이네."   | 1:1
컷3 | 중경  | 고개를 돌려 유저 쪽을 보는 하린, 살짝 놀란 표정(surprised)             | 대사: "왔어?"            | 4:5
컷4 | 클로즈업 | 정면, 살짝 비웃는 미소(smug), 시선 정면                             | 대사: "우산도 없이."      | 1:1
컷5 | 중경  | 손에 든 캔커피 하나를 내미는 하린, 표정 smile                           | 대사: "식었지만, 마셔."   | 4:5
```

### 2-2. 설정 카드·마스터 레퍼런스 확정
`03-consistency-workflow.md` §1~2. 팔레트·선 굵기·셀셰이딩 단계를 명시. 인트로 컷은 **표정 세트와 같은 도구·모델**로.

### 2-3. 컷 생성
설정 카드(고정) + 컷 변수(포즈·배경·소품·카메라·표정). 같은 툴·같은 모델·같은 레퍼런스. 프롬프트 끝에 **"배경에 읽을 수 없는 글자·다른 인물 넣지 말 것, 말풍선 없이"** 명시(말풍선은 후처리로).

Nano Banana Pro 컷 프롬프트 템플릿:
```
[설정 카드 전체 붙여넣기]

[컷 3]
구도: 1:1, 중경(허리 위), 카메라 눈높이, 캐릭터가 화면 오른쪽 1/3에 위치(왼쪽은 말풍선 자리로 비움).
배경: 비 그친 밤의 옥상, 난간, 멀리 도시 야경, 젖은 바닥의 반사.
동작: 난간에 기댄 채 고개를 왼쪽으로 돌려 카메라 쪽을 본다.
표정: 살짝 놀란 표정, 입 약간 벌림.
조명: 도시 불빛의 차가운 역광 + 얼굴에 약한 정면 보조광.
금지: 말풍선·글자·다른 인물·실사풍 없음.
```

### 2-4. 검수 4칸
얼굴·헤어 / 의상·주요 색 / 선 굵기·음영 / 소품 형태. 어긋나면 레퍼런스 품질·구도·강도·프롬프트·인물 수·모델 등급 6항목 점검(`03` §5-3).

### 2-5. 말풍선·텍스트 합성
- Nano Banana Pro는 한글 렌더링이 우수해 말풍선까지 한 번에 생성 가능하나 **오타·획 깨짐 검수 필수**. 소형 로고·긴 문구는 디자인 툴 후처리가 안전. [커뮤니티/3rd] research/04 §4-2
- 권장: 컷은 말풍선 없이 생성 → Clip Studio / Canva / Photopea에서 말풍선·폰트 합성 → `intro_03_text.png`로 별도 저장(원본 보존).
- 말풍선 규칙 [프로젝트 규칙]: 한 컷 1~2개, 12자 이내, 비속어·성적 은어 없음, 얼굴을 가리지 않게, 모바일 썸네일에서도 읽히는 크기(컷 짧은 변의 1/12 이상).

### 2-6. 플랫폼 규격 재단
크랙 1:1(5MB, webp 권장) / 베이비챗 16:9 또는 2:3(512×768) / 제타 3:4 / 케이브덕 2:3·1:1. 파일명은 크랙 `인트로_01`(분류 `인트로`), 케이브덕 키워드 `intro`.

### 2-7. 등록·테스트
배치표/키워드/Slug 매핑 → 실제 플레이로 호출 타이밍·대사 겹침 확인.

## 4. 플랫폼별 삽입 방법

### 4-1. 크랙
**방법 A — 프롤로그 직접 삽입** [공식] research/10 G·I-3
1. 스토리 빌더 5단계 미디어에 `인트로_01.webp` ~ `인트로_05.webp` 업로드(파일명 `분류_상황`).
2. 3단계 시작 설정 > 프롤로그에 삽입. 이미지는 `**` 상황 묘사 태그 **바깥·별도 줄**.
```
{{img::인트로_01}}

**비가 그친 밤. 광고회사 옥상에 젖은 바닥이 도시의 불빛을 되비춘다.**

{{img::인트로_02}}

하린 | "……또 야근이네."

{{img::인트로_03}}

**인기척에 고개를 돌린 하린이 당신을 본다.**

하린 | "왔어? 우산도 없이."

{{img::인트로_05}}

하린 | "식었지만, 마셔."
```
- 표기는 `{{img::이름}}` / `{{img: 이름}}` 중 빌더 미리보기에서 렌더링되는 쪽을 사용(`01-specs-by-platform.md` §1-2).
- 캐릭터 빌더(상황 이미지 50개)에서도 인트로 필드에 같은 방식으로 삽입 가능하나, 캐릭터 빌더의 `{{img}}` 지원 여부는 **미확인** → 실측.

**방법 B — 배치표 자동 호출** [공식] research/10 I-5
- 분류 `인트로`, 상황 `01~05`로 올려 배치표에 두면 AI가 상황에 맞춰 호출. 호출 타이밍을 제어할 수 없으므로 **인트로는 방법 A를 기본**으로, 배치표는 후속 컷(해금 힌트 "첫 만남 이후 비 오는 날" 등)에 쓴다.
- **이미지 보관함 해금** [공식] research/04 §1-1: 인트로 이후 컷을 해금 요소로 설계하면 "진행할수록 컷이 열리는" 웹툰식 연출.

### 4-2. 케이브덕
- **에피소드 시작 장면 이미지**: 에피소드(최대 3개) 시작 대사에 UI로 이미지 첨부 [공식] research/09 D-2. 텍스트 삽입 문법은 **미확인**. 나눠쓰기(말풍선 최대 10개) 모드와 결합하면 컷+대사 교차 구성이 가능.
- **앨범 키워드**: `intro`, `prologue`로 올려 첫 턴 맥락에서 호출되게. 키워드는 상황을 특정하는 단어만.
- **소개 페이지(사용자 별도 설명)에 세로 웹툰 전체 삽입** [공식] research/09 H:
```html
<div style="width:100%;max-width:640px;margin:0 auto;">
  <img src="https://(케이브덕 업로드 또는 공개 URL)/intro_scroll_01.webp" style="max-width:100%;height:auto;display:block;">
  <img src="https://(공개 URL)/intro_scroll_02.webp" style="max-width:100%;height:auto;display:block;">
  <p style="font-size:13px;color:#888;">AI 생성 이미지</p>
</div>
```
  - 허용 태그 `div p span b strong i em br hr img a`, 인라인 style만. `h1~h6`·`table`·`<style>`·script 불가. 15,000자 제한에 URL 글자수 포함 → 짧은 URL 사용. 소개란 이미지는 **세이프티 기준**.

### 4-3. 베이비챗
- 캐릭터 에셋에 인트로 컷 업로드(16:9 또는 2:3) → 제작 창에서 Slug 확인 → 첫 대사/상황묘사에 삽입 [공식] research/04 §1-3, [실측] research/07
```
img[k3p9a]
비가 그친 옥상. 젖은 난간에 기대 선 하린이 인기척에 고개를 돌린다.
img[m7q2c] 하린 | "왔어? 우산도 없이."
```
- 규칙: 내부 에셋과 외부 `![](URL)` 혼용 금지, 키워드 유도 문구 금지, 프롬프트에 코드 분류표 + "코드 임의 생성 금지". 스포일러 컷은 **비공개** 설정.
- 세로 긴 컷은 외부 이미지로만 가능하나 혼용 금지 규칙 때문에 **내부 에셋 2:3·16:9로 통일** 권장.

### 4-4. 제타
- **커버 10장 = 인트로 시퀀스** [추정]: 1장은 캐릭터 얼굴(사실상 썸네일), 2~6장은 콘티 순서대로 컷, 나머지는 세계관·장소 컷. 3:4 재단, 중요 요소 중앙(구 1:1 좌우 크롭 사례).
- 나만의 소개글(10,000자 + 이미지 5장, 마크다운)에 컷 5장 + 한 줄 캡션 [공식] research/02 5.1.
- 대화 중 자동 삽입 기능은 미확인이므로 인트로 텍스트에는 이미지 문법을 쓰지 않는다.

## 6. 인트로 컷 체크리스트

- [ ] 콘티 3~6컷, 원경→중경→클로즈업 순서, 마지막 컷이 유저에게 말을 건다
- [ ] 표정 세트와 같은 도구·모델·레퍼런스로 생성, 검수 4칸 통과
- [ ] 컷은 1:1 또는 4:5, 세로 긴 한 장 아님(크랙 비권장)
- [ ] 말풍선 문구 12자 이내·비속어/성적 은어 없음·얼굴 안 가림, 한글 오타 검수
- [ ] 프로필과 동일한 세이프티 기준(노출·혈흔·교복·학교 배경 없음)
- [ ] 크랙: `{{img}}`를 `**` 바깥 별도 줄, 파일명 `인트로_NN`, 미리보기에서 렌더링 확인
- [ ] 케이브덕: 시작 장면 이미지 첨부, 소개 HTML은 허용 태그만·공개 URL·"AI 생성 이미지" 표기
- [ ] 베이비챗: Slug 대응표 기록, 내부/외부 혼용 없음, 스포일러 컷 비공개
- [ ] 제타: 커버 3:4·10장 이내, 1장은 얼굴, 텍스트 최소
- [ ] 원본(`intro/`)과 말풍선 합성본(`_text`)·플랫폼 재단본(`export/`) 분리 저장
