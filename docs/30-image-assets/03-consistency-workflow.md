## 0. 전체 흐름

```
설정 카드(텍스트) ──▶ 마스터 레퍼런스 2장 ──▶ (필요 시) 캐릭터 시트 ──▶ 표정 세트 9~15종 ──▶ 상황 컷·배경 ──▶ 배경 분리·재단 ──▶ 파일명·매핑 ──▶ 플레이 테스트
      │                    │                                                   │
      └─ 모든 생성에 그대로 반복 ─┘                        베스트 1장을 다음 레퍼런스로 승격(원본 마스터는 보존)
```

원칙 3가지 (research/04 §3-1·§5-4):
1. **고정값은 텍스트로, 변수만 바꾼다** — 설정 카드(외형·의상·소품·화풍·금지)를 모든 프롬프트 맨 앞에 그대로 붙이고, 장면 변수(포즈·배경·소품·카메라 거리·표정)만 교체한다. 흔들리면 스타일 단어를 더하지 말고 고정값을 앞으로.
2. **한 캐릭터 = 한 도구·한 모델** — 체크포인트+LoRA 조합 또는 상용 모델 하나로 고정.
3. **레퍼런스 파일은 항상 같은 것** — IP-Adapter·Precise Reference·NB 레퍼런스에 매번 동일 파일 투입. 세션을 바꿀 때 새 세션으로(같은 세션에서 인물·구도를 크게 바꾸면 첫 입력 영향이 남음 [커뮤니티]).

### 4-2. 도구별 생성 절차 (research/04 §3-3)

**A. Nano Banana (세이프티, 가장 간단)**
```
[마스터 A 업로드]
이 캐릭터의 얼굴·머리·의상·조명·카메라 구도를 그대로 유지하고 표정만 "{표정 설명}"으로 바꿔줘.
배경은 단색 #00FF00. 글자·다른 인물 없이. 3:4 비율.
```
- 표정당 1장씩. 3×3 그리드로 한 번에 뽑으면 분할 시 얼굴 해상도 저하 → 1K 초안 → 선별 → 업스케일.
- 격한 표정·혀 내밀기·입 안 물체는 필터에 걸리는 사례 [커뮤니티].

**B. NovelAI V4.5**
- 마스터 A를 Character Reference로 투입. 방법 1: `expressions, multiple views, reference sheet, no text` + 표정 태그로 시트 1장 생성 후 분할. 방법 2: Precise Reference strength를 낮추고 표정 태그만 바꿔 개별 생성(strength 과다 시 표정까지 복제됨).

**C. ComfyUI (Illustrious / Animagine / NoobAI)**
- 베이스 프롬프트(설정 카드 태그) + IP-Adapter(마스터 A, 얼굴 weight 0.7~0.85, end 0.8~0.9) + **시드 고정** → 표정 태그 9종을 Prompt Scheduling / 문자열 리스트 노드로 배치 실행. 필요 시 ControlNet OpenPose로 머리 각도 고정. 배경 태그 `simple background, green background`. [3rd] research/04 §3-2
- 단어 하나만 바꿔도 결과가 흔들릴 수 있으니 시드 고정만 믿지 말고 IP-Adapter와 병행.

**D. 플랫폼 내장**
- 베이비챗: 캐릭터 에셋 > AI로 생성 > 레퍼런스에 마스터 A → "표정만 변경" 시리즈, **비율 3:4 또는 2:3 선택**(512×768 권장과 맞춤). 130프로챗/장이므로 9종 = 1,170프로챗.
- 케이브덕: 아트 스튜디오 > 이미지 편집(원본 인물 유지) → 표정 변경 → 앨범 업로드 시 키워드 통일.

### 4-3. 표정 세트 검수
- [ ] 9종 모두 얼굴 크기·머리 위치·카메라 거리가 동일(겹쳐 보면 윤곽이 일치)

## 5. 상황 컷·배경

### 5-1. 상황 컷
- 설정 카드(고정) + 장면 변수: `구도(거리·앵글) / 배경(장소·시간대·날씨) / 포즈·동작 / 소품 / 표정 / 시선`.
- 레퍼런스: NB는 마스터 A+B(+시트 1~2장), NAI는 마스터 B Character Reference, ComfyUI는 IP-Adapter + 필요 시 ControlNet Depth/OpenPose.
- 비율은 **처음부터 플랫폼 비율로 지정**(1:1 크랙 / 2:3 케이브덕·베이비챗 / 3:4 제타 / 16:9 배경). 나중에 크롭하면 구도가 깨진다. research/04 §5-4
- 다인 장면은 일관성이 급격히 떨어짐 → 1인 컷을 따로 뽑아 합성하거나 2인까지만.

### 5-2. 배경(인물 없음)
- "인물 없음, 빈 장소"를 명시하고 16:9로 생성. 같은 장소의 낮/밤/비 3종을 같은 시드·같은 레퍼런스로.
- 크랙 배치표용 1:1은 16:9 원본의 중앙 또는 포인트 영역을 크롭.
- 인트로 컷 합성용 배경은 캐릭터 누끼 PNG와 겹쳐 쓰므로 조명 방향을 설정 카드와 맞춘다.

### 5-3. 검수 4칸 (research/04 §4-3)
| 칸 | 확인 |
|---|---|
| 얼굴·헤어 | 눈 모양·눈색·앞머리·머리 길이 |
| 의상·주요 색 | 팔레트 hex와 대조 |
| 선 굵기·음영 | 외곽선 두께·셀셰이딩 단계 |
| 소품 형태 | 시계·귀걸이·검·반지 등 시그니처 |

어긋나면 6항목 점검: 레퍼런스 품질 / 구도(얼굴 크기) / 레퍼런스 강도 / 프롬프트(고정값 순서) / 인물 수 / 모델 등급.

## 6. 배경 분리·투명 배경·후처리 (research/04 §3-4)

- Nano Banana에 "투명 배경"을 요청하면 **체크무늬를 그려 넣음** → 순녹색(#00FF00)/마젠타 단색 배경으로 생성 후 크로마키 또는 `rembg`(BiRefNet/ISNet)로 누끼. [커뮤니티]
- 로컬: rembg(Python, BiRefNet), Photoshop '피사체 선택', Clip Studio, Photopea(무료 웹), remove.bg. 머리카락 가장자리는 BiRefNet 계열이 우수.
- **투명 PNG가 꼭 필요한 경우만** 만든다: 웹툰 컷 합성, 배경 교체. 베이비챗 2:3 에셋·케이브덕 앨범·제타 3:4는 배경 있는 이미지도 무방.
- 업스케일: 1K 초안 → 선별 → 2K. 4K는 불필요. WebP 변환으로 5MB 이하(크랙·베이비챗 상한). GIF는 크랙 미디어만 허용.
- 언세이프 가림: 불투명 유색(흰/검) 도형만. 모자이크·블러·시스루·피부색 불가(`06-policy-checklist.md` §4).

rembg 예(로컬, Python):
```bash
pip install "rembg[cli]"
rembg i -m birefnet-general assets/expr/raw/hahrin_smile.png assets/expr/hahrin_smile.png
```
