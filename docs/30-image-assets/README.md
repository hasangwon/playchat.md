## 3. 표준 파이프라인 8단계 (플랫폼 공통)

근거: research/04 §7-2. 각 단계의 상세는 괄호 안 문서.

1. **기획·설정 카드** — 외형(머리·눈·피부·체형·나이감)·의상·소품·화풍·팔레트·"바꾸지 말 것"을 한 블록으로 고정. 플랫폼 등급(세이프티/언세이프티)과 2차 창작 여부 확정(제타는 오리지널만). (`05-prompt-recipes.md` §4, `06-policy-checklist.md`)
2. **마스터 레퍼런스** — 3:4·2K 정면 하프샷 1장 + 전신 중립 1장(단순 배경). 생성 직후 정책 체크(교복·실사·노출·텍스트). (`03-consistency-workflow.md` §1)
3. **표정 세트 9~15종** — 마스터 고정, 표정만 교체, 단색 배경. 파일명을 플랫폼 키워드로. (`03` §3)
4. **상황·배경 컷** — 16:9 배경 / 1:1 크랙 / 3:4 제타 커버 / 2:3 케이브덕·베이비챗. 인트로 3~6컷은 설정 카드+장면 변수. (`03` §4, `04-webtoon-intro.md`)
5. **후처리** — 누끼(rembg), 말풍선·텍스트(Clip Studio/Canva/Photopea), 2K 업스케일, WebP 변환(5MB 이하), 언세이프는 불투명 가림. (`03` §5, `04` §3)
6. **정책 셀프 체크** — 실사 유사 ✗ / 미성년 신호 ✗ / 타 작품·실존 인물 ✗ / 프로필은 세이프티 기준 / 케이브덕 실사풍은 AI 표기 / 타인 저작권은 수익화 제한. (`06`)
7. **등록·매핑** — 크랙 배치표(분류×상황·해금 힌트) / 케이브덕 앨범 키워드·잠금 / 베이비챗 Slug 확인·로어북 / 제타 커버 10·캐릭터 5. (`01` 각 플랫폼 절)
8. **플레이 테스트** — 표정 호출 타이밍·중복 호출·대사 겹침 확인 → 썸네일 A/B(표정·텍스트 유무) 후 교체. (`05` §7, `03` §7)
