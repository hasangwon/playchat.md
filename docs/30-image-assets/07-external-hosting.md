# 07. 외장 이미지(외부 호스팅) 방식 — 상위작 표준

> 목적: 크랙·베이비챗 상위작이 쓰는 "외부 호스팅 + 이미지 코드표" 방식을 그대로 따라 하기 위한 절차. **이 프로젝트의 기본 이미지 방식.** 플랫폼 업로드(상황 이미지 50장, 베이비챗 에셋 100장)는 보조.
> 근거: research/12(크랙 1위·베이비챗 랭킹·케이브덕 실측), research/10 D, research/02 3.2, Cloudflare R2 가격표(2026-10-21 확인).

## 1. 실측 사례
| 작품 | 호스팅 | 규칙 | 규모 |
|---|---|---|---|
| 크랙 베스트 1위 「게임 판타지 속 히든 클래스가 되다」 | 개인 도메인 `1.metel.uk` | `![](https://1.metel.uk/{G/R}/{캐릭터ID}/{상황코드}.webp)` + NPC·몬스터·지역 경로 별도 | 주연 22명 × 2모습 × 상황 17종 = 최대 748장 + NPC 37 + 몬스터·지역 |
| 베이비챗 남성향 랭킹 상위작 | `iioi9.com`, 개인 도메인 5곳+, **Cloudflare R2**(`pub-….r2.dev`) | `https://iioi9.com/AL1/{번호}.webp` | 파일 번호 230번대 → 200장+ |
| 케이브덕 공식 크리에이터 작품 | 케이브덕 자체 서버 `i.cvdk.io` | 앨범 업로드 후 URL을 텍스트로 사용 | — |

공통 관례: 코드표는 **제작자 고정댓글의 대댓글** 또는 별도 HTML 페이지에 공개, `/디버그`·`!디버그`(이미지·상태창 오류 복구) 단축어, "고정댓글 및 플레이가이드 확인" 안내.

## 2. 플랫폼별 허용
| 플랫폼 | 외부 URL | 비고 |
|---|---|---|
| 크랙 | 사용 중(1위작) | 금지 조항 없음. 정책 위반 이미지를 외부 링크로 우회하면 경고 없이 최고 제재 → 외장 이미지도 상황 이미지 기준 준수 |
| 베이비챗/투킷 | 공식 허용 | 내부(`img:[slug]`)와 외부 URL 중 **한 방식만** 쓰라고 공식 가이드 명시 |
| 케이브덕 | 자체 서버 URL 사용 | 경쟁 플랫폼 링크 금지. 앨범 업로드(키워드 자동 출력·잠금 수익)를 쓰는 편이 유리 |

## 3. 표준 절차
1. **상황코드표 고정**(전 캐릭터 공통). 최소 기본 세트:
   `0 기본 1 미소 2 웃음 3 슬픔 4 오열 5 삐짐 6 화남 7 경멸 8 설렘/부끄 9 놀람/당황` + 작품 전용 10번대(포옹·전투·부상 등). 언세이프 컷은 20번대 이상으로 분리.
2. **캐릭터 ID표**: 주연 0~, NPC는 별도 접두(`N/`), 배경은 `bg/`.
3. **생성**: NAI(Character Reference) 또는 로컬 SD+LoRA로 캐릭터 × 상황코드 일괄 생성 → webp 변환(장당 1MB 이하 목표).
4. **업로드**: `{도메인}/{캐릭터ID}/{상황코드}.webp` 규칙으로. 파일명은 숫자만(한글·공백 금지).
5. **프롬프트에 넣을 것**(이것만):
```
## 이미지 출력 규칙
- 장면의 중심 인물 1명의 감정에 맞는 이미지를 대사 앞 줄에 1장만 출력한다.
- 형식: ![](https://img.example.com/{ID}/{상황코드}.webp)  ← 별도 줄, 묘사 기호(*) 밖
- ID: 서하=0 지원=1 …
- 상황코드: 0 기본 1 미소 2 웃음 3 슬픔 4 오열 5 삐짐 6 화남 7 경멸 8 설렘 9 놀람
- 표에 없는 ID·코드는 만들지 않는다.
```
   군상극은 ID·코드표를 키워드북(인물별 엔트리)에 나눠 담아 프롬프트 글자 수(크랙 캐릭터 2,000자)를 아낀다.
6. **공개**: 고정댓글 대댓글에 코드표, 플레이 가이드에 `/디버그` 안내.
7. **디버그 단축어**:
```
/디버그 — 직전 답변의 이미지 줄을 다시 확인한다. 형식이 ![](https://…/{ID}/{코드}.webp)가 아니거나 표에 없는 값이면 올바른 값으로 고쳐 다시 출력하고, 상태창도 형식에 맞게 다시 출력한다. 이야기는 진행하지 않는다.
```

## 4. 호스팅 선택과 비용
| 선택지 | 비용 | 메모 |
|---|---|---|
| **Cloudflare R2 + 개인 도메인** (권장) | 무료 구간: 저장 10GB/월, 읽기(Class B) 1,000만 회/월, 쓰기(Class A) 100만 회/월, **전송량 무료**. 초과 시 저장 $0.015/GB·월, 읽기 $0.36/100만 회. 도메인 연 1~2만 원 | 작품당 약 0.7GB(700장×1MB) → 10GB면 작품 10개 이상 무료. `r2.dev` 기본 주소는 속도 제한이 있어 개인 도메인 연결 권장 |
| 케이브덕 자체 서버 | 무료 | 케이브덕 작품 전용 |
| 무료 이미지 호스팅 사이트 | 무료 | 성인 이미지 삭제·링크 만료 위험 → 비권장 |

## 5. 리스크
- 호스트가 내려가면 모든 이미지가 깨진다 → 원본은 `characters/<slug>/assets/`에 보관, 도메인은 작품 간 공용으로 1개 운영.
- 성인 이미지 호스팅은 호스트 약관 확인(R2는 불법 콘텐츠만 금지, 미성년 외형 절대 금지).
- 플랫폼 정책은 외장 이미지에도 그대로 적용(미성년 외형·실존 인물·노출 기준).
