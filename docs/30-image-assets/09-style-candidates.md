# 09. 그림체(작가 태그 블록) 후보 출처 — V5 기준

> 목적: 그림체를 처음부터 깎지 않고, 커뮤니티에 공유된 V5 그림체("그깎") 중에서 후보를 골라 비교컷을 뽑는다. 최종 선택은 사용자.
> 근거: research/15 B·C (2026-10-22 열람). 추천 수는 열람일 기준.
> 주의: 공유 글 다수가 "2차 공유 금지"를 달았다 → **프롬프트 원문을 이 저장소나 공개 장소에 옮기지 않는다.** 작품 폴더 `assets/style-card.md`에는 우리가 수정·확정한 최종 블록만 저장(저장소가 공개 저장소면 style-card는 .gitignore 처리 검토).

## 1. 프롬프트를 얻는 방법
- 대부분 이미지 EXIF(PNG)에 프롬프트가 들어 있다("exif 살아있음"). PNG 원본을 받아 NovelAI 화면에 끌어다 놓으면 프롬프트·설정이 불러와진다(또는 NovelAI Inspect).
- 브라우저 안에서 이미지 바이트를 읽는 것은 CORS로 막혀 있음(2026-10-22 확인) → **PNG 원본 다운로드가 필요**하고, 다운로드는 사용자 승인 후.
- 노션 모음 링크는 열람만(로그인 불필요한 공개 페이지).

## 3. 고르는 기준 (비교컷 판정)
1. **타깃 일치**: 남성향은 여캐 주력 작태, 여성향은 남캐 주력 작태(작가 태그만 넣고 1girl/1boy를 돌려 어느 쪽이 잘 나오는지 확인 — research/15 B 1246).
2. **고정 타율**: 같은 캐릭터 프롬프트로 4장 중 3장 이상 같은 얼굴 인상. 감정 세트가 10장 넘게 필요하므로 화려함보다 타율.
3. **플랫폼 정책 적합**: 어려 보이는 데포르메(큰 눈·치비 경향) 작태는 제외. 반실사는 실존 인물 유사·AI 표기 이슈(케이브덕 신고 사례) → 2D 우선.
4. **작은 크기 가독성**: 채팅창 썸네일 크기에서 표정이 읽히는지(얼굴 비중 큰 upper body로 확인).
5. 작가 태그 게시물 수 50개 이상(퀄업용 100개 이상)인지 Danbooru에서 확인.
