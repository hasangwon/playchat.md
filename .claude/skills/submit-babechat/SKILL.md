# 베이비챗 / 투킷 제출

## 0. 사전 조건
- `status: qa` 이상, `platforms`에 babechat 또는 tookit. 독점 충돌 없음.
- 스펙·리스크: `docs/10-platforms/babechat-tookit.md`(현금 출금 불가, 정산 Cap 논란, 성인→전체 등급 되돌리기 불가). 사용자가 리스크를 알고 선택했는지 확인.
- 실측(research/07): 스텝 탭 **프로필 → 캐릭터 설정 → 캐릭터 에셋 → 시작 상황 → 로어북 → 기타 설정 및 등록**, 우측 채팅 테스트 ≤10회, 상단 임시 저장. 제작 진입 시 "캐릭터 제작 시 반드시 유의해주세요" 동의 모달이 뜬다 → **사용자 확인 후 클릭**.

## 1. 변환본 만들기
`exports/babechat.md`:
- 프로필: 대표 이미지 1:1 ≤5MB / 이름 ≤20자 / 캐릭터 소개 ≤500자(투킷 250자, **AI에 전달됨** → §2-2 사용)
- 실측값 우선(research/14, 2026-10-22).
- 캐릭터 설정: 시스템 템플릿 선택 / 상세 프롬프트 **≤5,000자**(공식 7,000자와 다름, 마크다운, 페르소나·로어북 관련은 `###`부터) / 제작자 권장 모델 / 플레이 가이드
- 이미지: **외장 URL 방식(기본, 07-external-hosting.md 이미지 출력 규칙 블록)** 또는 내부 에셋(≤100장, 512×768, 감정/상황 선택 → 출력 `img[ID]`, ID = 에셋 탭 "이미지 코드") 중 **한 방식만**(공식 가이드).
- 시작 상황 ≤3: 이름 ≤10자(실측) / 첫 상황 ≤1,000자 / 첫 대사 ≤500자 / 추천 답변 ≤3×200자
- 로어북: 제목 / 키워드 ≤5×20자 / 내용 ≤500자, 동시 적용 5 또는 15, 편집 화면 제한 없음 → **50개 이하로 설계**
- 기타: 공개 범위 / 성향(전체·여성향·남성향) / 이용 대상(전체·성인만) / 카테고리 12종 / 해시태그 1~10 / B Only(100일) / 베이비챗·투킷 선택
- 메시지 말미 `info` 상태창은 관례(research/07)이나 선택.

## 2. 브라우저 작업
1. 새 탭 → `https://babechat.ai` → 좌측 사이드바에 프로필·최근 대화가 보이면 로그인 상태. `캐릭터 제작` → `+ 캐릭터 제작`.
2. 동의 모달이 뜨면 내용을 사용자에게 전달하고 **확인 후** `동의하고 캐릭터 제작하기`.
3. 탭 순서대로 입력, 글자 수 카운터(0/20, 0/500 등) 스크린샷 확인. 각 탭 `다음`, 중간중간 `임시 저장`.
4. 우측 `채팅 테스트`(필수 정보 입력 후, ≤10회)로 첫 대사·말투·이미지 호출 확인.
5. 등록 전 요약 → **등록/공개·B Only·성인 등급 설정은 사용자 확인 후**(성인→전체 되돌릴 수 없음).

## 3. 기록
- `status.md`에 URL·플랫폼(베이비챗/투킷)·등급·B Only 만료일·실측 제한(로어북 상한 등)을 기록하고 `docs/10-platforms/babechat-tookit.md` 갱신.

## 4. 하지 않는 것
- 로그인·본인인증·결제·베리 환전·약관 동의(확인 전)·사용자 확인 없는 공개·삭제.
