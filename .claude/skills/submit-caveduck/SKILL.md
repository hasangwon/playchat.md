# 케이브덕 제출

## 0. 사전 조건
- `status: qa` 이상, `platforms`에 caveduck 포함. 크랙 온리(18개월)·B Only 중인 작품은 불가.
- 스펙·정책: `docs/10-platforms/caveduck.md`, `research/09`(공식 문서 전체), 매핑 `templates/platform-mapping.md`.
- 제작 규정 핵심: 교복·학교 주배경·어린 외형 금지(설정상 성인이어도), 혈연 근친 금지, 실존 인물·타인 저작물은 수익화 제한 필수, 언세이프는 등장인물 전원 성인 외형, 앨범 이미지 가림은 불투명 유색.

## 1. 변환본 만들기
`exports/caveduck.md`:
- **기본 정보**: 이름 ≤50자 / 캐릭터 설명 ≤10,000자(전체 2,000토큰 권장 — §3 핵심만) / 세계관(제목 60·설명 10,000; 여러 캐릭터 공유 시 '세계관' 메뉴에서 생성)
- **에피소드 ≤3**: 시작 대사(줄글 또는 나눠쓰기 ≤10말풍선) / 비밀(유저 비공개) / 문체 프롬프트(1~2문장) / 추천 페르소나 가이드 ≤300자 / 추천 모델 ≤3 / 위젯(상태창; 프롬프트의 상태창 명령은 제거)
- **미디어**: 앨범 이미지(파일명=키워드 `smile`, `angry`…, ≤100장, 잠금 여부), 슈퍼 보이스(선택)
- **예시 대화**: 항상 적용(말투) / 상황 적용(특정 반응) 구분
- **키워드북**: 만들기 → 키워드북에서 먼저 생성(≤150, 키워드 `|`구분, 내용 400자, 영어 키워드 병기) → 캐릭터 전문가 모드에서 연결
- **공개 설정**: 공개 범위 / 세이프티 여부 / 타깃(남·여·전체) / 한 줄 소개 / 크리에이터 코멘트 / 태그 ≤10 / 연관 캐릭터 / 수익화 제한 / 스냅샷 / 오리지널 토글(3개월 해제 불가 — 사용자 확인)
- 변수 `{{user}}`, `{{char}}` 그대로 사용.

## 2. 브라우저 작업
1. 새 탭 → `https://caveduck.io/ko` → 우상단 `로그인` 버튼이 보이면 로그아웃 상태 → 사용자에게 요청 후 중단.
2. 좌측 `만들기` → (키워드북 먼저) → 캐릭터 만들기. `전문가 모드` ON. 탭 순서대로 입력, 토큰 카운터 확인(권장 초과 시 §3-1 확장부터 삭제).
3. 이미지 업로드 후 금지 판정 여부 확인(재분류 신청은 사용자 판단).
4. 저장 → 내 캐릭터 채팅방 청진기(🩺)로 설정·예시대화·키워드북 반영 확인(RAG → Keywordbook).
5. 공개 전 요약 스크린샷 → **공개 / 저장 후 번역 / 오리지널 토글은 사용자 확인 후**.

## 3. 기록
- `status.md`에 URL·등급·타깃·오리지널 여부(만료일 +3개월)·실측 필드 제한(대표 이미지 규격 등 미확인 항목) 기록 → `docs/10-platforms/caveduck.md` 갱신.

## 4. 하지 않는 것
- 로그인·본인인증·결제·출금 신청·약관 동의, 사용자 확인 없는 공개·삭제·오리지널 설정.
