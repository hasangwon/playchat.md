# 크랙 제출

## 0. 사전 조건
- `characters/<slug>/character.md`의 `status: qa` 이상. `platforms`에 crack 포함. 독점 충돌 없음(케이브덕 오리지널 3개월·B Only 100일 중이면 중단).
- 스펙·정책: `docs/10-platforms/crack.md`, 매핑: `templates/platform-mapping.md`, 공식 필드 제한: `research/10` H·I.
- 크랙 등록 시 **세이프티/언세이프티는 등록 후 변경 불가**, 2차창작은 언세이프티 불가. 등급을 사용자에게 재확인.

## 1. 변환본 만들기 (브라우저 열기 전)
`characters/<slug>/exports/crack.md`를 생성한다. 유형 선택:
- **캐릭터(5단계)**: 캐릭터 설정(프로필 이미지·이름 2~30자 특수문자 불가·한 줄 소개 30자) → 인트로(인트로·예시 대화·플레이 가이드) → 프롬프트(템플릿 5종 중 선택 + 캐릭터 프롬프트 ≤3,000자) → 고급 기능(상황 이미지 ≤50, 각 상황 묘사) → 캐릭터 상세(설명 ≤1,000자·장르·타겟·해시태그·공개 범위)
- **스토리(9단계)**: 프로필 → 스토리 설정(템플릿·설정 및 정보·예시 대화 ≤3) → 시작 설정(이름·시작 상황·프롤로그 `{{img::이름}}`·플레이 가이드·추천 답변 ≤3) → 스탯(≤7, 레벨 ≤4) → 미디어(파일명 `분류_상황`, 배치표) → 키워드북(≤20, 400자) → 단축어(≤20) → 엔딩(1,005×1,490) → 등록(상세 설명·장르·타겟·대화 형태·권장 모드·출력량·공개·등급·해시태그·댓글)
- 변수: `{{user}}` 유지, `{{char}}`는 이름으로 치환(지원 미확인), `[IMG: 이름]` → `{{img::이름}}` 별도 줄.
- 상태창 지시가 있으면 "답변 최하단에만 출력" 문구를 프롬프트에 포함(동일 답변 방지, research/10 F).

## 2. 브라우저 작업
1. `tabs_context_mcp` → 새 탭 → `https://crack.wrtn.ai` → 로그인 여부 확인(좌하단 "지금 로그인하고" 문구가 있으면 로그아웃 상태 → 사용자에게 로그인 요청 후 중단).
2. 상단 `내 작품` → 빌더 진입(캐릭터/스토리). 단계마다 `read_page`(interactive)로 필드를 식별하고 `form_input`/`computer type`으로 입력. 긴 텍스트는 한 번에 붙여 넣고 글자 수 카운터를 스크린샷으로 확인.
3. 이미지는 `assets/`에서 `file_upload`. 업로드 후 AI 사전 검열 결과를 확인하고 반려 시 `docs/30-image-assets/06-policy-checklist.md`로 원인 파악.
4. 각 단계 입력 후 **임시 저장**. 미리보기 채팅으로 첫 메시지·말투·상태창 위치를 1~2턴 테스트.
5. 등록 단계에서 모든 값을 스크린샷으로 정리해 사용자에게 보여주고, **"등록/공개" 버튼은 사용자 확인 후** 누른다. 온리/오리지널 신청 토글도 동일.

## 3. 기록
- `status.md`에 날짜·URL·등급·독점·입력 중 발견한 실제 필드 제한을 적는다.
- 문서와 다른 필드·제한을 발견하면 `docs/10-platforms/crack.md` 미확인 항목을 갱신한다.

## 4. 하지 않는 것
- 로그인, 성인 인증, 결제, 약관·정책 동의 클릭, 사용자 확인 없는 공개·삭제·등급 변경.
